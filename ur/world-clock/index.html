عالمی گھڑی درست کیسے رہتی ہے؟

یہ آپ کی ڈیوائس گھڑی فی سیکنڈ ایک بار پڑھتا ہے اور اس لمحے کو آپ کے براؤزر میں شامل Intl API استعمال کرکے ہر شہر کے IANA وقت زون میں تبدیل کرتا ہے۔ وقت زون قواعد، دن کی روشنی بچت سمیت، اسی ڈیٹا بیس سے آتے ہیں جو آپریٹنگ سسٹم استعمال کرتے ہیں۔

دوسرے شہر میں تاریخ مختلف کیوں ہو سکتی ہے؟

کیونکہ دن کی حد شہروں کے درمیان ہے: جب آکلینڈ میں صبح سویرے ہے تو لاس اینجلس میں اب بھی پچھلی سہ پہر ہے۔ اس لیے ہر کارڈ شہر کی اپنی تاریخ کے ساتھ اس کا وقت بھی دکھاتا ہے۔

کیا یہ Loona Hours پر ٹائم زون کنورٹر جیسا ہے؟

نہیں۔ وہ آلہ دو زون کے درمیان ایک منتخب وقت تبدیل کرتا ہے۔ یہ صفحہ ایک نظر میں 24 شہروں میں موجودہ اوقات کا براہ راست بورڈ ہے۔ اس سائٹ پر موجود وقت کیلکولیٹر مدت جمع اور گھٹاتا ہے — پھر مختلف کام۔

اگر وقت غلط لگے تو؟

یہ کیسے کام کرتا ہے — فارمولا

ہر کارڈ ایک لمحہ تبدیل کرتا ہے — آپ کے آلے سے موجودہ وقت — بلٹ ان کے ساتھ ٹائم زون میں Intl.DateTimeFormat API اور IANA زون کا نام (مثال کے طور پر Asia/Karachi۔ ہر زون کی طرف سے دکھایا گیا UTC آف سیٹ وہی ہے جو وہ زون اس تاریخ پر مناتا ہے، تو گرمی اور سردی آف سیٹ (دن کی روشنی بچت) خودکار لاگو ہوتے ہیں۔ مقامی وقت = UTC لمحہ + اس تاریخ پر زون کا آفسیٹ۔

اس کے بجائے کسی خاص لمحے کو تبدیل کرنا؟ Loona ڈویلپر ٹولز پر ٹائم اسٹیمپ کنورٹر Unix ٹائم اسٹیمپ کو انسانی تاریخوں میں اور واپس تبدیل کرتا ہے — یہ سائٹ جان بوجھ کر اس کی نقل نہیں کرتی۔

عملی مثال

فوری: 15 جنوری 2026، 12:00:00 UTC۔

مراحل: لندن جنوری میں GMT (UTC+0) مناتا ہے → 12:00۔ کراچی سارا سال UTC+5 ہے → 17:00۔ دبئی UTC+4 ہے → 16:00۔ نیویارک جنوری میں EST (UTC−5) مناتا ہے → 07:00۔ ٹوکیو UTC+9 ہے → 21:00۔

نتیجہ: ایک لمحہ اس طرح دکھایا گیا 12:00 / 17:00 / 16:00 / 07:00 / 21:00 پانچوں شہروں میں۔
