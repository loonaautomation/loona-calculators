❤️ 目標心率計算器

輸入您的年齡和靜息心率，使用 Karvonen 公式獲得您的估計最大心率和五個訓練區，該公式利用您的心率儲備來個性化訓練區。

快速答案： 最大心率估算為 220 − 年齡。給定強度的 Karvonen 目標為靜息心率 + 強度 ×（最大心率 − 靜息心率）。對於一名靜息心率為 60 的 40 歲人士，2 區（60–70%）為 132–144 bpm。

如何使用 Target Heart Rate Calculator

  1. 輸入您的年齡。
  2. 輸入您的靜息心率——在早上起床前測量，數整整一分鐘的心跳。
  3. 讀取您的五個區間：恢復、燃脂耐力、有氧、閾值和最大努力。
示例： 年齡 40，靜息心率 60：最大心率 = 180，心率儲備 = 120。區間 2 在 60–70% 強度下 = 60 + 0.60×120 到 60 + 0.70×120 = 每分鐘 132–144 次。

常見問題

什麼是 Karvonen 公式？

目標心率 = 靜息心率 + 強度 ×（最大心率 − 靜息心率）。括號中的項是您的心率儲備——您的心臟實際能工作的範圍——這就是 Karvonen 區間與最大心率簡單百分比不同的原因。

220 − 年齡有多準確？

這是總體估算，對個體的典型誤差約為 ±10–12 bpm。Tanaka 公式（208 − 0.7 × 年齡）與研究資料的擬合略好；本頁顯示兩種最大估值，並基於經典的 220 − 年齡構建區間，使結果與大多數健身房圖表一致。

哪個區間燃燒脂肪？

較低的區間使用更高比例的脂肪作為燃料，但總卡路里對減重更重要。2 區（約 60–70%）是經典的可持續耐力區間，用於大部分訓練量。

我應該以最大心率訓練嗎？

第5區適合健康且受過訓練的人進行短時高強度間歇訓練。如果你有任何心臟疾病、症狀或健康疑慮，在進行高強度訓練前請諮詢醫生。本頁是教育指南，不是醫療建議。

工作原理 — 公式

最大心率 ≈ 220 − 年齡 (Tanaka 替代公式：208 − 0.7 × 年齡)。 心率儲備 (HRR) = 最大 HR − 靜息 HR。 Karvonen 目標 = 靜息心率 + 強度 × 心率儲備。 區間：第1區 = HRR的50–60%，第2區 = 60–70%，第3區 = 70–80%，第4區 = 80–90%，第5區 = 90–100%。

示例

輸入項： 年齡40歲，靜息心率60 bpm。

步驟： 最大心率 = 220 − 40 = 180。心率儲備 = 180 − 60 = 120。2 區下限 = 60 + 0.60 × 120 = 132；2 區上限 = 60 + 0.70 × 120 = 144。Tanaka 最大估值 = 208 − 0.7 × 40 = 180——此處相同。

結果： 第2區 = 132–144 bpm，最大 HR 180 bpm.
