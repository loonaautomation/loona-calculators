📐 勾股定理計算器

輸入直角三角形的任意兩條邊，計算器會使用勾股定理求出第三條邊，並展示完整的代入過程，以便學生跟上每一步。

快速答案： 勾股定理說，對於直角三角形 a² + b² = c²，其中 c 是斜邊。經典例子是 3-4-5：9 + 16 = 25，因此斜邊是 5。

如何使用 Pythagorean Theorem Calculator

  1. 輸入您知道的兩條邊（將未知邊留空，或設為 0）。
  2. 如果您知道斜邊，請將其輸入為 c。
  3. 按“計算”——缺失的邊和完整的演算過程隨即出現。
示例： 直角邊 6 和 8：c = √(36 + 64) = √100 = 10。當斜邊為 13、一條直角邊為 5 時：另一條直角邊 = √(169 − 25) = √144 = 12。

常見問題

哪一邊是斜邊？

直角對面的邊——始終是最長的邊，這裡標記為 c。其他兩條邊（直角邊）是 a 和 b。

如何求一條直角邊而不是斜邊？

重新整理定理：a = √(c² − b²)。斜邊必須比任何一條直角邊都長；如果不是，該三角形就不可能是邊長如此的直角三角形，計算器會說明這一點。

它適用於非直角三角形嗎？

不是。該定理僅對直角三角形成立。對於其他三角形，您需要餘弦定律——本站的 Trigonometry Calculator 可以幫助處理角度和比值。

為什麼 3-4-5 三角形到處出現？

因為 3² + 4² = 5² 恰好成立，建築商和木匠幾千年來一直使用 3-4-5 繩索或捲尺來標記真正的直角。其他整數三元組包括 5-12-13、8-15-17 和 7-24-25。

工作原理 — 公式

a² + b² = c². 求斜邊：c = √(a² + b²)。求一條直角邊：a = √(c² − b²) 或 b = √(c² − a²)。必須恰好給出兩條邊；第三條邊是推匯出來的，只有當斜邊是最長邊時才能求出直角邊。

示例

輸入項： 斜邊c = 13，直角邊a = 5，求b。

步驟： b = √(c² − a²) = √(169 − 25) = √144 = 12.

結果： b = 12 ——5-12-13三元組。
