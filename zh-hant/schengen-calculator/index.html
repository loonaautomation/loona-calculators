🇪🇺 申根90/180計算器

輸入您過去和計劃前往申根區的行程。計算器會檢查每個滾動的 180 天視窗——而不僅僅是日曆半年——計算已使用的天數，顯示您還剩多少天，警告任何逾期停留，並找出您可以開始新的完整 90 天停留的最早日期。

快速答案： 申根短期停留規則允許最多停留 90 天，在任何滾動 180 天期間內。入境日和出境日都算作在場天數，視窗每天移動——它不被分成固定的六個月塊。

將上面輸入的行程用作您的歷史。輸入一次計劃行程，檢視它的每一天是否都保持在 90/180 限制內。

如何使用 Schengen 90/180 Calculator

  1. 新增每次行程及其進入和離開日期（兩天都算）。
  2. 設定核查日期——預設為今天——以檢視截至該日的 180 天視窗內已使用的天數和剩餘天數。
  3. 讀取任何滾動視窗內找到的最大天數：超過 90 意味著根據該規則逾期停留。
  4. 如果您正在規劃一次長途新旅行，使用最早的完整停留結果。
示例： 兩次行程，各 45 天——一月1日–二月14日，2026年和三月1日–四月14日，2026年——正好用 90 天。在四月14日，2026年，視窗持有全部 90 天，剩餘 0 天，不存在逾期停留，因為允許 90 天。

常見問題

90/180 規則實際上如何運作？

在您身處申根區的任何一天，計算包括那一天在內的前 180 天內您的停留天數。總數永遠不得超過 90。該視窗每天向前滾動，本計算器在您的所有行程中逐日檢查。

入境日和出境日計算在內嗎？

是的。按歐盟規則，進入日和離開日都算作完整的停留天數，本計算器就是這樣計算的。

如果我離開又快速返回，什麼算作一次行程？

身處申根區內的每一天都算數，無論區外的間隔多短。請分別輸入每段停留，計算器會將它們全部加到相同的滾動視窗中。

這構成法律建議嗎？

不是。這是基於歐盟標準 90/180 短期停留規則的指導，適用於免籤和短期簽證訪客。它不涵蓋居留許可、長期簽證，或某些國籍在雙邊協議下的特殊規則。由邊境當局決定；請檢視歐盟官方來源瞭解您的情況。

工作原理 — 公式

對於每個日期 D，presence(D) = 落入該視窗內的你的行程天數 [D − 179天，D]。只有當存在某個 D 使 presence(D) > 90 時，規則才被打破。本計算器會對每一個相關日期評估 presence——每個行程日及其前後日期——而不是抽樣，因此滾動視窗的邊界情況能被精確捕捉。核查日期的剩餘天數 = 90 − presence（核查日期）。最早的完整停留開始日期是透過逐日測試候選開始日期找到的：從 S 開始的 90 天停留只有在停留期間每一天（包括新增的天數本身）presence 都保持在 90 或以下時才是安全的。

示例

輸入項： 行程 1：一月1日–二月14日，2026年（31 + 14 = 45 天）。行程 2：三月1日–四月14日，2026年（31 + 14 = 45 天）。檢查日期四月14日，2026年。

步驟： 截至 2026 年四月 14 日的 180 天視窗從 2025 年十月 17 日開始，因此它完整包含兩次旅行：45 + 45 = 已使用 90 天。剩餘天數 = 90 − 90 = 0。任何視窗內的最大值是 90，這是允許的——沒有逾期停留。

結果： 已使用 90 天，剩餘 0 天，未逾期停留 ——但多待一天，日期為四月15日，2026年，視窗內就會變成91天，從而違反規則。

免責宣告： 僅為指導，基於歐盟 90/180 短期停留規則。規則核查日期：十一月8日，2026年。不是法律建議。居留許可、長期簽證和雙邊協議可能改變這一狀況——請始終向歐盟或國家官方來源確認。
