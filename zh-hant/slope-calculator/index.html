📉 斜率計算器

輸入兩個點 (x₁, y₁) 和 (x₂, y₂)，即可獲得關於它們之間直線的全部資訊：斜率、距離、中點、角度以及方程 y = mx + b——並展示每個公式的代入過程。

快速答案： 斜率 = (y₂ − y₁) ÷ (x₂ − x₁)。對於 (1, 2) 和 (4, 8)：斜率 = 6 ÷ 3 = 2，距離 = √(3² + 6²) = √45 ≈ 6.71，中點為 (2.5, 5)。

如何使用 Slope Calculator

  1. 輸入第一個點的座標。
  2. 輸入第二個點的座標。
  3. 讀取斜率、距離、中點和直線方程。
示例： 點 (1, 2) 和 (4, 8)：斜率為 2，距離為 √45 ≈ 6.708，中點為 (2.5, 5)，直線方程為 y = 2x + 0——它經過原點，您可以驗證：當 x = 1 時，y = 2 ✓。

常見問題

斜率為 2 是什麼意思？

每向右移動 1 個單位，直線上升 2 個單位。斜率為 0 是平坦的，負斜率向右下降，未定義的斜率（除以零）是垂直線。

兩點之間的距離是如何計算的？

使用畢達哥拉斯：距離 = √((x₂ − x₁)² + (y₂ − y₁)²)。座標差是直角三角形的兩條直角邊，距離是它的斜邊。

什麼是中點公式？

平均座標：中點 = ((x₁ + x₂) ÷ 2, (y₁ + y₂) ÷ 2)。它正是線段正中間的點。

如果兩個 x 值相同怎麼辦？

這條線是垂直的：斜率未定義，沒有 y = mx + b 方程。計算器報告垂直線 x = 該值，外加正常的距離和中點。

工作原理 — 公式

斜率： m = (y₂ − y₁) ÷ (x₂ − x₁). Distance： d = √((x₂ − x₁)² + (y₂ − y₁)²). 中點： ((x₁ + x₂) ÷ 2, (y₁ + y₂) ÷ 2). 直線方程： 使用點1，b = y₁ − m·x₁，得到y = mx + b。 角度： θ = arctan(m)，以度為單位，從x軸正方向量起。

示例

輸入項： (1, 2) 和 (4, 8)。

步驟： 斜率 = (8 − 2) ÷ (4 − 1) = 6 ÷ 3 = 2。距離 = √((4−1)² + (8−2)²) = √(9 + 36) = √45 = 6.708。中點 = ((1+4)÷2, (2+8)÷2) = (2.5, 5)。截距：b = 2 − 2×1 = 0，因此直線為 y = 2x。

結果： 斜率 2，距離 6.708，中點 (2.5, 5)，方程 y = 2x.
