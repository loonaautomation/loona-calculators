📈 線性迴歸計算器

貼上配對的 x,y 資料以擬合最小二乘最佳擬合線：斜率、截距、相關性、擬合方程、任意 x 的預測——以及帶您的點和穿過它們的直線的散點圖。

快速答案： 最小二乘法：斜率 b = Σ(x−x̄)(y−ȳ) ÷ Σ(x−x̄)²，截距 a = ȳ − b·x̄。對於 x = 1..5，y = 2,4,5,4,5：斜率 = 6 ÷ 10 = 0.6，截距 = 4 − 0.6×3 = 2.2，因此直線為 y = 2.2 + 0.6x。

如何使用 Linear Regression Calculator

  1. 貼上匹配的 x 和 y 列表（至少 3 對）。
  2. 按“擬合直線”檢視方程、r 和 r²，以及散點圖。
  3. 輸入任意 x，即可讀取模型預測的 y。
示例： 對於學習時間資料 (x = 1–5，y = 2,4,5,4,5)，直線 y = 2.2 + 0.6x 預測在 x = 6 時分數為 2.2 + 0.6×6 = 5.8——這是超出資料的外推，因此請謹慎對待。

常見問題

'最小二乘' 是什麼意思？

選擇這條線是為了最小化點與線之間的垂直間隙（殘差）平方和。平方會嚴厲懲罰大的偏差，這就是異常值會拖動這條線的原因。

用通俗的話解釋斜率和截距？

斜率是當 x 上升 1 時 y 平均變化的量。截距是當 x = 0 時模型的 y——只有當 x = 0 在您資料的範圍內或附近時才有意義。

在資料範圍之外進行預測安全嗎？

這是外推，而且有風險：關係往往在觀測範圍之外彎曲。計算器會計算它，但離您的 x 範圍越遠，這條線就越不值得信任。

這與相關性計算器有何關係？

它們共享相同的總和：r 是標準化斜率。迴歸新增實際的線（以 y 單位每 x 單位）和預測，這是相關性本身無法給出的。

工作原理 — 公式

斜率 b = Sxy ÷ Sxx 其中Sxy = Σ(x−x̄)(y−ȳ)，Sxx = Σ(x−x̄)²。 截距 a = ȳ − b·x̄ ——這保證迴歸線總是穿過資料的質心（x̄，ȳ）。預測：ŷ = a + b·x。還會報告：r、r²和殘差標準誤。

示例

輸入項： x = [1,2,3,4,5], y = [2,4,5,4,5].

步驟： x̄ = 3，ȳ = 4，Sxy = 6（來自相關性計算），Sxx = 10。斜率 = 6 ÷ 10 = 0.6。截距 = 4 − 0.6 × 3 = 2.2。在x = 6處預測：2.2 + 0.6 × 6 = 5.8。

結果： 直線 y = 2.2 + 0.6x，r = 0.775，r² = 0.600。
