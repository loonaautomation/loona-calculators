💊 用藥時間表規劃器

在不同時間服用多種藥物很容易出錯。在下方新增每種藥物——其劑量、服藥時間以及是否隨餐服用——本規劃器會將它們合併為一份清晰的每日時間表，並提供可列印的藥片表、續藥日期和手機日曆提醒。免費、無需註冊且完全私密：您的清單永遠不會離開您的瀏覽器。

快速答案： 用藥時間表規劃器將您的所有藥物合併為一份每日時間表：輸入每種藥物、其劑量和時間——每隔 X 小時或在固定時間——它會構建合併表格、計算續藥日期並匯出日曆提醒。所有內容都保留在您的瀏覽器中。

安全第一： 本規劃器僅整理您輸入的時間表——它不是醫療建議，也不檢查劑量或藥物交互作用。請始終嚴格按照處方服藥，如有任何不清楚之處，請諮詢您的醫生或藥劑師。

🔒 隱私設計： 您的藥物僅保存在此瀏覽器中（本地儲存），因此當您再次訪問時規劃器能記住它們。任何內容都不會上傳或傳送到任何地方。

如何使用用藥時間表規劃器

  1. 新增每種藥物：其名稱、劑量（例如「500 mg — 1 片」），以及服用頻率——從首次服藥時間起每隔 X 小時，或每天在固定時間服用。
  2. 對於必須隨餐服用的藥物，勾選「隨餐服用」；如果您想獲得續藥日期，請輸入您現有的供應天數。
  3. 設置療程開始日期，以及在用完前多少天收到續藥提醒。
  4. 點擊「生成我的時間表」——您的所有藥物將被合併為一份每日時間表，並附有可列印的藥片表和可匯入手機的日曆（.ics）文件。
範例： 對乙酰氨基酚每8小時從06:00開始，服藥時間為06:00、14:00和22:00。再新增一種每天兩次、隨餐服用的藥物，時間為08:00和20:00，規劃器會將所有內容合併為一個清單——每天五個服藥時間，不遺漏，不重複。

常見問題

這是醫療建議嗎？

不是。本規劃器僅整理您輸入的時間表。它不檢查劑量、組合或交互作用。請始終嚴格按照處方服藥，如有任何不清楚之處，請諮詢您的醫生或藥劑師。

續藥日期如何計算？

續藥日期 = 開始日期 + 供應天數 − 提醒天數。如果您從11月18日開始，有30天供應量並設置3天提醒，規劃器會顯示您將在12月17日用完，應在12月15日之前訂購續藥。

這裡的「每8小時」是什麼意思？

您的第一次服藥在您選擇的時間，然後每8小時服藥一次，全天如此——例如06:00、14:00和22:00。超過午夜的時間會滾動到同一每日表格的凌晨時段。

我的藥物清單會被上傳到任何地方嗎？

不會。所有內容僅保存在您自己的瀏覽器中（本地儲存），因此規劃器能在此裝置上記住您的藥物。任何內容都不會傳送到伺服器，您可以隨時使用「清除保存的資料」將其刪除。

我可以把時間表放到手機日曆上嗎？

可以。點擊「下載日曆文件（.ics）」，將文件匯入 Google 日曆、Apple 日曆或 Outlook——每次服藥都會成為一個重複提醒，並在續藥日期生成一個續藥提醒。

工作原理——時間表計算

對於每隔 X 小時服用的藥物，規劃器從您的首次服藥時間開始，反覆加上 X 小時，直到覆蓋完整的24小時；超過午夜的時間會繞回到凌晨時段，然後將清單按時鐘順序排序。對於固定時間的藥物，它直接使用您輸入的時間，排序並去除重複。然後將所有藥物按一天中的時間合併為一份時間表——如果兩種藥物在同一時間服用，它們共用一行，因此不會隱藏任何內容，也不會重複計算。

續藥計算為：最後覆蓋日 = 開始日期 + 供應天數 − 1，續藥日期 = 開始日期 + 供應天數 − 提醒天數。日曆（.ics）匯出將每種模式轉換為標準重複事件——每隔 X 小時的藥物按小時重複，固定時間的藥物按天重複——在最後覆蓋日結束，並在續藥日期09:00新增一個續藥提醒事件。

實例

輸入： 藥物A每8小時一次，首次06:00。藥物B固定時間08:00和20:00，隨餐服用。開始日期2026年11月18日，兩者均有30天供應量，續藥提醒3天。

步驟： A得到06:00、14:00、22:00。B得到08:00和20:00。合併：06:00 A · 08:00 B（隨餐）· 14:00 A · 20:00 B（隨餐）· 22:00 A——每天5次。最後覆蓋日 = 11月18日 + 29天 = 2026年12月17日。續藥日期 = 11月18日 +（30 − 3）天 = 2026年12月15日。

結果： 一份包含5個服藥時間的每日時間表、一張7天打勾表、在2026年12月15日之前續藥，以及包含相同事件的.ics文件。
