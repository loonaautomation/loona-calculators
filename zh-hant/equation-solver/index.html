方程求解器（線性 & 二次）

求解線性方程 (ax + b = cx + d) 和二次方程 (ax² + bx + c = 0)，顯示每一步——包括判別式、重根和復根，以及將答案代回的最終檢驗。

輸入這四個數字，在 ax + b = cx + d。缺項處使用 0——例如，2x + 3 = 7 即 a = 2，b = 3，c = 0，d = 7。

輸入這三個係數，在 ax² + bx + c = 0。缺項處使用 0——例如，x² − 9 = 0 即 a = 1，b = 0，c = −9。

如何使用 Equation Solver

  1. 選擇方程型別：線性（僅 x）或二次（x²）。
  2. 輸入係數——x² 和 x 前面的數字，以及純數字。任何缺失項輸入 0。
  3. 按“帶步驟求解”，逐行閱讀演算過程。最後一步將答案代回原方程進行驗證。
示例： 3x + 2 = x + 10。將 x 項移到左側：2x + 2 = 10。將數字移到右側：2x = 8。兩邊除以 2： x = 4。檢驗：3 × 4 + 2 = 14 且 4 + 10 = 14 ✓

常見問題

本求解器能處理什麼型別的方程？

形式為 ax + b = cx + d 的線性方程，以及形式為 ax² + bx + c = 0 的二次方程。它顯示每一步、二次方程的判別式，以及最後的檢驗。它不求解三次方程、二元聯立方程或不等式——頁面標題確切說明了它的涵蓋範圍。

“無解”或“無窮多解”是什麼意思？

有時 x 項會完全抵消。如果數字也匹配（如 5x + 1 = 5x + 1），方程恆為真——有無窮多解。如果數字不匹配（5x + 1 = 5x + 3），它就永不為真——無解。求解器會誠實地告訴您屬於哪種情況，而不是捏造答案。

什麼是複數根？

當二次方程的判別式（b² − 4ac）為負時，圖形從不與 x 軸相交，沒有實數答案。根是使用 i 的複數，其中 i² = −1——例如，x² + 1 = 0 的根為 x = i 和 x = −i。本求解器顯示它們並仍會檢查它們。

工作原理——方法

線性方程 的解法是保持方程平衡——對一邊做的操作，也要對另一邊做。先把x項集中到左側（兩邊減cx），再把數字項集中到右側（減b），最後兩邊除以x的係數。

二次方程 使用求根公式。對於ax² + bx + c = 0：

x = (−b ± √(b² − 4ac)) ÷ (2a)

根號下的部分， D = b² − 4ac，稱為判別式，它在你完成計算之前就告訴你答案的型別：D > 0 表示兩個不同的實根，D = 0 表示一個重根，D < 0 表示兩個復根且沒有實數解。

示例

示例： 求解 x² − 5x + 6 = 0。這裡 a = 1，b = −5，c = 6。D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1，因此 √D = 1。然後 x = (5 + 1) ÷ 2 = 3 or x = (5 − 1) ÷ 2 = 2。檢驗 x = 3：9 − 15 + 6 = 0 ✓

常見問題

我如何輸入缺少一項的方程？

對於缺失的係數輸入 0。x² − 9 = 0 變為 a = 1、b = 0、c = −9，求解器給出 x = 3 或 x = −3。對於像 2x = 10 這樣的線性方程，則是 a = 2、b = 0、c = 0、d = 10。

如果我在二次方程求解器中輸入 a = 0 怎麼辦？

那麼 x² 項消失，方程實際上是線性的。求解器注意到這一點，並改為作為線性方程求解它，告訴您發生了什麼。

為什麼求解器在最後檢查其答案？

將答案代回原方程是發現錯誤最可靠的方法：如果兩邊相等，答案肯定正確。這對家庭作業也是一個好習慣——老師通常會為可見的檢驗給出方法分。
