🧮 かんたん電卓

大きくて押しやすいボタンを備えた無料の基本計算機：足し算、引き算、掛け算、割り算、パーセントキー、計算したすべての履歴テープ、コピーボタン、完全なキーボード対応。

    かんたん電卓の使い方

    1. 数字ボタンをタップするか（またはキーボードで入力して）、最初の数を入力します。
    2. + − × または ÷ をタップし、次に二つ目の数を入力します。チェーンを続けることができます — 2 + 3 + 4 は、進むにつれて各ステップを計算します。
    3. = を押すと、答えが見えます。再び = を押すと、最後の演算が繰り返されます。結果をコピーをタップすると答えがコピーされ、履歴テープの任意の行をタップすると、以前の答えが再使用できます。
    4. 間違えましたか？⌫ は最後の数字を消し、C は入力中の数だけをクリアし、AC はすべてをクリアします。
    例： 店の請求書が 1,250 になり、175 の配送料を加え、その後 2 人で分けると：1250 + 175 = と入力すると、テープには 1,250 + 175 = 1,425 と表示されます。その後 ÷ 2 = と入力すると、それぞれ 712.5 です。

    よくある質問

    % ボタンは、何をしますか？

    それは、その前の数を 100 で割るので、50% は 0.5 になり、10% は 0.1 になります。例えば、200 × 10% = 20 — クイックな割引、チップ、税に便利です。二つの数の間のパーセンテージの変化には、当社のパーセンテージ計算機を使ってください。

    履歴テープはどのように機能しますか？

    = を押すたびに、完成した合計は計算機の下のテープに加えられます。昔の加算機の紙ロールのようです。テープ上の任意の行をタップすると、その答えが戻ってきて計算を続けることができ、「履歴をクリアする」を使ってテープを空にします。テープはこのページのあなたのブラウザの中だけに存在します — サーバーに送信されたり保存されたりすることは決してありません。

    キーボードを使うことはできますか？

    はい。数字キーと . は、数字をタイプします。+ − * / は、操作を選びます。Enter や = は、合計を終えます。% はパーセントです。Backspace は、最後の数字を削除します。Delete は、現在のエントリをクリアします。そして、Escape は、すべてをクリアします。

    かんたん電卓とは何ですか？

    シンプルな計算機 — 基本計算機、四機能計算機とも呼ばれます — は日常の四つの演算を行います：足し算、引き算、掛け算、割り算、通常はパーセントキー付きです。人々が実際に最も必要とする計算機です：買い物の請求書を合計する、レストランの会計を分ける、宿題をチェックする、お釣りを計算する、一日の支出を合計する。この計算機は、人々が携帯電話の計算機で物足りなく感じるものを加えています：タップしやすい大きなボタン、各ステップをチェックできる履歴テープ、デスクトップでの適切なキーボード配置。

    キーボードショートカット

    • 0–9 そして . — 数をタイプします
    • + − * / — 加える、引く、掛ける、割る
    • 入力 または = — 合計を終えます（もう一度押すと、それを繰り返します）
    • % — パーセント（数を 100 で割ります）
    • バックスペース — 最後の数字を削除  ·  削除する — 現在のエントリをクリア（C） ·  エスケープ — すべてをクリア（AC）

    シンプルか科学か — どちらが必要ですか？

    合計が + − × ÷ と % だけを使う場合、このかんたん電卓がより速く、より親しみやすい選択です — 大きなボタン、不要なものはなく、あなたの作業を表示するテープ。合計が三角法、対数、累乗、根、階乗を必要とする場合は、当社の に切り替えます 関数電卓 代わりに。パーセンテージ自体についての合計については — 一つの数が、別の数の何パーセントか、または、パーセンテージの増加と減少 — その パーセント計算機 各ステップを説明します。

    よくある質問

    ゼロで割ると、何が起こりますか？

    計算機は、答えの代わりに「ゼロで割ることはできません」と表示します。ゼロで割ることは、数学で定義された結果を持たないためです。何も壊れません — C または AC を押すか、単に新しい数を入力し始めて、続行します。

    かんたん電卓を使うべきですか、関数電卓を使うべきですか？

    このかんたん電卓を、日常の加算、減算、乗算、除算 — 買い物、請求書、宿題、素早い合計 — のために使います。大きなボタンと履歴テープが最も役立つ場所です。sin、cos、tan、対数、累乗、根、階乗が必要な場合は、関数電卓を使います。
