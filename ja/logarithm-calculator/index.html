log 対数計算機

任意の底への任意の数の対数を求めます — そして、常用対数、自然対数（ln）、二進対数を並べて取得します。各々は、底を答えまで累乗して戻すこと（真数）で検証されます。

対数計算機の使い方

  1. 対数を求める数 x を入力してください。0 より大きくなければなりません。
  2. 底 b を入力してください — または「底 10」「底 2」「底 e」をタップ。底は 0 より大きく、1 に等しくてはなりません。
  3. 計算を押します。あなたの底への対数と、常用対数（底 10）、自然対数（底 e）、二進対数（底 2）が得られ、底をあなたの答えまで戻し上げる真数の確認が得られます。
例： log2(32) = 5（理由：25 = 32。そして log10(1000) = 3（理由：103 = 1000.

よくある質問

対数とは、簡単な言葉で何ですか？

対数は次の質問に答えます：「この数を得るには、底を何乗しなければならないか？」log10(1000) = 3。10の3乗は1000だからです。これは累乗の反対（逆）であり、わり算がかけ算の反対であるのと同じです。

log と ln の違いは何ですか？

"log" はほとんどの計算機では底10を意味します — 常用対数です。"ln" は底 e（e ≈ 2.71828）を意味します — 自然対数で、科学と金融のあらゆる場面で使われます。この計算機では、その両方と、底2（コンピューティングで使う二進対数）を、入力した任意の数について求められます。

なぜ、0 や負の数の対数が取れないのですか？

正の底のどの累乗も、0 や負の結果を生み出すことは決してできないためです：10 の任意の累乗は常に正です。そのため、実数については 0 や負の数の対数は未定義であり、この計算機は作られた答えを示すのではなく、そうあなたに伝えます。

仕組み — 公式

定義： logb(x) = y のときにちょうど by = x。対数と累乗は同じ事実の両面です。

底の変換： ほとんどの計算機は、log（底 10）と ln（底 e）のキーしか持ちません。任意の他の底への対数を見つけるためには、割ります：

logb(x) = ln(x) ÷ ln(b) = log10(x) ÷ log10(b)

その基数変換ルールは、このページが内部的に使うものです。そのため、基数 b について得られる答えは、手でステップごとに得られるものと同じです。

真数（アンチログ）： 底 b への y の逆対数は、単に b ですy — それは、対数を元に戻します。log が10(1000) = 3 のとき、3 の真数（アンチログ）は 103 = 1000。このページのすべての結果は、お見せする前にこの方法でチェックされます。

実例

例： 対数を求める2(32) は底の変換によります。ln(32) ≈ 3.4657、ln(2) ≈ 0.6931。割ると：3.4657 ÷ 0.6931 = 5。真数（アンチログ）で確認：25 = 32 ✓

よくある質問

任意の底における 1 の対数とは何ですか？

常に 0 です。0 の累乗に上げられた任意の底は 1 に等しいためです：b0 = 1。同じように、logb(b) は常に1です。なぜなら b1 = b.

なぜ、底は 1 であってはならないのですか？

1 を任意の累乗に上げても常に 1 であるため、「100 を得るには 1 を何乗しなければならないか？」には答えがまったくなく — 数 1 自体については無限に多くあることになります。そのため底 1 は除外され、実数の作業では底 0 と負の底も除外されます。

対数は、実生活でどこで使われますか？

量が乗算で増える場所すべて：地震の強さ（リヒター尺度）、音の大きさ（デシベル）、酸性度（pH）、複利と半減期の計算、そして、コンピューティングにおける二進対数（データセットが何ビット、または何回の半減を必要とするか）。
