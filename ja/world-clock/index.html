🌍 世界時計

世界中の 24 の主要都市における現在の現地時刻。一秒ごとに更新されます。時刻は、あなたの自身のデバイスの時計と、公式の IANA タイムゾーンデータベースを組み合わせたものから来ます。そのため、夏時間の変更は自動的に処理されます。

クイックな答え： 世界時計は他のタイムゾーンの現在時刻を表示します。たとえば、冬のロンドンで正午 12:00 のとき、カラチでは 17:00、ドバイでは 16:00、ニューヨークでは 07:00、東京では 21:00 です。

世界時計の使い方

  1. ページを開きます — 入力は不要です。
  2. グリッドであなたの都市を見つけてください。時刻と日付は毎秒更新されます。
  3. 各都市の下のオフセットラインを使って、あなたの自身の現地時刻と比較します。
例： 2026年一月15日 12:00:00 UTC には、時計はロンドン 12:00、カラチ 17:00、ドバイ 16:00、ニューヨーク 07:00、東京 21:00 を表示します — 同じ瞬間、五つの異なる現地時間。

よくある質問

世界時計はどのように正確を保ちますか？

それは、デバイスの時計を毎秒一度読み、その瞬間を、ブラウザに組み込まれた Intl API を使って各都市の IANA タイムゾーンに変換します。夏時間を含むタイムゾーンのルールは、オペレーティングシステムが使うのと同じデータベースから来ます。

なぜ、日付は、別の都市では異なることがあるのですか？

日の境界が都市の間に位置するためです：オークランドで早朝のとき、ロサンゼルスはまだ前日の午後です。そのため、各カードは市の時間とともに、その市自身の日付も表示します。

これは Loona Hours のタイムゾーン変換と同じですか？

いいえ。そのツールは、二つのゾーンの間で選ばれた一つの時刻を変換します。このページは、一目で 24 都市の現在の時刻のライブボードです。このサイトの既存の時間計算機は期間を加算・減算します — また異なる仕事です。

時刻が間違って見える場合はどうなりますか？

まずデバイスの時計を確認してください — 変換は正確ですが、デバイスの現在の瞬間から始まります。ブラウザはオペレーティングシステムからタイムゾーンのルールを取得します。そのため最新に保ってください。

仕組み — 公式

すべてのカードは一つの瞬間 — あなたのデバイスの現在時刻 — を、組み込みのタイムゾーンに変換します Intl.DateTimeFormat API と IANA ゾーン名（例： Asia/Karachi）。各ゾーンに表示される UTC オフセットは、その日付にそのゾーンが実際に使うものであるため、夏と冬のオフセット（夏時間）は自動的に適用されます。 現地時間 = UTC の瞬間 + その日付でのゾーンのオフセット。

代わりに特定の瞬間を変換しますか？その Loona 開発者ツールのタイムスタンプ変換 Unix タイムスタンプを、人間の日付に変換し、戻します — このサイトは、意図的にそれを複製しません。

実例

即時： 15 Jan 2026, 12:00:00 UTC.

ステップ： ロンドンは一月に GMT（UTC+0）を守ります → 12:00。カラチは一年中 UTC+5 → 17:00。ドバイは UTC+4 → 16:00。ニューヨークは一月に EST（UTC−5）を守ります → 07:00。東京は UTC+9 → 21:00。

結果： 一つの瞬間が次のように表示されます 12:00 / 17:00 / 16:00 / 07:00 / 21:00 五つの都市全体で。
