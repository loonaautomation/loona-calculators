📉 傾き計算機

二点 （x₁, y₁) と (x₂, y₂) を入力すると、それらの間の線についてのすべてが得られます：傾き、距離、中点、角度、方程式 y = mx + b — 各公式の代入が表示されます。

クイックな答え： 傾き = (y₂ − y₁) ÷ (x₂ − x₁)。(1, 2) と (4, 8) については：傾き = 6 ÷ 3 = 2、距離 = √(3² + 6²) = √45 ≈ 6.71、そして中点は (2.5, 5) です。

傾き計算機の使い方

  1. 最初の点の座標を入力してください。
  2. 二番目の点の座標を入力してください。
  3. 傾き、距離、中点、直線の方程式を読みます。
例： 点 (1, 2) と (4, 8)：傾き 2、距離 √45 ≈ 6.708、中点 (2.5, 5)、直線の方程式 y = 2x + 0 — それは原点を通ります。確認できます：x = 1 で、y = 2 ✓。

よくある質問

傾き 2 とは、何を意味しますか？

右に 1 ユニット移動するごとに、線は 2 ユニット上がります。傾き 0 は平坦、負の傾きは右に下がり、未定義の傾き（ゼロによる除算）は垂直な線です。

二つの点の間の距離はどのように計算されますか？

ピタゴラスで：距離 = √((x₂ − x₁)² + (y₂ − y₁)²)。座標の差は、直角三角形の二つの脚です。そして、距離は、その斜辺です。

中点の公式とは何ですか？

座標を平均します：中点 = ((x₁ + x₂) ÷ 2, (y₁ + y₂) ÷ 2)。区間の中間ちょうどの点です。

両方の x の値が同じ場合はどうなりますか？

直線は垂直です：傾きは未定義であり、y = mx + b の方程式はありません。計算機は、垂直な直線 x = その値を報告し、距離と中点を通常通り報告します。

仕組み — 公式

傾き： m = (y₂ − y₁) ÷ (x₂ − x₁)。 距離： d = √((x₂ − x₁)² + (y₂ − y₁)²)。 中点： ((x₁ + x₂) ÷ 2, (y₁ + y₂) ÷ 2). 直線の方程式： 点 1 を使って、b = y₁ − m·x₁、y = mx + b を与えます。 角度： θ = arctan(m)。正の x 軸からの、度で。

実例

入力： (1, 2) と (4, 8)。

ステップ： 傾き = (8 − 2) ÷ (4 − 1) = 6 ÷ 3 = 2。距離 = √((4−1)² + (8−2)²) = √(9 + 36) = √45 = 6.708。中点 = ((1+4)÷2, (2+8)÷2) = (2.5, 5)。切片：b = 2 − 2×1 = 0。だから直線は y = 2x です。

結果： 傾き 2、距離 6.708、中点 (2.5, 5)、方程式 y = 2x.
