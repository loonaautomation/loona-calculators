方程式ソルバー（線形と二次）

線形方程式（ax + b = cx + d）と二次方程式（ax² + bx + c = 0）を、すべてのステップを示して解きます — 判別式、重複根と複素数根を含み、答えを代入し戻す最終確認も。

四つの数を入力してください ax + b = cx + d。項が欠けている場合は 0 を使います — たとえば、2x + 3 = 7 は a = 2、b = 3、c = 0、d = 7 です。

三つの係数を入力してください ax² + bx + c = 0。項が欠けている場合は 0 を使います — たとえば、x² − 9 = 0 は a = 1、b = 0、c = −9 です。

方程式ソルバーの使い方

  1. 方程式の種類を選びます：線形（x のみ）か二次（x²）。
  2. 係数を入力します — x² と x の前の数と、無地の数。不在の項については、0 を入力します。
  3. ステップで解くを押し、作業を行ごとに読みます。最後のステップは、答えを元の方程式に戻し入れて確認します。
例： 3x + 2 = x + 10。x の項を左へ移す：2x + 2 = 10。数を右へ移す：2x = 8。2 で割る： x = 4。確認：3 × 4 + 2 = 14、4 + 10 = 14 ✓

よくある質問

このソルバーは、どの種類の方程式を処理できますか？

ax + b = cx + d の形の線形方程式と、ax² + bx + c = 0 の形の二次方程式。すべてのステップ、二次方程式の判別式、最終チェックを表示します。三次方程式、二つの未知数の連立方程式、不等式は解きません — ページのタイトルが、対象を正確に述べています。

「解なし」または「無限に多くの解」とは、何を意味しますか？

時には、x の項が完全に相殺されます。数も一致する場合（5x + 1 = 5x + 1 のように）、方程式は常に真です — 無限に多くの解。数が一致しない場合（5x + 1 = 5x + 3）、それが真になることは決してありません — 解なし。ソルバーは、答えをでっち上げるのではなく、どちらのケースか正直に伝えます。

複素数根とは何ですか？

二次方程式の判別式（b² − 4ac）が負の場合、グラフは x 軸を決して横切りません。そして、本当の答えはありません。根は、次に、i を使う複素数です。ここで i² = −1 — 例えば、x² + 1 = 0 は、根 x = i と x = −i を持ちます。このソルバーは、それらを表示し、依然としてそれらを確認します。

仕組み — 方法

線形方程式 方程式をバランスさせて解かれます — 一方に行うことは何でも、他方にも行います。まず、x の項は左に集められます（両辺から cx を引きます）。次に、数の項は右に（b を引きます）。そして、最後に、両辺は、x の係数で割られます。

二次方程式 二次方程式の公式を使用します。ax² + bx + c = 0 については：

x = (−b ± √(b² − 4ac)) ÷ (2a)

根の下の部分、 D = b² − 4ac、これは判別式と呼ばれ、解き終える前に答えの種類を教えてくれます：D > 0 は異なる二つの実数解、D = 0 は一つの重解、D < 0 は二つの複素数解で実数解なしを意味します。

実例

例： x² − 5x + 6 = 0 を解く。ここで a = 1、b = −5、c = 6。D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1。だから √D = 1。次に x = (5 + 1) ÷ 2 = 3 または x =（5 − 1）÷ 2 = 2。x = 3 で確認：9 − 15 + 6 = 0 ✓

よくある質問

項が欠けた方程式を入力するにはどうすればよいですか？

欠けている係数は 0 と入力してください。x² − 9 = 0 は a = 1、b = 0、c = −9 となり、ソルバーは x = 3 または x = −3 を示します。2x = 10 のような線形方程式では、a = 2、b = 0、c = 0、d = 10 です。

二次ソルバーで a = 0 と入力した場合はどうなりますか？

すると、x² の項は消え、方程式は本当に線形です。ソルバーは、これに気づき、代わりに線形方程式としてそれを解き、それが起こったことを伝えます。

なぜ、ソルバーは、最後にその答えを確認するのですか？

答えを元の式に代入し戻すことは、間違いを捕らえる最も確実な方法です：両側が等しくなれば、答えは確実に正しいです。それは宿題のためにも良い習慣です — 教師は、しばしば、目に見える確認に対して方法の点数を与えます。
