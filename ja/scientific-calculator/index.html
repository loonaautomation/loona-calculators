🧮 関数電卓

ブラウザの中の完全な関数電卓：三角関数とその逆関数、対数、累乗と根、階乗とパーセント — DEG/RAD 角度モードと完全なキーボード対応を備えます。

DEG/RAD をタップして角度モードを切り替えます。キーボードも動作します — 式を入力して Enter を押します。

関数電卓の使い方

  1. ボタンをタップするか、キーボードで直接入力して、式を構築します — 例えば sin(30) + 2^3。
  2. sin、cos、tan を使う前に、DEG/RAD ボタンを使って、角度がどう測られるかを選びます。
  3. =（または Enter）を押すと、答えが見えます。答えから計算を続けたり、AC を押して再び始めたりできます。
例： sin(30) は DEG モードで = 0.5。そして、2^3^2 = 512。冪は、まず右から処理されるためです（3² = 9、次に 2⁹ = 512）。

よくある質問

DEG と RAD の違いは何ですか？

DEG は角度を度で測ります（一周は 360°）、RAD はラジアンで測ります（一周は 2π）。学校と日常の数学は通常度を使います。高度な数学と科学はラジアンをよく使います。sin、cos、tan を使う前に必ずモードを確認してください — sin(30) は DEG モードでは 0.5 ですが、RAD モードでは約 −0.988 です。

5 の立方のような累乗を計算するにはどうすればよいですか？

5 をタップし、次に xʸ ボタン、次に 3 をタップし、次に =。キーボードで 5^3 と入力することもできます。x² ボタンは、その前の数を二乗するショートカットです。

% ボタンは、何をしますか？

それは、その前の数を 100 で割るので、50% は 0.5 になり、8% は 0.08 になります。例えば、200 × 8% = 16 — クイックな税、チップ、割引の合計に便利です。二つの数の間のパーセンテージの変化には、当社のパーセンテージ計算機を使ってください。

仕組み — 従うルール

この計算機は、式全体を読み、標準の演算順序を使ってそれを計算します — 学校で教えられるのと同じルール：

1. 括弧を先に — ( ) の内側のものは、他のすべてのものの前に処理されます。
2. 累乗と根 — xʸ、x²、√ が次に来ます。冪は、右結合です：2^3^2 は、2^(3^2) = 512 を意味します。
3. 掛け算と割り算 — × と ÷ は、左から右に行われます。あなたは、2π や 2(3 + 4) のように、物事を並べて置くことにより、乗算を書くこともできます。
4. 足し算と引き算 — + と − は、最後に、左から右に行われます。

sin、log、ln のような関数は、括弧内の値に適用されます。log は底 10（log 1000 = 3）で、ln は自然対数、底 e です。n! ボタンは階乗を与えます — 5! = 5 × 4 × 3 × 2 × 1 = 120 — そして 0 から上の整数について機能します。

実例

例： 辺が 3 と 4 の直角三角形の最も長い辺を求めます。√(3² + 4²) と入力します：まず括弧 （9 + 16 = 25)、その後平方根 — 答えは 5。キーパッドで：√、3、x²、+、4、x²、) をタップし、次に = をタップします。

よくある質問

なぜ、sin(30) は、間違った答えを与えたのですか？

ほとんどの場合は角度モードです。計算機が RAD モードの場合、30 を 30 度ではなく 30 ラジアンとして扱います。DEG/RAD ボタンをタップして DEG を表示させ、もう一度お試しください。モードはキーパッドの左上のボタンに表示されます。

立方根またはその他の根を求めるにはどうすればよいですか？

分数の累乗を使います：27 の立方根は、27^(1/3) = 3 です。一般に、数 x の n 乗根は、x^(1/n) です。√ ボタンは、一般的な平方根のケースをカバーします。

この計算機は無料ですか、そして私の計算を保存しますか？

はい。それは、サインアップなしで、完全に無料です。すべては、あなた自身のブラウザで計算されます — あなたの表現は、決してサーバーに送られたり、保存されたりしません。
