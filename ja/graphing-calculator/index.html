📈 グラフ計算機

x の関数を入力します — 例えば x^2、sin(x)、2x+3、1/x — そして、そのグラフを即座に確認します。二つ目の関数を加えて比較し、ズームインまたはズームアウトして、切片、転換点、漸近線を探ります。

クイックな答え： グラフ計算機は、見える区間全体の数百の x の値について y を計算し、点を結ぶことで y = f(x) を描きます。これは x^2、sin(x)、cos(x)、tan(x)、sqrt(x)、log(x)、分数、2x のような暗黙の掛け算を理解します。

グラフ計算機の使い方

  1. 最初の関数を入力してください。たとえば x^2 - 4。
  2. 任意で、異なる色で比較するために二つ目の関数を入力します。
  3. プロットを押し、ズームイン／ズームアウト、または表示をリセットを使います。
  4. グリッドから切片と交差を読みます — 各正方形はデフォルトで 1 単位です。
例： x^2 - 4 をプロットすると、x = -2 と x = 2 で x 軸と交差する放物線が得られ、最低点は (0, -4)。線 2x+3 を加えると、曲線と線がどこで出会うかが表示されます。

よくある質問

どの式が使えますか？

数、x、+ − * / ^ と括弧、さらに sin、cos、tan、sqrt、abs、log（底 10）、ln、exp、定数 pi と e。暗黙の乗算も機能します：2x、3(x+1)、(x+1)(x-1) はすべて理解されます。

なぜ、1/x や tan(x) のグラフは、場所によって切れるのですか？

それらの関数は、漸近線で、非常に大きな正の値と負の値の間をジャンプします。プロッターは、そのジャンプを検出し、誤った縦の直線を描く代わりに、ペンを持ち上げます。

x の二乗または累乗を書くにはどうすればよいですか？

キャレットを使います：x^2 は x の二乗を意味し、x^3 は立方、x^0.5 は sqrt(x) と同じです。累乗は右結合です。そのため、2^3^2 は 2^(3^2) = 512 と読まれます。

グラフは、どの範囲を表示しますか？

それは x が −10 から 10、y が −10 から 10 で始まります。各ズームステップは範囲に約 0.7（イン）または 1.4（アウト）を掛けます。

仕組み — 公式

プロッターは、各式をトークン（数、x、演算子、関数）に解析し、暗黙の乗算記号を挿入し（2x → 2*x）、標準の演算順序を尊重する再帰下降パーサーでそれを評価します： ^ は、最も強く結合し、右に結合します。次に * と /、次に + と −、関数と括弧を先に処理します。次に、区間全体の 720 の x 位置で関数をサンプリングし、連続する有限の点を結び、関数が定義されない場所や漸近線を跳ぶ場所では隙間を空けます。

実例

入力： f(x) = x^2 − 4。

ステップ： x = 0 のとき、y = −4（最低の点）。x = 2 のとき、y = 4 − 4 = 0、そして x = −2 のとき、y = 0 — 二つの x 切片。x = 3 のとき、y = 9 − 4 = 5。

結果： 頂点 (0, −4) を持ち、x 軸と交わる放物線： −2 と 2、グラフに表示される通りです。
