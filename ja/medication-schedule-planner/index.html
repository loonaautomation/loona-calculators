💊 服薬スケジュールプランナー

複数の薬を異なる時刻に服用するのは、間違えやすいものです。下に各薬 — 用量、時刻、食事と一緒に服用するかどうか — を追加すると、このプランナーはそれらを1つの明確な毎日の時刻表に統合し、印刷できる服薬表、補充日、スマートフォンのカレンダーリマインダーを提供します。無料、登録不要、完全にプライベート：あなたのリストがブラウザの外に出ることはありません。

クイックな答え： 服薬スケジュールプランナーは、すべての薬を1つの毎日の時刻表に統合します：各薬、その用量と時刻 — X時間ごと、または決まった時刻 — を入力すると、統合された表を作成し、補充日を計算し、カレンダーリマインダーをエクスポートします。すべてはブラウザ内に留まります。

安全第一： このプランナーは、入力したスケジュールを整理するだけです — 医療アドバイスではなく、用量や薬の相互作用はチェックしません。処方箋に書かれた通りに正確に従い、不明な点があれば医師または薬剤師に相談してください。

🔒 プライバシー設計： あなたの薬はこのブラウザ内（ローカルストレージ）にのみ保存されるため、戻ってきたときにプランナーが覚えています。アップロードや送信は一切行われません。

服薬スケジュールプランナーの使い方

  1. 各薬を追加します：名前、用量（例：「500 mg — 1錠」）、そして服用頻度 — 最初の服薬時刻からX時間ごと、または毎日決まった時刻。
  2. 食事と一緒に服用しなければならない薬については「食事と一緒に服用」にチェックを入れ、補充日が必要な場合は手持ちの供給日数を入力します。
  3. 服用開始日と、不足する何日前に補充リマインダーを受け取るかを設定します。
  4. 「スケジュールを作成」を押します — すべての薬が1つの毎日の時刻表に統合され、印刷できる服薬表と、スマートフォンにインポートできるカレンダー（.ics）ファイルが得られます。
例： パラセタモールを06:00から8時間ごとに服用すると、06:00、14:00、22:00に服薬します。食事と一緒に服用する1日2回の薬を08:00と20:00に追加すると、プランナーはすべてを1つのリストに統合します — 1日5回の服薬時刻で、漏れも重複もありません。

よくある質問

これは医療アドバイスですか？

いいえ。このプランナーは、入力したスケジュールを整理するだけです。用量、組み合わせ、相互作用はチェックしません。処方箋に書かれた通りに正確に従い、不明な点があれば医師または薬剤師に相談してください。

補充日はどのように決まりますか？

補充日 = 開始日 + 供給日数 − リマインダー日数。11月18日に開始し、30日分の供給があり、3日前のリマインダーを設定した場合、プランナーは12月17日に不足し、12月15日までに補充を注文すべきだと知らせます。

ここで「8時間ごと」とはどういう意味ですか？

最初の服薬は選択した時刻で、その後は24時間、8時間ごとに服薬します — 例えば06:00、14:00、22:00です。深夜を過ぎる時刻は、同じ毎日の表の早朝の時間に繰り越されます。

私の薬のリストはどこかにアップロードされますか？

いいえ。すべてはご自身のブラウザ内（ローカルストレージ）にのみ保存されるため、プランナーはこのデバイスであなたの薬を覚えています。サーバーに送信されることはなく、「保存データを消去」でいつでも削除できます。

スケジュールをスマートフォンのカレンダーに入れられますか？

はい。「カレンダーファイル（.ics）をダウンロード」を押し、ファイルを Google カレンダー、Apple カレンダー、または Outlook にインポートしてください — すべての服薬が繰り返しリマインダーになり、補充日には補充リマインダーが追加されます。

仕組み — スケジュールの計算

X時間ごとの薬については、プランナーは最初の服薬時刻から始めて、丸24時間をカバーするまでX時間を繰り返し加えます；深夜を過ぎる時刻は早朝の時間に繰り越され、リストは時計順に並べ替えられます。決まった時刻の薬については、入力した時刻をそのまま使用し、並べ替えて重複を取り除きます。その後、すべての薬は時刻をキーとして1つの時刻表に統合されます — 2つの薬が同じ時刻になる場合は1行を共有するため、何も隠されず、二重に数えられることもありません。

補充の計算は次の通りです：最後のカバー日 = 開始日 + 供給日数 − 1、補充日 = 開始日 + 供給日数 − リマインダー日数。カレンダー（.ics）エクスポートは、各パターンを標準の繰り返しイベントに変換します — X時間ごとの薬は毎時繰り返し、決まった時刻の薬は毎日繰り返し — 最後のカバー日で終了し、補充日の09:00に補充リマインダーイベントが1つ追加されます。

計算例

入力： 薬Aは8時間ごと、初回06:00。薬Bは決まった時刻08:00と20:00、食事と一緒に。開始日2026年11月18日、両方とも30日分の供給、補充リマインダー3日。

手順： Aは06:00、14:00、22:00。Bは08:00と20:00。統合：06:00 A · 08:00 B（食事と一緒に）· 14:00 A · 20:00 B（食事と一緒に）· 22:00 A — 1日5回。最後のカバー日 = 11月18日 + 29日 = 2026年12月17日。補充日 = 11月18日 +（30 − 3）日 = 2026年12月15日。

結果： 5回の服薬時刻の毎日の時刻表、7日間のチェック表、2026年12月15日までの補充、同じイベントの.icsファイル。

健康に関する免責事項： このプランナーは整理を助けるツールにすぎず、医療アドバイス、診断、治療ではありません。用量、タイミング、組み合わせが安全で正しいかどうかは検証しません。処方箋に常に従い、ご自身の薬については資格のある医療専門家に相談してください。
