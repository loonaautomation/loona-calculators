👥 標本サイズ計算機

あなたが調査を実行する前に、必要な標本の大きさを計算します：信頼水準と、許容できる誤差の範囲が与えられた、割合（世論調査のような）や平均を推定するために — 小さい母集団のための、任意の修正と共に。

クイックな答え： 比率が信頼度 95%、誤差 ±5% で、安全な p = 0.5 を使う場合：n = 1.96² × 0.25 ÷ 0.05² = 384.16。そのため 385 の回答が必要です。それは研究方法で最も引用されるサンプルサイズの結果です。

サンプルサイズ計算機の使い方

  1. 比率か平均を選びます。
  2. 比率では、予想される比率を入力してください（不明な場合は 0.5 を使います — それが最大で最も安全な標本を与えます）。
  3. 誤差範囲（比率の場合は小数として入力：0.05 = ±5 ポイント）と信頼水準を入力してください。
  4. 任意で、有限母集団の補正を適用するために母集団のサイズを入力します。
例： 有権者 2,000 人の町、信頼度 95%、±5%：未修正の n は 385 です。有限母集団修正を適用すると、n = 385 ÷ (1 + 384 ÷ 2000) ≈ 323 人の有権者が実際に必要です。

よくある質問

なぜ、p = 0.5 は、最大の標本を与えるのですか？

分散 p(1−p) は、p = 0.5 で最大化されます。本当の比率が 0.5 に近い場合、最も多くのデータが必要です；それが 0.1 または 0.9 に近いと知っている場合、より小さい標本が、同じマージンを達成します。

有限母集団修正とは何ですか？

あなたの標本が、有限母集団の注目すべき割合である場合、交換なしの標本抽出は、無限母集団の公式が想定するより正確です。修正 n_adj = n ÷ (1 + (n − 1) ÷ N) は、小さい母集団のための必要な標本を減らします。

誤差範囲はコストとどのようにトレードオフしますか？

誤差を半分にすると標本は四倍になります：±5% には 385、±2.5% には約 1,537、±1% には約 9,604 が必要です（すべて 95%、p = 0.5 で）。精度は二乗で買われます。

人口が大きいと、より大きな標本が必要ですか？

人口が大きい場合はほとんど変わりません — 200 百万人の国は、同じ誤差範囲に対して 200,000 人の都市とほぼ同じ 385 人を必要とします。サンプルサイズは、要求する誤差範囲によって決まり、人口サイズではありません。

仕組み — 公式

比率： n = z² × p(1 − p) ÷ E²、切り上げ。 平均： n =（z × σ ÷ E）²、切り上げ。 有限母集団の補正： n_adj = n ÷（1 +（n − 1）÷ N）、切り上げ。z は、信頼水準（1.645／1.960／2.576）から来ます。

実例

入力： 割合、p = 0.5、E = 0.05、95%（z = 1.96）。

ステップ： n = 1.96² × 0.5 × 0.5 ÷ 0.05² = 3.8416 × 0.25 ÷ 0.0025 = 0.9604 ÷ 0.0025 = 384.16 → 切り上げて 385。母集団が 2,000 の場合：385 ÷ (1 + 384 ÷ 2000) = 385 ÷ 1.192 = 322.99 → 323。平均の確認：σ = 15、E = 5 → (1.96 × 15 ÷ 5)² = 5.88² = 34.57 → 35.

結果： 385（人口 2,000 の町では 323）。平均のケースでは 35。
