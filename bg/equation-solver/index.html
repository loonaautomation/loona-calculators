Решаващ на уравнения (Линейни и Квадратни)

Решавайте линейни уравнения (ax + b = cx + d) и квадратни уравнения (ax² + bx + c = 0) с всяка показана стъпка — включително дискриминантата, повтарящите се и комплексните корени и крайна проверка, която замества отговора обратно.

Въведете четирите числа в ax + b = cx + d. Използвайте 0, където липсва член — например 2x + 3 = 7 е a = 2, b = 3, c = 0, d = 7.

Въведете трите коефициента в ax² + bx + c = 0. Използвайте 0, където липсва член — например x² − 9 = 0 е a = 1, b = 0, c = −9.

Как да използвате инструмента за решаване на уравнения

  1. Изберете типа уравнение: линейно (само x) или квадратно (x²).
  2. Въведете коефициентите — числата пред x² и x и обикновеното число. Въведете 0 за всеки липсващ член.
  3. Натиснете „Реши със стъпки“ и прочетете решението ред по ред. Последната стъпка проверява отговора, като го замества обратно в първоначалното уравнение.
Пример: 3x + 2 = x + 10. Преместете членовете с x наляво: 2x + 2 = 10. Преместете числото надясно: 2x = 8. Разделете на 2: x = 4. Проверка: 3 × 4 + 2 = 14 и 4 + 10 = 14 ✓

Често задавани въпроси

Какви видове уравнения може да обработва този решател?

Линейни уравнения във вида ax + b = cx + d и квадратни уравнения във вида ax² + bx + c = 0. Показва всяка стъпка, дискриминантата за квадратните уравнения и крайна проверка. Не решава кубични уравнения, системи от уравнения с две неизвестни или неравенства — заглавието на страницата казва точно какво покрива.

Какво означава „няма решение“ или „безкрайно много решения“?

Понякога членовете с x се съкращават напълно. Ако числата също съвпадат (като 5x + 1 = 5x + 1), уравнението винаги е вярно — безкрайно много решения. Ако числата не съвпадат (5x + 1 = 5x + 3), то никога не може да бъде вярно — няма решение. Решаващият инструмент ви казва честно кой случай имате, вместо да измисля отговор.

Какво са комплексните корени?

Когато дискриминантата на квадратно уравнение (b² − 4ac) е отрицателна, графиката никога не пресича оста x и няма реални отговори. Тогава корените са комплексни числа, използващи i, където i² = −1 — например x² + 1 = 0 има корени x = i и x = −i. Този решавател ги показва и все пак ги проверява.

Как работи — методът

Линейни уравнения се решават, като уравнението се поддържа балансирано — каквото направите на едната страна, правите и на другата. Първо членовете с x се събират отляво (изваждате cx от двете страни), след това числовите членове отдясно (изваждате b), и накрая двете страни се делят на коефициента на x.

Квадратни уравнения използвайте квадратната формула. За ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

Частта под корена, D = b² − 4ac, се нарича дискриминанта и ви казва вида на отговора, преди да сте завършили: D > 0 означава два различни реални корена, D = 0 означава един повтарящ се корен, а D < 0 означава два комплексни корена и никакъв реален отговор.

Разработен пример

Пример: Решете x² − 5x + 6 = 0. Тук a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, така че √D = 1. Тогава x = (5 + 1) ÷ 2 = 3 или x = (5 − 1) ÷ 2 = 2. Проверка x = 3: 9 − 15 + 6 = 0 ✓

Често задавани въпроси

Как да въведа уравнение с липсващ член?

Въведете 0 за липсващия коефициент. x² − 9 = 0 става a = 1, b = 0, c = −9 и решаващият дава x = 3 или x = −3. За линейно уравнение като 2x = 10, това е a = 2, b = 0, c = 0, d = 10.

А ако въведа a = 0 в решателя за квадратни уравнения?

Тогава членът x² изчезва и уравнението всъщност е линейно. Решавателят забелязва това и го решава като линейно уравнение вместо това, като ви казва, че това се е случило.

Защо решавателят проверява отговора си накрая?

Заместването на отговора обратно в първоначалното уравнение е най-сигурният начин да хванете грешка: ако двете страни излязат равни, отговорът със сигурност е верен. Това е добър навик и за домашните — учителите често дават точки за метод при видима проверка.
