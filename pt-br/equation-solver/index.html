Equação Solver (Linear & Quadrática)

Resolva equações lineares (ax + b = cx + d) e equações quadráticas (ax² + bx + c = 0) com todos os passos apresentados — incluindo o discriminante, as raízes repetidas e complexas, e uma verificação final que substitui a resposta de volta.

Digite o quatro números em ax + b = cx + d. Use 0 onde falta um termo — por exemplo, 2x + 3 = 7 é a = 2, b = 3, c = 0, d = 7.

Digite o três coefficients em ax² + bx + c = 0. Use 0 onde falta um termo — por exemplo, x² − 9 = 0 é a = 1, b = 0, c = −9.

Como utilizar o Solucionador de Equações

  1. Escolha o tipo de equação: linear (apenas x) ou quadrática (x²).
  2. Escreva os coeficientes — os números à frente de x² e de x, e o número simples. Digite 0 para qualquer termo em falta.
  3. Pressione Resolver com passos e leia o cálculo linha a linha. O último passo verifica a resposta substituindo-a de volta na equação original.
Exemplo: 3x + 2 = x + 10. Mover os termos em x para a esquerda: 2x + 2 = 10. Mover o número para a direita: 2x = 8. Dividir por 2: x = 4. Verificação: 3 × 4 + 2 = 14 e 4 + 10 = 14 ✓

Frequently Asked Perguntas

Que tipos de equações consegue resolver este solucionador?

Equações lineares na forma ax + b = cx + d, e equações quadráticas na forma ax² + bx + c = 0. Mostra todos os passos, o discriminante para as quadráticas e uma verificação final. Não resolve equações cúbicas, sistemas de equações a duas incógnitas nem inequações — o título da página diz exatamente o que abrange.

O que significa "sem solução" ou "infinitas soluções"?

Por vezes, os termos em x anulam-se por completo. Se os números também coincidirem (como 5x + 1 = 5x + 1), a equação é sempre verdadeira — infinitas soluções. Se os números não coincidirem (5x + 1 = 5x + 3), nunca pode ser verdadeira — sem solução. O solucionador indica honestamente qual é o caso, em vez de inventar uma resposta.

O que são raízes complexas?

Quando o discriminante de uma quadrática (b² − 4ac) é negativo, o gráfico nunca cruza o eixo x e não há respostas reais. As raízes são então números complexos com i, onde i² = −1 — por exemplo, x² + 1 = 0 tem raízes x = i e x = −i. Este solucionador mostra-as e continua a verificá-las.

Como funciona — o método

Equações lineares resolvem-se mantendo a equação equilibrada — o que fizer a um membro, faz ao outro. Primeiro, juntam-se os termos em x à esquerda (subtrai-se cx de ambos os membros), depois os termos numéricos à direita (subtrai-se b), e por fim dividem-se ambos os membros pelo coeficiente de x.

Equações quadráticas usa-se a fórmula quadrática. Para ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

A parte sob a raiz, D = b² − 4ac, chama-se discriminante, e indica o tipo de resposta antes de terminar: D > 0 significa duas raízes reais diferentes, D = 0 significa uma raiz repetida, e D < 0 significa duas raízes complexas e nenhuma resposta real.

Exemplo prático

Exemplo: Resolver x² − 5x + 6 = 0. Aqui a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, pelo que √D = 1. Depois x = (5 + 1) ÷ 2 = 3 ou x = (5 − 1) ÷ 2 = 2. Verifique x = 3: 9 − 15 + 6 = 0 ✓

Frequently asked perguntas

Como se insere uma equação com um termo em falta?

Digite 0 para missing coefficient. x² − 9 = 0 becomes = 1, b = 0, c = −9, e solver dá x = 3 ou x = −3. Para linear equação like 2x = 10, esse é = 2, b = 0, c = 0, d = 10.

E se escrever a = 0 no solucionador quadrático?

Então, o termo x² desaparece e a equação é, na realidade, linear. O solucionador nota isso e resolve-a como uma equação linear, dizendo que foi isso que aconteceu.

Porque é que o solucionador verifica a sua resposta no fim?

Substituir a resposta de volta na equação original é a forma mais segura de detetar um erro: se ambos os lados forem iguais, a resposta está certamente certa. Também é um bom hábito para os trabalhos de casa — os professores atribuem frequentemente pontos pelo método quando a verificação é visível.
