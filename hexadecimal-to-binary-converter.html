Convert hexadecimal (base 16) numbers to binary (base 2) instantly, with digit validation, a worked place-value example and a reference table.

How to convert hexadecimal to binary

Step 1 — value: expand the hexadecimal number by place values to get its decimal value. Step 2 — re-base: divide that value by 2 again and again, collecting remainders, and read them in reverse.

Worked example: FF (hexadecimal) → binary

Step 1: F×161 = 240 + F×160 = 15 → total 255 (decimal). FF is full intensity of one colour channel.

Step 2: 255 written in base 2 is 11111111.

Result: FF (hexadecimal) = 11111111 (binary).

Hexadecimal groups binary digits in fours and is everywhere in computing: colours (#FF5733), MAC addresses, memory addresses and hex editors.

Binary is the language of computers: every file, photo and program is stored as binary digits (bits). Eight bits make a byte.

Frequently Asked Questions

How do I convert hexadecimal to binary by hand?

First find the decimal value using place values (each digit is worth its face value times the base raised to its position), then divide by 2 repeatedly, reading the remainders upwards. The worked example on this page shows both steps for FF.

What is FF (hexadecimal) in binary?

FF in hexadecimal is 11111111 in binary. FF is full intensity of one colour channel.

Which digits are allowed in hexadecimal?

Only these 16: 0123456789ABCDEF. Letters A–F stand for the values 10–15.

Where is hexadecimal used?

Hexadecimal groups binary digits in fours and is everywhere in computing: colours (#FF5733), MAC addresses, memory addresses and hex editors.

How do I convert binary back to hexadecimal?

Use the binary to hexadecimal converter — the process is the same, in the other direction.
