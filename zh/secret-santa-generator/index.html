🎅 秘密圣诞老人生成器

添加每个人的名字，添加任何排除项（例如不应互相抽到的伴侣），然后运行抽签。没有人能看到完整列表——每个人选择自己的名字，私下只揭示他们为谁购买。

快速答案： 秘密圣诞老人抽签是一种随机配对，每个人送出一份礼物并收到一份礼物，没有人被配对到自己，完整列表保持秘密：每个人只揭示自己的配对。

私下揭晓 — 每次一人

如何使用秘密圣诞老人生成器

  1. 输入所有名字，每行一个（至少 3 人）。
  2. 可选择添加排除项，每行一个，格式为 Name1, Name2——这两个人不会在任何方向上配对。
  3. 按“开始抽奖”。
  4. 每个人在揭晓框中选择自己的名字，只能看到自己的配对结果。揭晓时请保持屏幕私密。
示例： 五位朋友——Ali、Sara、John、Maria、Chen——排除组合为 Ali, Sara：抽签总是让每个人恰好为一个人购买礼物，没有人抽到自己，Ali 和 Sara 永不互相抽到。

常见问题

排除项如何运作？

将一对输入为同一行上的 Name1, Name2。抽签绝不会在任何方向上配对这两个人——对情侣或去年的配对很有用。名字必须与主清单中完全一致地拼写。

抽奖会变得不可能吗？

是的——如果人数太少而排除项太多，可能不存在有效的配对。工具会如实告知，而不是勉强给出糟糕的抽签结果；请减少一个排除项或增加一个人。

结果会被存储或发送到任何地方吗？

不是。抽奖完全在您的浏览器中进行，不会上传任何内容。如果您关闭页面，抽奖即消失——这正是保密的意义。

私密揭晓如何运作？

抽签后，一个下拉菜单列出每个名字。每个人选择自己的名字并按 Reveal，只查看自己的收礼人。组织者永远不需要看到整个列表。

工作原理 — 公式

有效的抽签是一个 带禁配对的错排：一个名字的排列，其中没有人映射到自己，被排除的配对也不会以任一方向映射。生成器首先尝试洗牌排列（对普通群体很快），如果随机尝试一直失败，它会切换到确定性的 回溯搜索 它要么找到有效的抽签结果，要么证明不存在——它从不默默违反规则。

示例

输入项： 5 个名字，排除 Ali–Sara。

步骤： 工具可以生成的一个有效抽签：Ali → John，John → Maria，Maria → Chen，Chen → Sara，Sara → Ali。检验：五位赠送者，五位不同的接收者，没有人抽到自己，Ali 和 Sara 没有互相抽到。

结果： 每条规则都得到满足，每个人在揭晓时只能看到自己的一行。
