📉 斜率计算器

输入两个点 (x₁, y₁) 和 (x₂, y₂)，即可获得关于它们之间直线的全部信息：斜率、距离、中点、角度以及方程 y = mx + b——并展示每个公式的代入过程。

快速答案： 斜率 = (y₂ − y₁) ÷ (x₂ − x₁)。对于 (1, 2) 和 (4, 8)：斜率 = 6 ÷ 3 = 2，距离 = √(3² + 6²) = √45 ≈ 6.71，中点为 (2.5, 5)。

如何使用 Slope Calculator

  1. 输入第一个点的坐标。
  2. 输入第二个点的坐标。
  3. 读取斜率、距离、中点和直线方程。
示例： 点 (1, 2) 和 (4, 8)：斜率为 2，距离为 √45 ≈ 6.708，中点为 (2.5, 5)，直线方程为 y = 2x + 0——它经过原点，您可以验证：当 x = 1 时，y = 2 ✓。

常见问题

斜率为 2 是什么意思？

每向右移动 1 个单位，直线上升 2 个单位。斜率为 0 是平坦的，负斜率向右下降，未定义的斜率（除以零）是垂直线。

两点之间的距离是如何计算的？

使用毕达哥拉斯：距离 = √((x₂ − x₁)² + (y₂ − y₁)²)。坐标差是直角三角形的两条直角边，距离是它的斜边。

什么是中点公式？

平均坐标：中点 = ((x₁ + x₂) ÷ 2, (y₁ + y₂) ÷ 2)。它正是线段正中间的点。

如果两个 x 值相同怎么办？

这条线是垂直的：斜率未定义，没有 y = mx + b 方程。计算器报告垂直线 x = 该值，外加正常的距离和中点。

工作原理 — 公式

斜率： m = (y₂ − y₁) ÷ (x₂ − x₁). Distance： d = √((x₂ − x₁)² + (y₂ − y₁)²). 中点： ((x₁ + x₂) ÷ 2, (y₁ + y₂) ÷ 2). 直线方程： 使用点1，b = y₁ − m·x₁，得到y = mx + b。 角度： θ = arctan(m)，以度为单位，从x轴正方向量起。

示例

输入项： (1, 2) 和 (4, 8)。

步骤： 斜率 = (8 − 2) ÷ (4 − 1) = 6 ÷ 3 = 2。距离 = √((4−1)² + (8−2)²) = √(9 + 36) = √45 = 6.708。中点 = ((1+4)÷2, (2+8)÷2) = (2.5, 5)。截距：b = 2 − 2×1 = 0，因此直线为 y = 2x。

结果： 斜率 2，距离 6.708，中点 (2.5, 5)，方程 y = 2x.
