如何将比特转换为字节

公式： 字节 = 比特 × 0.125。

十进制单位（KB、MB、GB、TB）遵循存储制造商和 macOS 使用的 SI 定义：1 KB = 1,000 字节。二进制单位（KiB、MiB）遵循 IEC 80000-13：1 KiB = 1,024 字节——这一差距就是为什么一块 '500 GB' 硬盘在 Windows 中显示约为 465 GiB。

示例

问题： 8000000 bit（1 MB 照片中的比特数）等于多少字节？

步骤： 取以比特计的值：8000000 bit。应用上方的公式。得到 1000000 B.

结果： 8000000 bit = 1000000 B.

关于这个换算对值得了解的内容

字节： 一个字节大约容纳一个纯文本字符；一封简短的电子邮件约为 2,000 字节。

比特： 网速以比特每秒（Mbps）出售，文件大小以字节计——8 比特构成一个字节，因此将 Mbps 除以 8 即可得到 MB/s。
