📐 勾股定理计算器

输入直角三角形的任意两条边，计算器会使用勾股定理求出第三条边，并展示完整的代入过程，以便学生跟上每一步。

快速答案： 勾股定理说，对于直角三角形 a² + b² = c²，其中 c 是斜边。经典例子是 3-4-5：9 + 16 = 25，因此斜边是 5。

如何使用 Pythagorean Theorem Calculator

  1. 输入您知道的两条边（将未知边留空，或设为 0）。
  2. 如果您知道斜边，请将其输入为 c。
  3. 按“计算”——缺失的边和完整的演算过程随即出现。
示例： 直角边 6 和 8：c = √(36 + 64) = √100 = 10。当斜边为 13、一条直角边为 5 时：另一条直角边 = √(169 − 25) = √144 = 12。

常见问题

哪一边是斜边？

直角对面的边——始终是最长的边，这里标记为 c。其他两条边（直角边）是 a 和 b。

如何求一条直角边而不是斜边？

重新整理定理：a = √(c² − b²)。斜边必须比任何一条直角边都长；如果不是，该三角形就不可能是边长如此的直角三角形，计算器会说明这一点。

它适用于非直角三角形吗？

不是。该定理仅对直角三角形成立。对于其他三角形，您需要余弦定律——本站的 Trigonometry Calculator 可以帮助处理角度和比值。

为什么 3-4-5 三角形到处出现？

因为 3² + 4² = 5² 恰好成立，建筑商和木匠几千年来一直使用 3-4-5 绳索或卷尺来标记真正的直角。其他整数三元组包括 5-12-13、8-15-17 和 7-24-25。

工作原理 — 公式

a² + b² = c². 求斜边：c = √(a² + b²)。求一条直角边：a = √(c² − b²) 或 b = √(c² − a²)。必须恰好给出两条边；第三条边是推导出来的，只有当斜边是最长边时才能求出直角边。

示例

输入项： 斜边c = 13，直角边a = 5，求b。

步骤： b = √(c² − a²) = √(169 − 25) = √144 = 12.

结果： b = 12 ——5-12-13三元组。
