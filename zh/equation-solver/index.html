方程求解器（线性 & 二次）

求解线性方程 (ax + b = cx + d) 和二次方程 (ax² + bx + c = 0)，显示每一步——包括判别式、重根和复根，以及将答案代回的最终检验。

输入这四个数字，在 ax + b = cx + d。缺项处使用 0——例如，2x + 3 = 7 即 a = 2，b = 3，c = 0，d = 7。

输入这三个系数，在 ax² + bx + c = 0。缺项处使用 0——例如，x² − 9 = 0 即 a = 1，b = 0，c = −9。

如何使用方程求解器

  1. 选择方程类型：线性（仅 x）或二次（x²）。
  2. 输入系数——x² 和 x 前面的数字，以及纯数字。任何缺失项输入 0。
  3. 按“带步骤求解”，逐行阅读演算过程。最后一步将答案代回原方程进行验证。
示例： 3x + 2 = x + 10。将 x 项移到左侧：2x + 2 = 10。将数字移到右侧：2x = 8。两边除以 2： x = 4。检验：3 × 4 + 2 = 14 且 4 + 10 = 14 ✓

常见问题

本求解器能处理什么类型的方程？

形式为 ax + b = cx + d 的线性方程，以及形式为 ax² + bx + c = 0 的二次方程。它显示每一步、二次方程的判别式，以及最后的检验。它不求解三次方程、二元联立方程或不等式——页面标题确切说明了它的涵盖范围。

“无解”或“无穷多解”是什么意思？

有时 x 项会完全抵消。如果数字也匹配（如 5x + 1 = 5x + 1），方程恒为真——有无穷多解。如果数字不匹配（5x + 1 = 5x + 3），它就永不为真——无解。求解器会诚实地告诉您属于哪种情况，而不是捏造答案。

什么是复数根？

当二次方程的判别式（b² − 4ac）为负时，图形从不与 x 轴相交，没有实数答案。根是使用 i 的复数，其中 i² = −1——例如，x² + 1 = 0 的根为 x = i 和 x = −i。本求解器显示它们并仍会检查它们。

工作原理——方法

线性方程 的解法是保持方程平衡——对一边做的操作，也要对另一边做。先把x项集中到左侧（两边减cx），再把数字项集中到右侧（减b），最后两边除以x的系数。

二次方程 使用求根公式。对于ax² + bx + c = 0：

x = (−b ± √(b² − 4ac)) ÷ (2a)

根号下的部分， D = b² − 4ac，称为判别式，它在你完成计算之前就告诉你答案的类型：D > 0 表示两个不同的实根，D = 0 表示一个重根，D < 0 表示两个复根且没有实数解。

示例

示例： 求解 x² − 5x + 6 = 0。这里 a = 1，b = −5，c = 6。D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1，因此 √D = 1。然后 x = (5 + 1) ÷ 2 = 3 or x = (5 − 1) ÷ 2 = 2。检验 x = 3：9 − 15 + 6 = 0 ✓

常见问题

我如何输入缺少一项的方程？

对于缺失的系数输入 0。x² − 9 = 0 变为 a = 1、b = 0、c = −9，求解器给出 x = 3 或 x = −3。对于像 2x = 10 这样的线性方程，则是 a = 2、b = 0、c = 0、d = 10。

如果我在二次方程求解器中输入 a = 0 怎么办？

那么 x² 项消失，方程实际上是线性的。求解器注意到这一点，并改为作为线性方程求解它，告诉您发生了什么。

为什么求解器在最后检查其答案？

将答案代回原方程是发现错误最可靠的方法：如果两边相等，答案肯定正确。这对家庭作业也是一个好习惯——老师通常会为可见的检验给出方法分。
