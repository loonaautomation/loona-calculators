如何使用世界时钟

  1. 打开页面——无需输入。
  2. 在网格中找到您的城市；时间和日期每秒更新。
  3. 使用每个城市下方的偏移行将其与您自己的当地时间进行比较。
示例： 在 2026 年一月 15 日 12:00:00 UTC，时钟显示 London 12:00、Karachi 17:00、Dubai 16:00、New York 07:00 和 Tokyo 21:00——同一时刻，五个不同的本地时间。

常见问题

世界时钟如何保持准确？

它每秒读取一次您设备的时钟，并使用浏览器内置的 Intl API 将该时刻转换为每个城市的 IANA 时区。时区规则（包括夏令时）来自操作系统使用的同一数据库。

为什么另一个城市的日期可以不同？

因为日期边界位于城市之间：当 Auckland 是清晨时，Los Angeles 仍是前一天下午。因此每张卡片都显示该城市自己的日期以及其时间。

这与 Loona Hours 上的时区转换器相同吗？

不是。那个工具在两个时区之间转换一个选定的时间。本页是一眼看到 24 个城市当前时间的实时面板。本站现有的 Time Calculator 则加减时长——又是不同的工作。

如果时间看起来不对怎么办？

先检查你的设备时钟——换算是精确的，但起点是你设备当前时刻。浏览器从你的操作系统获取时区规则，因此请保持系统更新。

工作原理 — 公式

每张卡片都将一个瞬间——来自您设备的当前时间——转换为一个时区，使用内置的 Intl.DateTimeFormat API 和 IANA 时区名称（例如 Asia/Karachi)。每个时区显示的 UTC 偏移量是该时区在该日期实际采用的偏移，因此夏令时和冬令时偏移（夏令时）会自动应用。 当地时间 = UTC 时刻 + 该时区在该日期的偏移。

想换算的是某个具体时刻？那么 Loona 开发者工具上的时间戳转换器 将Unix时间戳转换为人类可读的日期并可反向转换——本站有意不重复提供该功能。

示例

时刻： 2026 年一月 15 日，12:00:00 UTC。

步骤： 伦敦一月实行 GMT（UTC+0）→ 12:00。卡拉奇全年为 UTC+5 → 17:00。迪拜为 UTC+4 → 16:00。纽约一月实行 EST（UTC−5）→ 07:00。东京为 UTC+9 → 21:00。

结果： 一个时刻显示为 12:00 / 17:00 / 16:00 / 07:00 / 21:00 遍布五个城市。
