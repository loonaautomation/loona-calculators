❤️ 目标心率计算器

输入您的年龄和静息心率，使用 Karvonen 公式获得您的估计最大心率和五个训练区，该公式利用您的心率储备来个性化训练区。

快速答案： 最大心率估算为 220 − 年龄。给定强度的 Karvonen 目标为静息心率 + 强度 ×（最大心率 − 静息心率）。对于一名静息心率为 60 的 40 岁人士，2 区（60–70%）为 132–144 bpm。

如何使用 Target Heart Rate Calculator

  1. 输入您的年龄。
  2. 输入您的静息心率——在早上起床前测量，数整整一分钟的心跳。
  3. 读取您的五个区间：恢复、燃脂耐力、有氧、阈值和最大努力。
示例： 年龄 40，静息心率 60：最大心率 = 180，心率储备 = 120。区间 2 在 60–70% 强度下 = 60 + 0.60×120 到 60 + 0.70×120 = 每分钟 132–144 次。

常见问题

什么是 Karvonen 公式？

目标心率 = 静息心率 + 强度 ×（最大心率 − 静息心率）。括号中的项是您的心率储备——您的心脏实际能工作的范围——这就是 Karvonen 区间与最大心率简单百分比不同的原因。

220 − 年龄有多准确？

这是总体估算，对个体的典型误差约为 ±10–12 bpm。Tanaka 公式（208 − 0.7 × 年龄）与研究数据的拟合略好；本页显示两种最大估值，并基于经典的 220 − 年龄构建区间，使结果与大多数健身房图表一致。

哪个区间燃烧脂肪？

较低的区间使用更高比例的脂肪作为燃料，但总卡路里对减重更重要。2 区（约 60–70%）是经典的可持续耐力区间，用于大部分训练量。

我应该以最大心率训练吗？

第5区适合健康且受过训练的人进行短时高强度间歇训练。如果你有任何心脏疾病、症状或健康疑虑，在进行高强度训练前请咨询医生。本页是教育指南，不是医疗建议。

工作原理 — 公式

最大心率 ≈ 220 − 年龄 (Tanaka 替代公式：208 − 0.7 × 年龄)。 心率储备 (HRR) = 最大 HR − 静息 HR。 Karvonen 目标 = 静息心率 + 强度 × 心率储备。 区间：第1区 = HRR的50–60%，第2区 = 60–70%，第3区 = 70–80%，第4区 = 80–90%，第5区 = 90–100%。

示例

输入项： 年龄40岁，静息心率60 bpm。

步骤： 最大心率 = 220 − 40 = 180。心率储备 = 180 − 60 = 120。2 区下限 = 60 + 0.60 × 120 = 132；2 区上限 = 60 + 0.70 × 120 = 144。Tanaka 最大估值 = 208 − 0.7 × 40 = 180——此处相同。

结果： 第2区 = 132–144 bpm，最大 HR 180 bpm.
