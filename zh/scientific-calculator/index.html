🧮 科学计算器

一个在浏览器中的完整科学计算器：三角函数及其反函数、对数、幂和根、阶乘和百分比——带 DEG/RAD 角度模式和完整的键盘支持。

点击 DEG/RAD 切换角度模式。您的键盘也可以使用——输入表达式并按 Enter。

如何使用 Scientific Calculator

  1. 点击按钮，或直接用键盘输入，来构建您的表达式——例如 sin(30) + 2^3。
  2. 在使用 sin、cos 或 tan 之前，使用 DEG/RAD 按钮选择角度的测量方式。
  3. 按 =（或 Enter）查看答案。您可以继续用答案进行计算，或按 AC 重新开始。
示例： 在DEG模式下sin(30) = 0.5，2^3^2 = 512，因为幂运算从右先算（3² = 9，然后2⁹ = 512）。

常见问题

DEG 和 RAD 有什么区别？

DEG 以度衡量角度（一整圈为 360°），RAD 以弧度衡量（一整圈为 2π）。学校和日常数学通常用度；高等数学和科学则常用弧度。使用 sin、cos 或 tan 前务必检查模式——在 DEG 模式下 sin(30) 为 0.5，而在 RAD 模式下约为 −0.988。

我如何计算像 5 的立方这样的幂？

点击 5，然后点击 xʸ 按钮，再点击 3，然后点击 =。您也可以用键盘输入 5^3。x² 按钮是一个快捷方式，可将它前面的数字平方。

% 按钮做什么？

它将前面的数字除以 100，因此 50% 变为 0.5，8% 变为 0.08。例如，200 × 8% = 16——便于快速计算税款、小费和折扣。如需计算两个数字之间的百分比变化，请使用我们的 Percentage Calculator。

工作原理——它遵循的规则

本计算器读取您的整个表达式并使用标准运算顺序计算它——与学校教授的规则相同：

1. 先算括号 ——（ ）内的内容先于一切计算。
2. 幂与根 —— xʸ、x²和√接下来。幂是右结合的：2^3^2表示2^(3^2) = 512。
3. 乘法和除法 —— ×和÷从左到右计算。你也可以把量并排写来表示乘法，如2π或2(3 + 4)。
4. 加法和减法 —— +和−最后计算，从左到右。

sin、log 和 ln 等函数适用于其括号中的值。log 是以 10 为底（log 1000 = 3），ln 是自然对数，以 e 为底。n! 按钮给出阶乘——5! = 5 × 4 × 3 × 2 × 1 = 120——适用于从 0 开始的整数。

示例

示例： 求边长为 3 和 4 的直角三角形的最长边。输入 √(3² + 4²)：先算括号 (9 + 16 = 25)，然后开平方根——答案是 5。在键盘上：依次点击 √、3、x²、+、4、x²、)，然后 =。

常见问题

为什么 sin(30) 给出错误的答案？

几乎总是角度模式。如果计算器处于 RAD 模式，它会将 30 视为 30 弧度，而不是 30 度。点击 DEG/RAD 按钮使其显示 DEG，然后再试一次。该模式显示在键盘左上角的按钮上。

我如何求立方根或其他根？

使用分数幂：27 的立方根是 27^(1/3) = 3。一般来说，数字 x 的 n 次根是 x^(1/n)。√ 按钮涵盖常见的平方根情况。
