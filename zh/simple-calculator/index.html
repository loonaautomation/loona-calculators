    如何使用简单计算器

    1. 点击数字按钮（或在键盘上输入）以输入第一个数字。
    2. 点击 + − × 或 ÷，然后输入第二个数字。您可以继续连锁计算——2 + 3 + 4 会在进行时逐步计算每一步。
    3. 按 = 查看答案。再次按 = 可重复上一次运算，点击复制结果可复制答案，或点击历史记录带上的任意一行以重新使用之前的答案。
    4. 输错了？⌫ 删除最后一位数字，C 只清除您正在输入的数字，AC 清除一切。

    常见问题

    % 按钮做什么？

    它将前面的数字除以 100，因此 50% 变为 0.5，10% 变为 0.1。例如，200 × 10% = 20——便于快速计算折扣、小费和税款。如需计算两个数字之间的百分比变化，请使用我们的 Percentage Calculator。

    历史记录功能如何运作？

    每次您按下 =，已完成的计算就会添加到计算器下方的记录带中，就像旧式加法机上的纸卷一样。点按记录带上的任意一行即可取回其答案并继续用它计算，使用清除历史记录可清空记录带。记录带只存在于您浏览器中的此页面——任何内容都不会发送到服务器或存储在服务器上。

    我可以使用键盘吗？

    是的。数字键和.用于输入数字，+ − * /选择运算，Enter或=完成计算，%表示百分号，Backspace删除最后一位数字，Delete清除当前输入，Escape清除全部。

    什么是简单计算器？

    一个简单的计算器——也称为基本或四功能计算器——执行四种日常运算：加法、减法、乘法和除法，通常带百分键。它是大多数人大多数时候真正需要的计算器：合计购物账单、分摊餐厅支票、检查家庭作业、计算找零或合计一天的开支。这个计算器还添加了人们在手机计算器上缺少的东西：易于点按的大按钮、可以检查每个步骤的历史带，以及桌面上合适的键盘布局。

    键盘快捷键

    • 0–9 和 . ——输入一个数字
    • + − * / ——加、减、乘、除
    • 输入 或 = ——完成计算（再按一次可重复）
    • % ——百分号（将数字除以100）
    • 退格 ——删除最后一位数字  ·  删除 ——清除当前输入（C） ·  Escape ——清除全部（AC）

    简单还是科学——您需要哪一种？

    如果您的计算只用到 + − × ÷ 和 %，这个 Simple Calculator 是更快、更友好的选择——按钮更大，没有多余功能，还有显示计算过程的记录带。当计算需要三角函数、对数、幂、根或阶乘时，请切换到我们的 科学计算器 代替。关于百分比本身的计算——一个数是另一个数的百分之几，或百分比的增减——请使用 百分比计算器 解释每一步。

    常见问题

    如果我除以零会发生什么？

    本计算器显示“无法除以零”而不是答案，因为在数学中除以零没有定义的结果。什么都不会损坏——按 C 或 AC，或直接开始输入新数字，即可继续。

    我应该使用简单计算器还是科学计算器？

    将本简单计算器用于日常加、减、乘、除——购物、账单、家庭作业和快速总计——大按钮和历史记录最有帮助。当您需要 sin、cos、tan、对数、幂、根或阶乘时使用科学计算器。
