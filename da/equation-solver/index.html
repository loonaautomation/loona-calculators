Ligningsløser (Lineær & Kvadratisk)

Løs lineære ligninger (ax + b = cx + d) og andengradsligninger (ax² + bx + c = 0) med hvert trin vist — inklusive diskriminanten, gentagne og komplekse rødder samt en endelig kontrol, der sætter svaret ind igen.

Indtast de fire tal i ax + b = cx + d. Brug 0, hvor et led mangler — for eksempel er 2x + 3 = 7 lig med a = 2, b = 3, c = 0, d = 7.

Indtast de tre koefficienter i ax² + bx + c = 0. Brug 0, hvor et led mangler — for eksempel er x² − 9 = 0 lig med a = 1, b = 0, c = −9.

Sådan bruger du Ligningsløser

  1. Vælg ligningstypen: lineær (kun x) eller andengrads (x²).
  2. Indtast koefficienterne — tallene foran x² og x samt det rene tal. Indtast 0 for et manglende led.
  3. Tryk på Løs med trin og læs udregningen linje for linje. Det sidste trin kontrollerer svaret ved at sætte det ind i den oprindelige ligning igen.
Eksempel: 3x + 2 = x + 10. Flyt x-leddene til venstre: 2x + 2 = 10. Flyt tallet til højre: 2x = 8. Divider med 2: x = 4. Tjek: 3 × 4 + 2 = 14 og 4 + 10 = 14 ✓

Ofte stillede spørgsmål

Hvilke slags ligninger kan denne løser håndtere?

Lineære ligninger på formen ax + b = cx + d og andengradsligninger på formen ax² + bx + c = 0. Den viser hvert trin, diskriminanten for andengradsligninger og en afsluttende kontrol. Den løser ikke tredjegradsligninger, ligningssystemer med to ubekendte eller uligheder — sidens titel siger præcis, hvad den dækker.

Hvad betyder "ingen løsning" eller "uendeligt mange løsninger"?

Nogle gange går x-leddene helt ud med hinanden. Hvis tallene også matcher (som 5x + 1 = 5x + 1), er ligningen altid sand — uendeligt mange løsninger. Hvis tallene ikke matcher (5x + 1 = 5x + 3), kan den aldrig være sand — ingen løsning. Løseren fortæller dig ærligt, hvilket tilfælde du har, i stedet for at opfinde et svar.

Hvad er komplekse rødder?

Når en andengradslignings diskriminant (b² − 4ac) er negativ, krydser grafen aldrig x-aksen, og der er ingen reelle svar. Rødderne er da komplekse tal med i, hvor i² = −1 — for eksempel har x² + 1 = 0 rødderne x = i og x = −i. Denne løser viser dem og kontrollerer dem stadig.

Sådan fungerer det — metoden

Lineære ligninger løses ved at holde ligningen i balance — hvad du end gør ved den ene side, gør du ved den anden. Først samles x-leddene til venstre (træk cx fra begge sider), derefter tallene til højre (træk b fra), og til sidst divideres begge sider med koefficienten for x.

Andengradsligninger brug den kvadratiske formel. For ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

Den del under rodtegnet, D = b² − 4ac, kaldes diskriminanten, og den fortæller dig, hvilken slags svar du får, før du er færdig: D > 0 betyder to forskellige reelle rødder, D = 0 betyder én gentagen rod, og D < 0 betyder to komplekse rødder og intet reelt svar.

Gennemregnet eksempel

Eksempel: Løs x² − 5x + 6 = 0. Her er a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, så √D = 1. Derefter x = (5 + 1) ÷ 2 = 3 eller x = (5 − 1) ÷ 2 = 2. Tjek x = 3: 9 − 15 + 6 = 0 ✓

Ofte stillede spørgsmål

Hvordan indtaster jeg en ligning, hvor et led mangler?

Indtast 0 for den manglende koefficient. x² − 9 = 0 bliver til a = 1, b = 0, c = −9, og løseren giver x = 3 eller x = −3. For en lineær ligning som 2x = 10 er det a = 2, b = 0, c = 0, d = 10.

Hvad hvis jeg skriver a = 0 i andengradsløseren?

Så forsvinder x²-leddet, og ligningen er i virkeligheden lineær. Løseren bemærker det og løser den som en lineær ligning i stedet, og fortæller dig, at det er, hvad der skete.

Hvorfor kontrollerer løseren sit svar til sidst?

At sætte svaret ind i den oprindelige ligning igen er den sikreste måde at fange en fejl på: hvis begge sider bliver lige, er svaret helt sikkert rigtigt. Det er også en god vane til hjemmearbejde — lærere giver ofte metodepoint for en synlig kontrol.
