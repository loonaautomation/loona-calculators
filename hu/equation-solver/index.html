Egyenletmegoldó (Lineáris és másodfokú)

Oldjon meg lineáris egyenleteket (ax + b = cx + d) és másodfokú egyenleteket (ax² + bx + c = 0) minden lépést megmutatva — beleértve a diszkriminánst, az ismétlődő és komplex gyököket, és egy végső ellenőrzést, amely a választ visszahelyettesíti.

Adja meg a négy számot ebben: ax + b = cx + d. Használjon 0-t ott, ahol egy tag hiányzik — például a 2x + 3 = 7 esetén a = 2, b = 3, c = 0, d = 7.

Adja meg a három együtthatót ebben: ax² + bx + c = 0. Használjon 0-t ott, ahol egy tag hiányzik — például az x² − 9 = 0 esetén a = 1, b = 0, c = −9.

Az Egyenletmegoldó használata

  1. Válassza ki az egyenlet típusát: lineáris (csak x) vagy másodfokú (x²).
  2. Írja be az együtthatókat — az x² és az x előtti számokat, valamint a puszta számot. Hiányzó tag esetén írjon 0-t.
  3. Nyomja meg a Megoldás lépésekkel gombot, és olvassa végig a megoldást sorról sorra. Az utolsó lépés úgy ellenőrzi a választ, hogy visszahelyettesíti az eredeti egyenletbe.
Példa: 3x + 2 = x + 10. Vigye az x-es tagokat balra: 2x + 2 = 10. Vigye a számot jobbra: 2x = 8. Osszon 2-vel: x = 4. Ellenőrzés: 3 × 4 + 2 = 14 és 4 + 10 = 14 ✓

Gyakran ismételt kérdések

Milyen egyenleteket tud kezelni ez a megoldó?

Lineáris egyenletek ax + b = cx + d alakban, és másodfokú egyenletek ax² + bx + c = 0 alakban. Minden lépést megmutat, a másodfokú egyenletek diszkriminánsát és egy végső ellenőrzést. Nem old meg harmadfokú egyenleteket, kétismeretlenes egyenletrendszereket vagy egyenlőtlenségeket — az oldal címe pontosan megmondja, mit fed le.

Mit jelent a „nincs megoldás” vagy a „végtelen sok megoldás”?

Néha az x-tagok teljesen kiesnek. Ha a számok is egyeznek (mint 5x + 1 = 5x + 1), az egyenlet mindig igaz — végtelen sok megoldás. Ha a számok nem egyeznek (5x + 1 = 5x + 3), soha nem lehet igaz — nincs megoldás. A megoldó őszintén megmondja, melyik esete van, ahelyett hogy kitalálna egy választ.

Mik a komplex gyökök?

Amikor egy másodfokú egyenlet diszkriminánsa (b² − 4ac) negatív, a grafikon soha nem lépi át az x tengelyt, és nincsenek valós válaszok. A gyökök ezután komplex számok i használatával, ahol i² = −1 — például x² + 1 = 0 gyökei x = i és x = −i. Ez a megoldó megmutatja őket, és még mindig ellenőrzi őket.

Hogyan működik — a módszer

Lineáris egyenletek úgy oldják meg, hogy az egyenletet egyensúlyban tartják — bármit tesz az egyik oldallal, azt teszi a másikkal is. Először az x tagokat a bal oldalon gyűjtik össze (vonja ki a cx-et mindkét oldalból), majd a számtagokat a jobb oldalon (vonja ki a b-t), és végül mindkét oldalt elosztják az x együtthatójával.

Quadratic egyenletek használja a másodfokú egyenlet megoldóképletét. Ax² + bx + c = 0 esetén:

x = (−b ± √(b² − 4ac)) ÷ (2a)

A rész alatt a gyök, D = b² − 4ac, neve diszkrimináns, és még a befejezés előtt megmondja, milyen lesz a válasz: D > 0 két különböző valós gyököt jelent, D = 0 egy ismétlődő gyököt, D < 0 pedig két komplex gyököt és valós válasz hiányát.

Kidolgozott példa

Példa: Oldja meg: x² − 5x + 6 = 0. Itt a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, így √D = 1. Akkor x = (5 + 1) ÷ 2 = 3 vagy x = (5 − 1) ÷ 2 = 2. Ellenőrzés x = 3 esetén: 9 − 15 + 6 = 0 ✓

Gyakori kérdések

Hogyan adhatok meg egy egyenletet, amelyből hiányzik egy tag?

Adjon meg 0-t a hiányzó együtthatóra. Az x² − 9 = 0 egyenletből a = 1, b = 0, c = −9 lesz, és a megoldó x = 3 vagy x = −3 értéket ad. Egy lineáris egyenletnél, mint a 2x = 10, ez a = 2, b = 0, c = 0, d = 10.

Mi van, ha a = 0-t írok be a másodfokú megoldóba?

Akkor az x²-es tag eltűnik, és az egyenlet valójában lineáris. A megoldó ezt észleli, és lineáris egyenletként oldja meg helyette, jelezve Önnek, hogy ez történt.

Miért ellenőrzi a megoldó a válaszát a végén?

A válasz visszahelyettesítése az eredeti egyenletbe a legbiztosabb módja egy hiba elkapásának: ha mindkét oldal egyenlőnek jön ki, a válasz biztosan helyes. Jó szokás a házi feladathoz is — a tanárok gyakran adnak módszertani pontokat egy látható ellenőrzésért.
