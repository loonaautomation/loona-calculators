Rješavač jednadžbi (linearne i kvadratne)

Riješite linearne jednadžbe (ax + b = cx + d) i kvadratne jednadžbe (ax² + bx + c = 0) sa svakim prikazanim korakom — uključujući diskriminantu, ponovljene i kompleksne korijene te završnu provjeru koja odgovor uvrštava natrag.

Unesite četiri broja u ax + b = cx + d. Koristite 0 tamo gdje član nedostaje — primjerice, 2x + 3 = 7 je a = 2, b = 3, c = 0, d = 7.

Unesite tri koeficijenta u ax² + bx + c = 0. Koristite 0 gdje član nedostaje — na primjer, x² − 9 = 0 je a = 1, b = 0, c = −9.

Kako koristiti Rješavač jednadžbi

  1. Odaberite vrstu jednadžbe: linearnu (samo x) ili kvadratnu (x²).
  2. Utipkajte koeficijente — brojeve ispred x² i x te običan broj. Za svaki član koji nedostaje unesite 0.
  3. Pritisnite Riješi s koracima i čitajte postupak redak po redak. Zadnji korak provjerava odgovor uvrštavanjem natrag u izvornu jednadžbu.
Primjer: 3x + 2 = x + 10. Premjestite članove s x ulijevo: 2x + 2 = 10. Premjestite broj udesno: 2x = 8. Podijelite s 2: x = 4. Provjera: 3 × 4 + 2 = 14 i 4 + 10 = 14 ✓

Često postavljana pitanja

Koje vrste jednadžbi ovaj rješavač može obraditi?

Linearne jednadžbe u obliku ax + b = cx + d i kvadratne jednadžbe u obliku ax² + bx + c = 0. Prikazuje svaki korak, diskriminantu za kvadratne jednadžbe i završnu provjeru. Ne rješava kubne jednadžbe, sustave jednadžbi s dvije nepoznanice ni nejednadžbe — naslov stranice točno kaže što pokriva.

Što znači „nema rješenja” ili „beskonačno mnogo rješenja”?

Ponekad se članovi s x potpuno ponište. Ako se i brojevi podudaraju (kao 5x + 1 = 5x + 1), jednadžba je uvijek točna — beskonačno mnogo rješenja. Ako se brojevi ne podudaraju (5x + 1 = 5x + 3), nikada ne može biti točna — nema rješenja. Rješavač vam iskreno kaže koji je vaš slučaj, umjesto da izmišlja odgovor.

Što su kompleksni korijeni?

Kad je diskriminanta kvadratne jednadžbe (b² − 4ac) negativna, graf nikad ne siječe os x i nema realnih odgovora. Korijeni su tada kompleksni brojevi koji koriste i, gdje je i² = −1 — na primjer, x² + 1 = 0 ima korijene x = i i x = −i. Ovaj rješavač ih prikazuje i ipak ih provjerava.

Kako radi — metoda

Linearne jednadžbe rješavaju se održavanjem ravnoteže jednadžbe — što god učinite jednoj strani, učinite i drugoj. Najprije se članovi s x okupljaju na lijevoj strani (oduzmite cx od obiju strana), zatim brojčani članovi na desnoj (oduzmite b), i na kraju se obje strane dijele koeficijentom od x.

Kvadratne jednadžbe koristite kvadratnu formulu. Za ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

Dio pod korijenom, D = b² − 4ac, naziva se diskriminanta i govori vam vrstu odgovora prije nego što završite: D > 0 znači dva različita realna korijena, D = 0 znači jedan ponovljeni korijen, a D < 0 znači dva kompleksna korijena i nijedan realan odgovor.

Obrađeni primjer

Primjer: Riješite x² − 5x + 6 = 0. Ovdje je a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, pa je √D = 1. Zatim x = (5 + 1) ÷ 2 = 3 ili x = (5 − 1) ÷ 2 = 2. Provjera x = 3: 9 − 15 + 6 = 0 ✓

Često postavljana pitanja

Kako unijeti jednadžbu kojoj nedostaje član?

Unesite 0 za koeficijent koji nedostaje. x² − 9 = 0 postaje a = 1, b = 0, c = −9, a rješavač daje x = 3 ili x = −3. Za linearnu jednadžbu poput 2x = 10, to je a = 2, b = 0, c = 0, d = 10.

Što ako u rješavaču kvadratne jednadžbe upišem a = 0?

Tada član x² nestaje i jednadžba je zapravo linearna. Rješavač to primjećuje i rješava je kao linearnu jednadžbu, uz napomenu da je to učinio.

Zašto rješavač na kraju provjerava svoj odgovor?

Vraćanje odgovora u izvornu jednadžbu najsigurniji je način da se uoči pogreška: ako obje strane ispadnu jednake, odgovor je sigurno točan. To je dobra navika i za domaću zadaću — učitelji često daju bodove za postupak kada je provjera vidljiva.
