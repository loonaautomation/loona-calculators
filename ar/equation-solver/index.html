معادلة Solver (Linear & Quadratic)

Solve linear معادلات (ax + b = cx + d) وquadratic معادلات (ax² + bx + c = 0) مع كل خطوة المعروض — بما في ذلك discriminant، repeated وcomplex جذر، وfinal تحقق ذلك substitutes الإجابة رجوعًا في.

أدخل أربعة أعداد في ax + b = cx + d. استخدم 0 where مدة missing — على سبيل المثال، 2 x + 3 = 7 = 2، b = 3، c = 0، d = 7.

أدخل ثلاثة coefficients في ax² + bx + c = 0. استخدم 0 where مدة missing — على سبيل المثال، x² − 9 = 0 = 1، b = 0، c = − 9.

كيفية استخدام المعادلة Solver

  1. Choose المعادلة اكتب: linear (x فقط) أو quadratic (x²).
  2. اكتب في coefficients — أعداد في front x² وx، وplain عدد. أدخل 0 لـأي missing مدة.
  3. اضغط Solve مع خطوات واقرأ خطوات الحل سطر بواسطة سطر. أخير خطوة تحقق الإجابة بواسطة substituting إنه رجوعًا إلى الأصلي معادلة.
مثال: 3 x + 2 = x + 10. Move x مدة يسار: 2 x + 2 = 10. Move العدد يمين: 2 x = 8. اقسم بواسطة 2: x = 4. تحقق: 3 × 4 + 2 = 14 و4 + 10 = 14 ✓

Frequently Asked أسئلة

ما kinds معادلات يمكن هذا solver handle؟

Linear معادلات في form ax + b = cx + d، وquadratic معادلات في form ax² + bx + c = 0. إنه يعرض كل خطوة، discriminant لـquadratics، وfinal تحقق. إنه يفعل لا solve cubic معادلات، simultaneous معادلات في اثنان unknowns، أو inequalities — الصفحة title يقول تمامًا ما إنه covers.

ماذا يعني " لا حل " أو " infinitely كثير حلول " متوسط؟

أحيانًا x مدة cancel خارج completely. إذا أعداد أيضًا match (like 5 x + 1 = 5 x + 1) المعادلة دائمًا الحقيقي — infinitely كثير حلول. إذا أعداد افعل لا match (5 x + 1 = 5 x + 3) إنه يمكن أبدًا يكون الحقيقي — لا حل. solver tells أنت honestly أي case أنت لديك بدلاً من inventing إجابة.

ما هي complex جذر؟

عندما quadratic discriminant (b² − 4 ac) negative، رسم بياني أبدًا crosses x-axis وهناك لا حقيقي إجابة. جذر ثم complex أعداد باستخدام أنا، where i² = − 1 — على سبيل المثال، x² + 1 = 0 لديه جذر x = أنا وx = − أنا. هذا solver يعرض لهم ولا يزال تحقق لهم.

كيف يعمل — الطريقة

Linear معادلات solved بواسطة احتفظ المعادلة الرصيد — whatever أنت افعل إلى واحد جانب، أنت افعل إلى آخر. الأول x مدة gathered في يسار (اطرح cx من كلاهما جانب)، ثم العدد مدة في يمين (اطرح b)، وfinally كلاهما جانب مقسوم بواسطة coefficient x.

Quadratic معادلات استخدم quadratic صيغة. لـax² + bx + c = 0:

x = (− b ± √ (b² − 4 ac)) ÷ (2)

الجزء تحت الجذر، D = b² − 4 ac، called discriminant، وإنه tells أنت kind إجابة قبل أنت finish: D &gt؛ 0 متوسط اثنان مختلف حقيقي جذر، D = 0 متوسط واحد repeated جذر، وD &lt؛ 0 متوسط اثنان complex جذر ولا حقيقي إجابة.

مثال محلول

مثال: Solve x² − 5 x + 6 = 0. هنا = 1، b = − 5، c = 6. D = (− 5) ² − 4 × 1 × 6 = 25 − 24 = 1، لذلك √ D = 1. ثم x = (5 + 1) ÷ 2 = 3 أو x = (5 − 1) ÷ 2 = 2. تحقق x = 3: 9 − 15 + 6 = 0 ✓

Frequently asked أسئلة

كيف هل أ أدخل معادلة مع مدة missing؟

أدخل 0 لـmissing coefficient. x² − 9 = 0 becomes = 1، b = 0، c = − 9، وsolver يعطي x = 3 أو x = − 3. لـlinear معادلة like 2 x = 10، ذلك = 2، b = 0، c = 0، d = 10.

ما إذا أنا اكتب = 0 في quadratic solver؟

ثم x² مدة disappears والمعادلة really linear. solver notices هذا وsolves إنه كـ linear معادلة بدلاً من، telling أنت ذلك ما happened.

لماذا solver تحقق إجابة عند النهاية؟

Substituting الإجابة رجوعًا إلى الأصلي معادلة surest طريقة إلى catch خطأ: إذا كلاهما جانب يأتي خارج يساوي، الإجابة certainly يمين. إنه good habit لـhomework أيضًا — teachers غالبًا يمنح طريقة marks لـvisible تحقق.
