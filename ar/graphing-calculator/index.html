حاسبة 📈 رسم بياني

اكتب function x — على سبيل المثال x ^ 2، sin (x)، 2 x + 3 أو 1 / x — وانظر رسم بياني فورًا. اجمع ثانية function إلى compare، وzoom في أو خارج إلى explore intercepts، يتحول نقاط وasymptotes.

سريع إجابة: رسم بياني حاسبة draws y = f (x) بواسطة خطوات الحل خارج y لـمئة x قيم across visible window وjoining النقاط. هذا واحد understands x ^ 2، sin (x)، cos (x)، tan (x)، sqrt (x)، log (x)، كسور وimplicit multiplication like 2 x.

حاسبة كيفية استخدام رسم بياني

  1. أدخل الأول function، على سبيل المثال x ^ 2 - 4.
  2. Optionally أدخل ثانية function إلى compare في مختلف colour.
  3. اضغط Plot، ثم استخدم Zoom في / Zoom خارج أو Reset View.
  4. اقرأ intercepts وcrossings off grid — كل مربع 1 وحدة بواسطة default.
مثال: Plotting x ^ 2 - 4 يعطي parabola crossing x-axis عند x = - 2 وx = 2، مع lowest نقطة عند (0، - 4). اجمع السطر 2 x + 3 يعرض where curve والسطر يقابل.

Frequently Asked أسئلة

ما expressions هل يمكنني استخدم؟

أعداد، x، + − * / ^ وbrackets، زائد sin، cos، tan، sqrt، abs، log (أساس 10)، ln، exp وconstants pi وe. Implicit multiplication يعمل أيضًا: 2 x، 3 (x + 1) و(x + 1) (x - 1) كل understood.

لماذا رسم بياني 1 / x أو tan (x) break في أماكن؟

Those functions jump بين جدًا كبير positive وnegative قيم عند asymptote. plotter detects jump وlifts pen بدلاً من drawing خاطئ vertical سطر.

كيف هل أ write x مربع أو قدرة؟

استخدم caret: x ^ 2 متوسط x مربع، x ^ 3 مكعب، وx ^ 0.5 نفس كما sqrt (x). قدرة right-associative، لذلك 2 ^ 3 ^ 2 اقرأ كما 2 ^ (3 ^ 2) = 512.

ما مدى يفعل رسم بياني يعرض؟

إنه يبدأ عند x من − 10 إلى 10 وy من − 10 إلى 10. كل zoom خطوة multiplies مدى بواسطة حوالي 0.7 (في) أو 1.4 (خارج).

كيف يعمل — الصيغة

plotter parses كل expression إلى tokens (أعداد، x، operators، functions)، inserts implied multiplication إشارات (2 x → 2 * x)، وevaluates إنه مع recursive-descent parser ذلك respects قياسي order operations: ^ binds tightest وassociates إلى يمين، ثم * و/، ثم + و−، مع functions وbrackets الأول. إنه ثم samples function عند 720 x-positions across window وconnects consecutive finite نقاط، skipping gaps where function undefined أو jumps across asymptote.

مثال محلول

Inputs: f (x) = x ^ 2 − 4.

خطوات: عند x = 0، y = − 4 (lowest نقطة). عند x = 2، y = 4 − 4 = 0، وعند x = − 2، y = 0 — اثنان x-intercepts. عند x = 3، y = 9 − 4 = 5.

نتيجة: parabola مع vertex (0، − 4) crossing x-axis عند − 2 و2، تمامًا بوصفه رسم بياني يعرض.
