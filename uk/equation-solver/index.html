Розв’язувач рівнянь (лінійні та квадратні)

Розв'язуйте лінійні рівняння (ax + b = cx + d) і квадратні рівняння (ax² + bx + c = 0) з кожним показаним кроком — включно з дискримінантом, повторюваними та комплексними коренями та остаточною перевіркою, яка підставляє відповідь назад.

Введіть чотири числа в ax + b = cx + d. Використовуйте 0 там, де доданка немає, — наприклад, 2x + 3 = 7 — це a = 2, b = 3, c = 0, d = 7.

Введіть три коефіцієнти в ax² + bx + c = 0. Використовуйте 0 там, де доданка немає, — наприклад, x² − 9 = 0 — це a = 1, b = 0, c = −9.

Як користуватися: Розв’язувач рівнянь

  1. Виберіть тип рівняння: лінійне (лише x) або квадратне (x²).
  2. Введіть коефіцієнти — числа перед x² і x, а також вільний член. Для будь-якого відсутнього члена введіть 0.
  3. Натисніть «Розв’язати з кроками» і читайте розв’язання рядок за рядком. Останній крок перевіряє відповідь, підставляючи її назад у початкове рівняння.
Приклад: 3x + 2 = x + 10. Перенесіть доданки з x ліворуч: 2x + 2 = 10. Перенесіть число праворуч: 2x = 8. Поділіть на 2: x = 4. Перевірка: 3 × 4 + 2 = 14 і 4 + 10 = 14 ✓

Часті запитання

Які види рівнянь може обробляти цей розв’язувач?

Лінійні рівняння у формі ax + b = cx + d і квадратні рівняння у формі ax² + bx + c = 0. Він показує кожен крок, дискримінант для квадратних рівнянь і остаточну перевірку. Він не розв'язує кубічні рівняння, системи рівнянь із двома невідомими або нерівності — назва сторінки каже точно, що вона охоплює.

Що означає «немає розв’язку» або «безліч розв’язків»?

Іноді члени з x повністю скасовуються. Якщо числа також збігаються (як 5x + 1 = 5x + 1), рівняння завжди істинне — нескінченно багато розв'язків. Якщо числа не збігаються (5x + 1 = 5x + 3), воно ніколи не може бути істинним — розв'язку немає. Розв'язувач чесно каже вам, який випадок ви маєте, замість того, щоб винаходити відповідь.

Що таке комплексні корені?

Коли дискримінант квадратного рівняння (b² − 4ac) від'ємний, графік ніколи не перетинає вісь x і реальних відповідей немає. Корені тоді є комплексними числами, що використовують i, де i² = −1, — наприклад, x² + 1 = 0 має корені x = i та x = −i. Цей розв'язувач показує їх і все ще перевіряє їх.

Як це працює — метод

Лінійні рівняння розв'язуються збереженням рівняння збалансованим — що б ви не робили з одним боком, ви робите з іншим. Спочатку члени x збираються ліворуч (відніміть cx з обох боків), потім числові члени праворуч (відніміть b), і нарешті обидва боки діляться на коефіцієнт x.

Квадратні рівняння скористайтеся формулою коренів квадратного рівняння. Для ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

Частина під коренем, D = b² − 4ac, називається дискримінантом, і він підказує вам тип відповіді ще до завершення: D > 0 означає два різні дійсні корені, D = 0 означає один повторюваний корінь, а D < 0 означає два комплексні корені та відсутність дійсної відповіді.

Розібраний приклад

Приклад: Розв’яжіть x² − 5x + 6 = 0. Тут a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, отже √D = 1. Тоді x = (5 + 1) ÷ 2 = 3 або x = (5 − 1) ÷ 2 = 2. Перевірка x = 3: 9 − 15 + 6 = 0 ✓

Часті запитання

Як ввести рівняння з відсутнім членом?

Введіть 0 для відсутнього коефіцієнта. x² − 9 = 0 стає a = 1, b = 0, c = −9, і розв’язувач дає x = 3 або x = −3. Для лінійного рівняння на кшталт 2x = 10, це a = 2, b = 0, c = 0, d = 10.

Що, якщо я введу a = 0 у розв’язувачі квадратних рівнянь?

Тоді член x² зникає, і рівняння насправді лінійне. Розв’язувач помічає це й натомість розв’язує його як лінійне рівняння, повідомляючи вам, що саме сталося.

Чому розв’язувач перевіряє свою відповідь наприкінці?

Підстановка відповіді назад у початкове рівняння — найнадійніший спосіб зловити помилку: якщо обидві сторони виходять рівними, відповідь, безумовно, правильна. Це також добра звичка для домашнього завдання — вчителі часто дають бали за метод за видиму перевірку.
