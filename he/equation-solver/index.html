פותֵר משוואות (לינאריות וריבועיות)

פתרו משוואות ליניאריות (ax + b = cx + d) ומשוואות ריבועיות (ax² + bx + c = 0) כאשר כל שלב מוצג — כולל הדיסקרימיננטה, שורשים חוזרים ומרוכבים, ובדיקה סופית המחליפה את התשובה בחזרה.

הזינו את ארבעת המספרים ב ax + b = cx + d. השתמשו ב־0 כאשר איבר חסר — לדוגמה, 2x + 3 = 7 הוא a = 2, b = 3, c = 0, d = 7.

הזינו את שלושת המקדמים ב ax² + bx + c = 0. השתמשו ב־0 כאשר איבר חסר — לדוגמה, x² − 9 = 0 הוא a = 1, b = 0, c = −9.

כיצד להשתמש בפותר המשוואות

  1. בחרו את סוג המשוואה: לינארית (x בלבד) או ריבועית (x²).
  2. הקלידו את המקדמים — המספרים שלפני x² ו־x, והמספר הרגיל. הזינו 0 לכל איבר חסר.
  3. לחצו על פתור עם שלבים וקראו את החישוב שורה אחר שורה. השלב האחרון בודק את התשובה על ידי הצבתה חזרה במשוואה המקורית.
דוגמה: 3x + 2 = x + 10. העבירו את איברי ה־x שמאלה: 2x + 2 = 10. העבירו את המספר ימינה: 2x = 8. חלקו ב־2: x = 4. בדיקה: 3 × 4 + 2 = 14 ו־4 + 10 = 14 ✓

שאלות נפוצות

אילו סוגי משוואות פותר זה יכול לטפל?

משוואות ליניאריות מהצורה ax + b = cx + d, ומשוואות ריבועיות מהצורה ax² + bx + c = 0. הוא מציג כל שלב, את הדיסקרימיננטה למשוואות ריבועיות, ובדיקה סופית. הוא אינו פותר משוואות ממעלה שלישית, משוואות סימולטניות בשני נעלמים, או אי־שוויונות — כותרת העמוד אומרת בדיוק מה הוא מכסה.

מה פירוש "אין פתרון" או "אינסוף פתרונות"?

לפעמים איברי ה־x מתבטלים לחלוטין. אם גם המספרים תואמים (כמו 5x + 1 = 5x + 1) המשוואה נכונה תמיד — אינסוף פתרונות. אם המספרים אינם תואמים (5x + 1 = 5x + 3) היא לעולם אינה יכולה להיות נכונה — אין פתרון. הפותר אומר לכם בכנות איזה מקרה יש לכם במקום להמציא תשובה.

מהם שורשים מרוכבים?

כאשר הדיסקרימיננטה של משוואה ריבועית (b² − 4ac) שלילית, הגרף לעולם אינו חוצה את ציר ה־x ואין תשובות ממשיות. השורשים הם אז מספרים מרוכבים המשתמשים ב־i, כאשר i² = −1 — למשל, ל־x² + 1 = 0 יש השורשים x = i ו־x = −i. פותר זה מציג אותם ועדיין בודק אותם.

איך זה עובד — השיטה

משוואות ליניאריות נפתרים על ידי שמירה על המשוואה מאוזנת — כל מה שעושים לצד אחד, עושים לצד השני. תחילה נאספים איברי ה־x בצד שמאל (מחסירים cx משני הצדדים), לאחר מכן איברי המספרים בצד ימין (מחסירים b), ולבסוף מחלקים את שני הצדדים במקדם של x.

משוואות ריבועיות השתמשו בנוסחת השורשים. עבור ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

החלק שמתחת לשורש, D = b² − 4ac, נקרא הדיסקרימיננטה, והוא אומר לכם איזו מין תשובה תתקבל עוד לפני שסיימתם: D > 0 פירושו שני שורשים ממשיים שונים, D = 0 פירושו שורש חוזר אחד, ו־D < 0 פירושו שני שורשים מרוכבים ואין תשובה ממשית.

דוגמה פתורה

דוגמה: פתרו x² − 5x + 6 = 0. כאן a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, כך ש־√D = 1. אז x = (5 + 1) ÷ 2 = 3 או x = (5 − 1) ÷ 2 = 2. בדיקה x = 3: 9 − 15 + 6 = 0 ✓

שאלות נפוצות

איך מזינים משוואה עם איבר חסר?

הזינו 0 עבור המקדם החסר. x² − 9 = 0 הופך ל־a = 1, b = 0, c = −9, והפותֵר נותן x = 3 או x = −3. למשוואה לינארית כמו 2x = 10, זה a = 2, b = 0, c = 0, d = 10.

מה אם אני מקליד a = 0 בפותר המשוואות הריבועיות?

אז איבר ה־x² נעלם והמשוואה היא בעצם ליניארית. הפותר מבחין בכך ופותר אותה כמשוואה ליניארית, ומודיע לכם שזה מה שקרה.

למה הפותר בודק את תשובתו בסוף?

החלפת התשובה בחזרה למשוואה המקורית היא הדרך הבטוחה ביותר לתפוס טעות: אם שני הצדדים יוצאים שווים, התשובה בוודאות נכונה. זהו גם הרגל טוב לשיעורי בית — מורים נותנים לעיתים קרובות נקודות שיטה על בדיקה נראית לעין.
