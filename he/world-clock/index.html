שאלות נפוצות

איך שעון העולם נשאר מדויק?

הוא קורא את שעון המכשיר שלכם אחת לשנייה וממיר את אותו רגע לאזור הזמן IANA של כל עיר באמצעות Intl API המובנה בדפדפן שלכם. כללי אזור הזמן, כולל שעון קיץ, מגיעים מאותו מסד נתונים שמערכות הפעלה משתמשות בו.

למה התאריך יכול להיות שונה בעיר אחרת?

כי גבול היום יושב בין ערים: כשמוקדם בבוקר באוקלנד עדיין אחר הצהריים של אתמול בלוס אנג'לס. כל כרטיס מציג לכן את התאריך של העיר עצמה וגם את השעה שלה.

האם זה זהה לממיר אזורי הזמן שב־Loona Hours?

לא. הכלי ההוא ממיר זמן נבחר אחד בין שני אזורים. העמוד הזה הוא לוח חי של זמנים נוכחיים ב־24 ערים במבט אחד. מחשבון הזמן הקיים באתר הזה מחבר ומחסיר משכים — עבודה שונה שוב.

מה אם שעה נראית שגויה?

בדקו תחילה את שעון המכשיר שלכם — ההמרות מדויקות, אבל הן מתחילות מהרגע הנוכחי של המכשיר שלכם. דפדפנים מקבלים את כללי אזור הזמן ממערכת ההפעלה שלכם, ולכן שמרו עליו מעודכן.

איך זה עובד — הנוסחה

כל כרטיס ממיר רגע אחד — השעה הנוכחית מהמכשיר שלכם — לאזור זמן בעזרת ה Intl.DateTimeFormat API ושם האזור של IANA (לדוגמה Asia/Karachi). היסט ה־UTC שמציג כל אזור הוא ההיסט שאותו אזור מקיים בתאריך זה, לכן היסטי קיץ וחורף (שעון קיץ) מוחלים אוטומטית. שעון מקומי = רגע UTC + היסט האזור באותו תאריך.

ממירים דווקא רגע מסוים? ה ממיר חותמות זמן ב־Loona Developer Tools ממיר חותמות זמן של Unix לתאריכים קריאים ובחזרה — האתר הזה במתכוון אינו משכפל אותו.

דוגמה פתורה

מיידי: 15 בינואר 2026, ‏12:00:00 UTC.

שלבים: לונדון נוהגת לפי GMT (UTC+0) בינואר → 12:00. קראצ'י ב־UTC+5 כל השנה → 17:00. דובאי ב־UTC+4 → 16:00. ניו יורק נוהגת לפי EST (UTC−5) בינואר → 07:00. טוקיו ב־UTC+9 → 21:00.

תוצאה: רגע אחד מוצג כ 12:00 / 17:00 / 16:00 / 07:00 / 21:00 על פני חמש הערים.
