🗓️ Days Between Dates

How many days are there between two dates? For deadlines, visa periods, contracts or counting down to a special day — just select the start and end dates.

How to use the Days Between Dates

  1. Select the start date.
  2. Select the end date (today is pre-filled).
  3. Press Calculate.
Example: From 1 January 2026 to 28 October 2026 there are exactly 300 days.

Frequently Asked Questions

Does it include the end date?

The main result counts the difference (end − start). We also show the inclusive count (+1 day) if your end date should be counted too.

Can I count days until a future date?

Yes — set the future date as the end date.

What about weeks?

The result also breaks the days into weeks and extra days.
