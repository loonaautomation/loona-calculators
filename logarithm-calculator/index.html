log Logarithm Calculator

Find the logarithm of any number to any base — and get the common log, natural log (ln) and binary log alongside it, each one verified by raising the base back to the answer (the antilog).

How to use the Logarithm Calculator

  1. Enter the number x whose logarithm you want. It must be greater than 0.
  2. Enter the base b — or tap Base 10, Base 2 or Base e. The base must be greater than 0 and not equal to 1.
  3. Press Calculate. You get the log to your base plus the common log (base 10), natural log (base e) and binary log (base 2), and an antilog check that raises the base back to your answer.
Example: log2(32) = 5, because 25 = 32. And log10(1000) = 3, because 103 = 1000.

Frequently Asked Questions

What is a logarithm, in simple words?

A logarithm answers the question: "To what power must I raise the base to get this number?" log10(1000) = 3 because 10 raised to the power 3 is 1000. It is the opposite (inverse) of a power, just as division is the opposite of multiplication.

What is the difference between log and ln?

"log" on most calculators means base 10 — the common logarithm. "ln" means base e (e ≈ 2.71828) — the natural logarithm, used across science and finance. This calculator gives you both, plus base 2 (the binary log used in computing), for any number you enter.

Why can I not take the log of 0 or a negative number?

Because no power of a positive base can ever produce 0 or a negative result: 10 to any power is always positive. So for real numbers the logarithm of 0 or a negative number is undefined, and the calculator will tell you so rather than show a made-up answer.

How it works — the formula

Definition: logb(x) = y exactly when by = x. The logarithm and the power are two sides of the same fact.

Change of base: most calculators only have log (base 10) and ln (base e) keys. To find a log to any other base, divide:

logb(x) = ln(x) ÷ ln(b) = log10(x) ÷ log10(b)

That change-of-base rule is what this page uses internally, so the answer you get for base b is the same one you would get step by step by hand.

Antilog: the antilog of y to base b is simply by — it undoes the logarithm. If log10(1000) = 3, then the antilog of 3 is 103 = 1000. Every result on this page is checked this way before you see it.

Worked example

Example: Find log2(32) by change of base. ln(32) ≈ 3.4657 and ln(2) ≈ 0.6931. Divide: 3.4657 ÷ 0.6931 = 5. Check with the antilog: 25 = 32 ✓

Frequently asked questions

What is the log of 1 in any base?

Always 0, because any base raised to the power 0 equals 1: b0 = 1. In the same way, logb(b) is always 1, because b1 = b.

Why must the base not be 1?

Because 1 raised to any power is always 1, so "to what power must I raise 1 to get 100?" has no answer at all — and for the number 1 itself it would have infinitely many. Base 1 is therefore excluded, and so are base 0 and negative bases for real-number work.

Where are logarithms used in real life?

Wherever quantities grow by multiplication: earthquake strength (Richter scale), sound loudness (decibels), acidity (pH), compound interest and half-life calculations, and the binary log in computing (how many bits, or how many halvings, a dataset needs).
