Gleichungslöser (Linear & Quadratisch)

Lösen Sie lineare Gleichungen (ax + b = cx + d) und quadratische Gleichungen (ax² + bx + c = 0) mit jedem Schritt angezeigt — einschließlich der Diskriminante, doppelter und komplexer Wurzeln und einer abschließenden Prüfung, die die Antwort wieder einsetzt.

Geben Sie die vier Zahlen in ax + b = cx + d. Verwenden Sie 0, wo ein Term fehlt — zum Beispiel ist 2x + 3 = 7 gleich a = 2, b = 3, c = 0, d = 7.

Geben Sie die drei Koeffizienten in ax² + bx + c = 0. Verwenden Sie 0, wo ein Term fehlt — zum Beispiel ist x² − 9 = 0 gleich a = 1, b = 0, c = −9.

So verwenden Sie: Gleichungslöser

  1. Wählen Sie den Gleichungstyp: linear (nur x) oder quadratisch (x²).
  2. Geben Sie die Koeffizienten ein — die Zahlen vor x² und x, und die reine Zahl. Geben Sie 0 für jeden fehlenden Term ein.
  3. Drücken Sie auf Mit Schritten lösen und lesen Sie die Berechnung Zeile für Zeile. Der letzte Schritt prüft die Antwort, indem er sie wieder in die ursprüngliche Gleichung einsetzt.
Beispiel: 3x + 2 = x + 10. Die x-Terme nach links bringen: 2x + 2 = 10. Die Zahl nach rechts bringen: 2x = 8. Durch 2 teilen: x = 4. Prüfung: 3 × 4 + 2 = 14 und 4 + 10 = 14 ✓

Häufig gestellte Fragen

Welche Arten von Gleichungen kann dieser Löser behandeln?

Lineare Gleichungen in der Form ax + b = cx + d und quadratische Gleichungen in der Form ax² + bx + c = 0. Er zeigt jeden Schritt, die Diskriminante für Quadratische und eine Schlussprüfung. Er löst keine kubischen Gleichungen, keine Gleichungssysteme mit zwei Unbekannten und keine Ungleichungen — der Seitentitel sagt genau, was er abdeckt.

Was bedeutet „keine Lösung“ oder „unendlich viele Lösungen“?

Manchmal heben sich die x-Terme vollständig auf. Wenn auch die Zahlen übereinstimmen (wie 5x + 1 = 5x + 1), ist die Gleichung immer wahr — unendlich viele Lösungen. Wenn die Zahlen nicht übereinstimmen (5x + 1 = 5x + 3), kann sie niemals wahr sein — keine Lösung. Der Löser sagt Ihnen ehrlich, welchen Fall Sie haben, statt eine Antwort zu erfinden.

Was sind komplexe Wurzeln?

Wenn die Diskriminante einer quadratischen Gleichung (b² − 4ac) negativ ist, kreuzt der Graph niemals die x-Achse, und es gibt keine reellen Antworten. Die Wurzeln sind dann komplexe Zahlen mit i, wobei i² = −1 — zum Beispiel hat x² + 1 = 0 die Wurzeln x = i und x = −i. Dieser Löser zeigt sie an und prüft sie trotzdem.

So funktioniert es — die Methode

Lineare Gleichungen werden gelöst, indem die Gleichung im Gleichgewicht bleibt — was immer Sie auf einer Seite tun, tun Sie auch auf der anderen. Zuerst werden die x-Terme auf der linken Seite gesammelt (cx von beiden Seiten subtrahieren), dann die Zahlenterme auf der rechten Seite (b subtrahieren), und schließlich werden beide Seiten durch den Koeffizienten von x geteilt.

Quadratische Gleichungen verwenden Sie die quadratische Formel. Für ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

Der Teil unter der Wurzel, D = b² − 4ac, wird Diskriminante genannt und verrät Ihnen die Art der Antwort, bevor Sie fertig sind: D > 0 bedeutet zwei verschiedene reelle Wurzeln, D = 0 bedeutet eine doppelte Wurzel und D < 0 bedeutet zwei komplexe Wurzeln und keine reelle Antwort.

Ausgearbeitetes Beispiel

Beispiel: Lösen Sie x² − 5x + 6 = 0. Hier ist a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, daher gilt √D = 1. Anschließend ist x = (5 + 1) ÷ 2 = 3 oder x = (5 − 1) ÷ 2 = 2. Prüfung x = 3: 9 − 15 + 6 = 0 ✓

Häufig gestellte Fragen

Wie gebe ich eine Gleichung ein, bei der ein Term fehlt?

Geben Sie 0 für den fehlenden Koeffizienten ein. x² − 9 = 0 wird zu a = 1, b = 0, c = −9, und der Löser ergibt x = 3 oder x = −3. Für eine lineare Gleichung wie 2x = 10 ist das a = 2, b = 0, c = 0, d = 10.

Was, wenn ich im quadratischen Löser a = 0 eingebe?

Dann verschwindet der x²-Term, und die Gleichung ist wirklich linear. Der Löser bemerkt dies und löst sie stattdessen als lineare Gleichung und sagt Ihnen, dass dies geschehen ist.

Warum prüft der Löser seine Antwort am Ende?

Die Antwort wieder in die ursprüngliche Gleichung einzusetzen ist der sicherste Weg, einen Fehler zu entdecken: Wenn beide Seiten gleich herauskommen, ist die Antwort sicher richtig. Es ist auch eine gute Gewohnheit für Hausaufgaben — Lehrer geben oft Methodenpunkte für eine sichtbare Prüfung.
