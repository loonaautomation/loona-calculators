🎯 Rundungsrechner

Runden Sie jede Zahl auf die übliche Schulweise — halb aufrunden — auf eine gewählte Anzahl von Dezimalstellen, auf die nächsten zehn, hundert oder tausend, oder auf eine feste Anzahl signifikanter Stellen.

Kurze Antwort: Beim Runden wird die erste wegfallende Ziffer betrachtet: 5 oder mehr rundet auf, weniger als 5 rundet ab. So rundet 1,234.5678 auf 1,234.57 bei 2 Dezimalstellen, auf 1,230 auf die nächsten 10, auf 1,200 auf die nächsten 100 und auf 1,235 bei 4 signifikanten Stellen.

So verwenden Sie: Rundungsrechner

  1. Geben Sie die zu rundende Zahl ein.
  2. Wählen Sie den Rundungsmodus und die Genauigkeit.
  3. Lesen Sie das gerundete Ergebnis und die angewandte Regel.
Beispiel: 1,234.5678: auf 2 Dezimalstellen → 1,234.57; auf die nächsten 100 → 1,200; auf 4 signifikante Stellen → 1,235 (da die 5. signifikante Ziffer eine 5 ist, rundet die 4. von 4 auf 5 auf — ergibt 1,235).

Häufig gestellte Fragen

Was ist „Runden auf die Hälfte aufwärts“?

Wenn der weggelassene Teil genau die Hälfte ist (eine 5, gefolgt von nichts), rundet die Zahl auf, von null weg für Positive. Es ist die Konvention, die in Schulen gelehrt und in den meisten Alltagskontexten verwendet wird. Banker-Rundung (auf die gerade Zahl) existiert in Finanzen und Informatik, ist hier aber nicht der Standard.

Was sind signifikante Stellen?

Ziffern mit Bedeutung, gezählt ab der ersten von Null verschiedenen Ziffer. 0.004560 hat 4 signifikante Stellen (4, 5, 6 und die abschließende 0). Das Runden auf signifikante Stellen hält die Genauigkeit proportional zur Größe der Zahl — deshalb bevorzugen Wissenschaftler diese Methode.

Wie runde ich auf den nächsten Tausender?

Das ist Runden an der Stellenwert-Position −3: Betrachten Sie die Hunderterstelle; 1,234 hat die Hunderterstelle 2, also rundet sie auf 1,000 ab, während 1,567 auf 2,000 aufrundet.

Warum können Computer 2.675 als 2.67 anzeigen?

Binäre Gleitkommazahlen können die meisten Dezimalbrüche nicht exakt speichern, sodass naiver Code manchmal 'falsch' rundet. Dieser Rechner korrigiert mit einem winzigen Epsilon, sodass exakte Hälften sich so verhalten, wie die Schulmathematik es erwartet.

So funktioniert es — die Formel

Dezimalstellen: rounded = round(x × 10ᵈ) ÷ 10ᵈ mit Round-Half-Up (mit einer Epsilon-Korrektur für binäre Gleitkommazahlen). Stellenwert: dieselbe Formel mit negativem d — Runden auf die nächsten 100 ist d = −2. Signifikante Stellen: wenn x ≠ 0, d = sig − 1 − floor(log₁₀|x|), dann wenden Sie die Dezimalstellen-Regel mit diesem d an.

Ausgearbeitetes Beispiel

Eingaben: x = 1,234.5678.

Schritte: 2 Dezimalstellen: 1,234.5678 × 100 = 123,456.78 → runden → 123,457 → ÷ 100 = 1,234.57. Nächste 100: 1,234.5678 ÷ 100 = 12.345678 → runden → 12 → × 100 = 1,200. 4 signifikante Stellen: Die ersten vier signifikanten Ziffern sind 1, 2, 3, 4 (die Zahl bis zur Einerstelle, 1,234); die nächste Ziffer ist 5 (die Zehntelstelle), also rundet die Einerstelle von 4 auf 5 auf und ergibt 1,235. In Formelbegriffen: floor(log₁₀ 1234.5678) = 3, also d = 4 − 1 − 3 = 0 Dezimalstellen.

Ergebnis: 1,234.57 (2 Dezimalstellen), 1,200 (nächste 100), 1,235 (4 signifikante Stellen).
