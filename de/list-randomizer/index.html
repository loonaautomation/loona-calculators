🔀 Listen-Zufallsgenerator

Fügen Sie eine beliebige Liste ein — Namen, Aufgaben, Lieder, Tombola-Einträge — und mischen Sie sie in eine wirklich zufällige Reihenfolge, oder ziehen Sie eine Zufallsstichprobe einer gewählten Größe daraus. Die Liste verlässt Ihren Browser nie.

Kurze Antwort: Ein Listen-Zufallsgenerator mischt Elemente mit dem Fisher–Yates-Algorithmus, sodass jede mögliche Reihenfolge gleich wahrscheinlich ist. Er kann auch N zufällige Elemente ohne Wiederholungen auswählen — Ziehen ohne Zurücklegen.

So verwenden Sie: Listen-Zufallsgenerator

  1. Fügen Sie Ihre Einträge ein, einen pro Zeile.
  2. Wählen Sie Ganze Liste mischen oder Stichprobe ziehen und legen Sie fest, wie viele Elemente gezogen werden.
  3. Drücken Sie auf Zufällig mischen und kopieren Sie das Ergebnis.
Beispiel: Eine Liste mit 5 Elementen (A, B, C, D, E) hat 5! = 120 mögliche Reihenfolgen, jede nach einer fairen Mischung gleich wahrscheinlich. Die Ziehung einer Stichprobe von 2 aus 10 Elementen kann C(10, 2) = 45 mögliche Paare ergeben.

Häufig gestellte Fragen

Wie unterscheidet sich dies vom Random Team Generator und Wheel of Names?

Jene verwandeln eine zufällige Reihenfolge in Teams oder einen einzelnen sich drehenden Gewinner. Die Aufgabe dieses Tools ist die rohe gemischte Liste selbst — eine zufällige Laufreihenfolge, Warteschlange oder Stichprobe — die Sie dann überall verwenden.

Ist das Mischen fair?

Ja. Es verwendet ein Fisher–Yates-Shuffle, angetrieben von Zufallszahlen in Krypto-Qualität, die Standardmethode, die jede Reihenfolge gleich wahrscheinlich macht.

Kann ein Element zweimal in einer Stichprobe vorkommen?

Nein. Die Stichprobenziehung erfolgt ohne Zurücklegen: Jeder gezogene Gegenstand wird aus dem Pool entfernt, wie das Ziehen von Namen aus einem Hut.

Wird meine Liste irgendwo hochgeladen?

Nein. Alles läuft in Ihrem Browser; schließen Sie die Seite, und die Liste ist weg.

So funktioniert es — die Formel

Das Fisher–Yates-Mischung durchläuft die Liste vom letzten Eintrag bis zum zweiten und tauscht jeden Eintrag mit einem gleichmäßig zufälligen Eintrag an oder vor seiner Position. Eine Liste mit n Einträgen hat n! mögliche Reihenfolgen, und Fisher–Yates gibt jeder exakt die Wahrscheinlichkeit 1 ÷ n!. Eine Stichprobe von k aus n zu ziehen ist ein partielles Mischen: Es gibt C(n, k) = n! ÷ (k! × (n−k)!) mögliche Stichproben, alle gleich wahrscheinlich.

Ausgearbeitetes Beispiel

Eingaben: 10 Elemente, Stichprobengröße 2.

Schritte: C(10, 2) = 10! ÷ (2! × 8!) = (10 × 9) ÷ 2 = 45 mögliche Paare. Eine faire Auswahl gibt jedem Paar die Wahrscheinlichkeit 1 ÷ 45.

Ergebnis: Jedes bestimmte Paar — sagen wir die Elemente 3 und 7 — hat eine 1 von 45 Chance, dieselbe wie bei jedem anderen Paar.
