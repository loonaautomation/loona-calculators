📐 Kalkulačka Pythagorovy věty

Zadejte libovolné dvě strany pravoúhlého trojúhelníku a kalkulačka najde třetí stranu pomocí Pythagorovy věty, s uvedením úplného dosazení, aby studenti mohli sledovat každý krok.

Rychlá odpověď: Pythagorova věta říká, že pro pravoúhlý trojúhelník platí a² + b² = c², kde c je přepona. Klasický příklad je 3-4-5: 9 + 16 = 25, takže přepona je 5.

Jak používat kalkulačku Pythagorovy věty

  1. Zadejte dvě strany, které znáte (neznámou stranu nechte prázdnou, nebo ji nastavte na 0).
  2. Pokud znáte přeponu, zadejte ji jako c.
  3. Stiskněte Vypočítat — chybějící strana a úplný postup se objeví.
Příklad: Odvěsny 6 a 8: c = √(36 + 64) = √100 = 10. S přeponou 13 a odvěsnou 5: druhá odvěsna = √(169 − 25) = √144 = 12.

Často kladené otázky

Která strana je přepona?

Strana naproti pravému úhlu — vždy nejdelší strana, zde označená c. Další dvě strany (odvěsny) jsou a a b.

Jak najdete odvěsnu místo přepony?

Přeskupte větu: a = √(c² − b²). Přepona musí být delší než kterákoli odvěsna; pokud není, trojúhelník nemůže být pravoúhlý s těmito stranami a kalkulačka to řekne.

Funguje i pro nepravoúhlé trojúhelníky?

Ne. Věta platí pouze pro pravoúhlé trojúhelníky. Pro jiné trojúhelníky potřebujete kosinovou větu — kalkulačka trigonometrie na tomto webu vám může pomoci s úhly a poměry.

Proč se trojúhelníky 3-4-5 objevují všude?

Protože 3² + 4² = 5² přesně, stavitelé a tesaři používají provaz nebo pás 3-4-5 k vyznačení pravých úhlů už tisíce let. Další celočíselné trojice zahrnují 5-12-13, 8-15-17 a 7-24-25.

Jak to funguje — vzorec

a² + b² = c². Hledání přepony: c = √(a² + b²). Hledání odvěsny: a = √(c² − b²) nebo b = √(c² − a²). Musí být zadány přesně dvě strany; třetí se odvodí a odvěsnu lze najít pouze tehdy, když je přepona nejdelší stranou.

Vypracovaný příklad

Vstupy: přepona c = 13, odvěsna a = 5, najděte b.

Kroky: b = √(c² − a²) = √(169 − 25) = √144 = 12.

Výsledek: b = 12 — trojice 5-12-13.
