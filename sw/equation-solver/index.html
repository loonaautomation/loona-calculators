Kisuluhishi cha Milinganyo (Cha Mstari na cha Pili)

Tatua milinganyo ya mstari (ax + b = cx + d) na milinganyo ya quadratic (ax² + bx + c = 0) kwa kila hatua inayoonyeshwa — ikiwemo kibaguzi, mizizi iliyorudiwa na changamani, na ukaguzi wa mwisho unaorudisha jibu ndani.

Weka nambari nne katika ax + b = cx + d. Tumia 0 mahali ambapo istilahi inakosekana — kwa mfano, 2x + 3 = 7 ni a = 2, b = 3, c = 0, d = 7.

Weka vigawo vitatu katika ax² + bx + c = 0. Tumia 0 mahali ambapo istilahi inakosekana — kwa mfano, x² − 9 = 0 ni a = 1, b = 0, c = −9.

Jinsi ya kutumia Kitatua Milinganyo

  1. Chagua aina ya mlinganyo: wa mstari (x tu) au wa pili (x²).
  2. Andika migawo — namba zilizo mbele ya x² na x, na namba ya kawaida. Ingiza 0 kwa kiunga chochote kinachokosekana.
  3. Bonyeza Tatua kwa hatua na usome mahesabu mstari kwa mstari. Hatua ya mwisho hukagua jibu kwa kuliweka tena katika mlinganyo wa asili.
Mfano: 3x + 2 = x + 10. Hamisha istilahi za x kushoto: 2x + 2 = 10. Hamisha nambari kulia: 2x = 8. Gawanya kwa 2: x = 4. Kagua: 3 × 4 + 2 = 14 na 4 + 10 = 14 ✓

Maswali Yanayoulizwa Mara kwa Mara

Kitatua hiki kinaweza kushughulikia aina zipi za milinganyo?

Milinganyo ya mstari katika umbo ax + b = cx + d, na milinganyo ya quadratic katika umbo ax² + bx + c = 0. Inaonyesha kila hatua, kibaguzi kwa quadratic, na ukaguzi wa mwisho. Haitatui milinganyo ya mchemraba, milinganyo ya wakati mmoja yenye visivyojulikana viwili, au ukosefu wa usawa — kichwa cha ukurasa kinasema hasa kile kinachohusu.

"Hakuna suluhisho" au "suluhisho nyingi zisizo na kikomo" zinamaanisha nini?

Wakati mwingine maneno ya x hujifuta kabisa. Ikiwa nambari pia zinalingana (kama 5x + 1 = 5x + 1) mlinganyo ni wa kweli kila mara — masuluhisho yasiyokuwa na idadi. Ikiwa nambari hazilingani (5x + 1 = 5x + 3) hauwezi kamwe kuwa wa kweli — hakuna suluhisho. Kitatuzi kinakwambia kwa uaminifu kesi gani uliyo nayo badala ya kubuni jibu.

Mizizi changamano (complex) ni nini?

Kibaguzi cha quadratic (b² − 4ac) kinapokuwa hasi, grafu haivuki kamwe mhimili wa x na hakuna majibu halisi. Mizizi ni nambari changamani zinazotumia i, ambapo i² = −1 — kwa mfano, x² + 1 = 0 ina mizizi x = i na x = −i. Kitatuzi hiki huwaonyesha na bado huwaangalia.

Jinsi inavyofanya kazi — mbinu

Milinganyo ya mstari hutatuliwa kwa kuweka mlinganyo ukiwa na uwiano — chochote unachofanya kwa upande mmoja, unakifanya kwa mwingine. Kwanza maneno ya x hukusanywa kushoto (toa cx kutoka pande zote mbili), kisha maneno ya nambari kulia (toa b), na mwishowe pande zote mbili hugawanywa kwa kigawe cha x.

Miliganu ya quadratic tumia fomula ya quadratic. Kwa ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

Sehemu iliyo chini ya mzizi, D = b² − 4ac, huitwa kibaguzi, na inakuambia aina ya jibu kabla hujamaliza: D > 0 inamaanisha mizizi miwili tofauti halisi, D = 0 inamaanisha mzizi mmoja uliorudiwa, na D < 0 inamaanisha mizizi miwili changamano na hakuna jibu halisi.

Mfano uliofanyiwa kazi

Mfano: Tatua x² − 5x + 6 = 0. Hapa a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, hivyo √D = 1. Kisha x = (5 + 1) ÷ 2 = 3 au x = (5 − 1) ÷ 2 = 2. Kagua x = 3: 9 − 15 + 6 = 0 ✓

Maswali yanayoulizwa mara kwa mara

Ninawezaje kuweka mlinganyo wenye kipengele kilichokosekana?

Weka 0 kwa kigawo kinachokosekana. x² − 9 = 0 huwa a = 1, b = 0, c = −9, na kisuluhishi hutoa x = 3 au x = −3. Kwa mlinganyo wa mstari kama 2x = 10, hiyo ni a = 2, b = 0, c = 0, d = 10.

Je, ikiwa nitaandika a = 0 katika kitatua cha quadratic?

Kisha kiunga cha x² kinatoweka na mlinganyo ni wa mstari (linear) kweli. Kitatua hutambua hili na kuutatua kama mlinganyo wa mstari badala yake, kikiwa kinakuambia kuwa ndivyo ilivyotokea.

Kwa nini kitatua hukagua jibu lake mwishoni?

Kurudisha jibu katika mlinganyo wa awali ndiyo njia yenye uhakika zaidi ya kukamata kosa: ikiwa pande zote mbili zinatoka sawa, jibu ni sahihi kwa hakika. Ni tabia nzuri kwa kazi ya nyumbani pia — waalimu mara nyingi hutoa alama za mbinu kwa ukaguzi unaoonekana.
