🎱 Bingo Number Caller

Run a bingo night without a cage: choose 75-ball (American B-I-N-G-O columns) or 90-ball (British) mode, press Call Next Number, and the caller draws each number exactly once and keeps the full called board up to date.

Quick answer: In 75-ball bingo, numbers belong to letter columns: B = 1–15, I = 16–30, N = 31–45, G = 46–60, O = 61–75. A fair caller draws without replacement, so all 75 numbers appear exactly once in a full game.
Press Start / Reset, then Call Next Number

How to use the Bingo Number Caller

  1. Choose 75-ball or 90-ball mode and press Start / Reset.
  2. Press Call Next Number for each draw — the big display shows the current ball and its letter (75-ball).
  3. Check the called board to verify any player's claim; the counter shows how many numbers remain.
Example: A 75-ball game: the first calls might be B-7, O-68, N-33 — each from its own column range, and none of them can be called again in the same game.

Frequently Asked Questions

What is the difference between 75-ball and 90-ball bingo?

75-ball (common in North America) uses numbers 1–75 in five letter columns and cards with a free centre square. 90-ball (common in the UK and Europe) uses 1–90 with tickets of three rows. The caller mechanics are the same: draw without replacement.

Are the draws fair?

Yes. Each draw picks uniformly at random from the numbers not yet called, using crypto-grade randomness — exactly like balls drawn from a cage, with no repeats possible.

Can I go back if I mis-call a number?

The caller does not remove called numbers (real cages cannot undraw either) — use Reset to start a fresh game if a call goes wrong early.

Does it work offline for a hall or classroom?

Once the page has loaded, everything runs locally in the browser — no connection is needed during the game.

How it works — the formula

The caller keeps the set of uncalled numbers and, on each call, selects one uniformly at random and removes it — sampling without replacement. The probability that a given remaining number is called next is 1 ÷ (numbers remaining). In 75-ball mode the letter is fixed by range: letter index = floor((n − 1) ÷ 15) into B, I, N, G, O.

Worked example

Example: the number 33 in 75-ball mode: (33 − 1) ÷ 15 = 2.13, floor = 2 → the third letter, N. So 33 is always called as 'N-33'. The number 68: (68 − 1) ÷ 15 = 4.47, floor 4 → O, called 'O-68'.

Check: B covers 1–15, I 16–30, N 31–45 (33 ✓), G 46–60, O 61–75 (68 ✓).
