📉 Calculator de pantă

Introduceți două puncte (x₁, y₁) și (x₂, y₂) pentru a obține totul despre dreapta dintre ele: panta, distanța, punctul mijlociu, unghiul și ecuația y = mx + b — cu înlocuirea fiecărei formule afișată.

Răspuns rapid: Pantă = (y₂ − y₁) ÷ (x₂ − x₁). Pentru (1, 2) și (4, 8): panta = 6 ÷ 3 = 2, distanța = √(3² + 6²) = √45 ≈ 6.71, iar punctul de mijloc este (2.5, 5).

Cum se folosește Calculatorul de pantă

  1. Introduceți coordonatele primului punct.
  2. Introduceți coordonatele celui de-al doilea punct.
  3. Citește panta, distanța, punctul de mijloc și ecuația dreptei.
Exemplu: Punctele (1, 2) și (4, 8): panta 2, distanța √45 ≈ 6.708, punctul de mijloc (2.5, 5) și ecuația dreptei y = 2x + 0 — trece prin origine, ceea ce poți verifica: la x = 1, y = 2 ✓.

Întrebări frecvente

Ce înseamnă o pantă de 2?

Pentru fiecare 1 unitate cu care vă deplasați la dreapta, dreapta urcă 2 unități. O pantă de 0 este orizontală, o pantă negativă coboară spre dreapta, iar o pantă nedefinită (împărțire la zero) este o dreaptă verticală.

Cum se calculează distanța dintre două puncte?

Cu Pitagora: distanța = √((x₂ − x₁)² + (y₂ − y₁)²). Diferențele de coordonate sunt cele două catete ale unui triunghi dreptunghic, iar distanța este ipotenuza lui.

Care este formula punctului de mijloc?

Mediați coordonatele: punctul de mijloc = ((x₁ + x₂) ÷ 2, (y₁ + y₂) ÷ 2). Este punctul aflat exact la jumătatea segmentului.

Ce se întâmplă dacă ambele valori x sunt aceleași?

Linia este verticală: panta este nedefinită și nu există nicio ecuație y = mx + b. Calculatorul raportează linia verticală x = acea valoare, plus distanța și punctul de mijloc ca de obicei.

Cum funcționează — formula

Pantă: m = (y₂ − y₁) ÷ (x₂ − x₁). Distanță: d = √((x₂ − x₁)² + (y₂ − y₁)²). Punct de mijloc: ((x₁ + x₂) ÷ 2, (y₁ + y₂) ÷ 2). Ecuația dreptei: folosind punctul 1, b = y₁ − m·x₁, obținând y = mx + b. Unghi: θ = arctan(m), în grade de la axa x pozitivă.

Exemplu rezolvat

Intrări: (1, 2) și (4, 8).

Pași: Pantă = (8 − 2) ÷ (4 − 1) = 6 ÷ 3 = 2. Distanță = √((4−1)² + (8−2)²) = √(9 + 36) = √45 = 6.708. Punct de mijloc = ((1+4)÷2, (2+8)÷2) = (2.5, 5). Intersecție: b = 2 − 2×1 = 0, așa că dreapta este y = 2x.

Rezultat: Pantă 2, distanța 6.708, punctul de mijloc (2.5, 5), ecuația y = 2x.
