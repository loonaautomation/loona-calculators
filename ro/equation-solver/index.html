Rezolvator de ecuații (liniare și pătratice)

Rezolvă ecuații liniare (ax + b = cx + d) și ecuații pătratice (ax² + bx + c = 0) cu fiecare pas afișat — inclusiv discriminantul, rădăcinile repetate și complexe și o verificare finală care înlocuiește răspunsul înapoi.

Introduceți cele patru numere în ax + b = cx + d. Folosiți 0 acolo unde lipsește un termen — de exemplu, 2x + 3 = 7 înseamnă a = 2, b = 3, c = 0, d = 7.

Introduceți cei trei coeficienți în ax² + bx + c = 0. Folosiți 0 acolo unde lipsește un termen — de exemplu, x² − 9 = 0 înseamnă a = 1, b = 0, c = −9.

Cum se folosește Rezolvatorul de ecuații

  1. Alegeți tipul de ecuație: liniară (doar x) sau pătratică (x²).
  2. Tastează coeficienții — numerele din fața lui x² și x, și numărul simplu. Introdu 0 pentru orice termen lipsă.
  3. Apasă Rezolvă cu pași și citește rezolvarea rând cu rând. Ultimul pas verifică răspunsul, înlocuindu-l înapoi în ecuația originală.
Exemplu: 3x + 2 = x + 10. Mutați termenii cu x la stânga: 2x + 2 = 10. Mutați numărul la dreapta: 2x = 8. Împărțiți la 2: x = 4. Verificare: 3 × 4 + 2 = 14 și 4 + 10 = 14 ✓

Întrebări frecvente

Ce tipuri de ecuații poate rezolva acest rezolvator?

Ecuații liniare de forma ax + b = cx + d și ecuații pătratice de forma ax² + bx + c = 0. Arată fiecare pas, discriminantul pentru cele pătratice și o verificare finală. Nu rezolvă ecuații cubice, sisteme de ecuații cu două necunoscute sau inecuații — titlul paginii spune exact ce acoperă.

Ce înseamnă "nicio soluție" sau "infinit de multe soluții"?

Uneori termenii x se anulează complet. Dacă și numerele se potrivesc (ca 5x + 1 = 5x + 1), ecuația este întotdeauna adevărată — infinit de multe soluții. Dacă numerele nu se potrivesc (5x + 1 = 5x + 3), ea nu poate fi niciodată adevărată — nicio soluție. Rezolvitorul îți spune sincer ce caz ai, în loc să inventeze un răspuns.

Ce sunt rădăcinile complexe?

Când discriminantul unei ecuații pătratice (b² − 4ac) este negativ, graficul nu intersectează niciodată axa x și nu există răspunsuri reale. Rădăcinile sunt atunci numere complexe folosind i, unde i² = −1 — de exemplu, x² + 1 = 0 are rădăcinile x = i și x = −i. Acest rezolvator le arată și totuși le verifică.

Cum funcționează — metoda

Ecuații liniare sunt rezolvate păstrând ecuația în echilibru — orice faci unei părți, faci și celeilalte. Mai întâi termenii cu x sunt adunați la stânga (scade cx din ambele părți), apoi termenii numerici la dreapta (scade b), iar la final ambele părți sunt împărțite la coeficientul lui x.

Ecuații pătratice folosește formula pătratică. Pentru ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

Partea de sub rădăcină, D = b² − 4ac, se numește discriminant și vă spune tipul răspunsului înainte să terminați: D > 0 înseamnă două rădăcini reale diferite, D = 0 înseamnă o rădăcină dublă, iar D < 0 înseamnă două rădăcini complexe și niciun răspuns real.

Exemplu rezolvat

Exemplu: Rezolvă x² − 5x + 6 = 0. Aici a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, așa că √D = 1. Apoi x = (5 + 1) ÷ 2 = 3 sau x = (5 − 1) ÷ 2 = 2. Verificare x = 3: 9 − 15 + 6 = 0 ✓

Întrebări frecvente

Cum introduc o ecuație cu un termen lipsă?

Introduceți 0 pentru coeficientul lipsă. x² − 9 = 0 devine a = 1, b = 0, c = −9, iar rezolvatorul dă x = 3 sau x = −3. Pentru o ecuație liniară ca 2x = 10, aceasta este a = 2, b = 0, c = 0, d = 10.

Ce se întâmplă dacă tastez a = 0 în rezolvatorul pătratic?

Atunci termenul x² dispare și ecuația este de fapt liniară. Rezolvatorul observă acest lucru și o rezolvă ca pe o ecuație liniară în schimb, spunându-ți că asta s-a întâmplat.

De ce își verifică rezolvatorul răspunsul la final?

Înlocuirea răspunsului înapoi în ecuația inițială este cel mai sigur mod de a prinde o greșeală: dacă ambele părți ies egale, răspunsul este cu siguranță corect. Este un obicei bun și pentru temele de acasă — profesorii acordă adesea puncte pentru metodă pentru o verificare vizibilă.
