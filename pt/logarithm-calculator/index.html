log Calculadora de Logaritmos

Encontrar logaritmo de qualquer número para qualquer base — e obter comum logaritmo, natural logaritmo (ln) e binário logaritmo alongside isto, cada um verified por raising base atrás para resposta (antilog).

Como utilizar a Calculadora de Logaritmos

  1. Introduza o número x whose logaritmo querer. Isto deve ser greater do que 0.
  2. Introduza o base b — ou toque Base 10, Base 2 ou Base e. base deve ser greater do que 0 e não igual para 1.
  3. Prima Calcular. Obtém o logaritmo na sua base mais o logaritmo comum (base 10), o logaritmo natural (base e) e o logaritmo binário (base 2), e uma verificação de antilogaritmo que eleva a base de volta à resposta.
Exemplo: log2(32) = 5, porque 25 = 32. E log10(1000) = 3, porque 103 = 1000.

Frequently Asked Perguntas

O que é um logaritmo, em palavras simples?

Um logaritmo responde à pergunta: "A que potência tenho de elevar a base para obter este número?" log10(1000) = 3 porque 10 elevado à potência 3 é 1000. É o oposto (inverso) de uma potência, tal como a divisão é o oposto da multiplicação.

Qual é a diferença entre log e ln?

"log" na maioria das calculadoras significa base 10 — o logaritmo comum. "ln" significa base e (e ≈ 2.71828) — o logaritmo natural, usado em toda a ciência e nas finanças. Esta calculadora fornece ambos, além da base 2 (o logaritmo binário usado em computação), para qualquer número introduzido.

Porque é que não posso tirar o logaritmo de 0 ou de um número negativo?

Porque nenhuma potência de uma base positiva pode alguma vez produzir 0 ou um resultado negativo: 10 elevado a qualquer potência é sempre positivo. Assim, para os números reais, o logaritmo de 0 ou de um número negativo é indefinido, e a calculadora indica-o em vez de mostrar uma resposta inventada.

Como funciona — a fórmula

Definição: logb(x) = y exatamente quando by = x. O logaritmo e a potência são dois lados do mesmo facto.

Mudança de base: a maioria das calculadoras só tem as teclas log (base 10) e ln (base e). Para encontrar um logaritmo em qualquer outra base, divida:

logb(x) = ln(x) ÷ ln(b) = log10(x) ÷ log10(b)

Essa regra de mudança de base é a que esta página usa internamente, pelo que a resposta obtida para a base b é a mesma que se obteria passo a passo à mão.

Antilog: o antilogaritmo de y na base b é simplesmente by — desfaz o logaritmo. Se log10(1000) = 3, então o antilogaritmo de 3 é 103 = 1000. Todos os resultados nesta página são verificados desta forma antes de serem vistos.

Exemplo prático

Exemplo: Encontrar logaritmo2(32) por mudança de base. ln(32) ≈ 3.4657 e ln(2) ≈ 0.6931. Dividir: 3.4657 ÷ 0.6931 = 5. Verifique com o antilogaritmo: 25 = 32 ✓

Frequently asked perguntas

Quanto é o logaritmo de 1 em qualquer base?

Sempre 0, porque qualquer base elevada à potência 0 é igual a 1: b0 = 1. Da mesma forma, logb(b) é sempre 1, porque b1 = b.

Porque é que a base não pode ser 1?

Porque 1 elevado a qualquer potência é sempre 1, pelo que «a que potência devo elevar 1 para obter 100?» não tem resposta alguma — e, para o próprio número 1, teria infinitas. A base 1 é, por isso, excluída, tal como a base 0 e as bases negativas no trabalho com números reais.

Onde são utilizados os logaritmos na vida real?

Onde quer que as quantidades cresçam por multiplicação: intensidade de sismos (escala de Richter), intensidade do som (decibéis), acidez (pH), juros compostos e cálculos de semivida, e o logaritmo binário na informática (quantos bits, ou quantas divisões ao meio, um conjunto de dados precisa).
