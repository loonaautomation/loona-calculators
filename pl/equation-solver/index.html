Solwer równań (liniowe i kwadratowe)

Rozwiązuj równania liniowe (ax + b = cx + d) i równania kwadratowe (ax² + bx + c = 0) z każdym pokazanym krokiem — w tym wyróżnik, pierwiastki wielokrotne i zespolone oraz końcowe sprawdzenie, które podstawia odpowiedź z powrotem.

Wpisz cztery liczby w ax + b = cx + d. Użyj 0 tam, gdzie brakuje wyrazu — na przykład 2x + 3 = 7 to a = 2, b = 3, c = 0, d = 7.

Wpisz trzy współczynniki w ax² + bx + c = 0. Użyj 0 tam, gdzie brakuje wyrazu — na przykład x² − 9 = 0 to a = 1, b = 0, c = −9.

Jak korzystać z rozwiązywania równań

  1. Wybierz typ równania: liniowe (tylko x) lub kwadratowe (x²).
  2. Wpisz współczynniki — liczby przed x² i x oraz liczbę zwykłą. Wpisz 0 dla każdego brakującego wyrazu.
  3. Naciśnij Rozwiąż z krokami i czytaj rozwiązywanie linia po linii. Ostatni krok sprawdza odpowiedź, podstawiając ją z powrotem do pierwotnego równania.
Przykład: 3x + 2 = x + 10. Przenieś wyrazy z x na lewo: 2x + 2 = 10. Przenieś liczbę na prawo: 2x = 8. Podziel przez 2: x = 4. Sprawdzenie: 3 × 4 + 2 = 14 i 4 + 10 = 14 ✓

Najczęściej zadawane pytania

Jakie rodzaje równań obsługuje ten solwer?

Równania liniowe w postaci ax + b = cx + d oraz równania kwadratowe w postaci ax² + bx + c = 0. Pokazuje każdy krok, wyróżnik dla równań kwadratowych i końcowe sprawdzenie. Nie rozwiązuje równań sześciennych, układów równań z dwiema niewiadomymi ani nierówności — tytuł strony mówi dokładnie, co obejmuje.

Co oznacza „brak rozwiązania” lub „nieskończenie wiele rozwiązań”?

Czasem wyrazy z x skracają się całkowicie. Jeśli liczby też się zgadzają (jak 5x + 1 = 5x + 1), równanie jest zawsze prawdziwe — nieskończenie wiele rozwiązań. Jeśli liczby się nie zgadzają (5x + 1 = 5x + 3), nigdy nie może być prawdziwe — brak rozwiązania. Kalkulator uczciwie mówi, który przypadek występuje, zamiast wymyślać odpowiedź.

Czym są pierwiastki zespolone?

Gdy wyróżnik równania kwadratowego (b² − 4ac) jest ujemny, wykres nigdy nie przecina osi x i nie ma rzeczywistych odpowiedzi. Pierwiastki są wtedy liczbami zespolonymi używającymi i, gdzie i² = −1 — na przykład x² + 1 = 0 ma pierwiastki x = i oraz x = −i. Ten solwer pokazuje je i nadal je sprawdza.

Jak to działa — metoda

Równania liniowe są rozwiązywane przez utrzymywanie równania w równowadze — cokolwiek robisz z jedną stroną, robisz z drugą. Najpierw wyrazy z x są zbierane po lewej (odejmij cx od obu stron), potem wyrazy liczbowe po prawej (odejmij b), a na końcu obie strony są dzielone przez współczynnik przy x.

Równania kwadratowe użyj wzoru kwadratowego. Dla ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

Część pod pierwiastkiem, D = b² − 4ac, nazywa się dyskryminantem i mówi ci, jaki rodzaj odpowiedzi otrzymasz, zanim skończysz: D > 0 oznacza dwa różne pierwiastki rzeczywiste, D = 0 oznacza jeden pierwiastek podwójny, a D < 0 oznacza dwa pierwiastki zespolone i brak rzeczywistej odpowiedzi.

Opracowany przykład

Przykład: Rozwiąż x² − 5x + 6 = 0. Tutaj a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, więc √D = 1. Potem x = (5 + 1) ÷ 2 = 3 lub x = (5 − 1) ÷ 2 = 2. Sprawdzenie dla x = 3: 9 − 15 + 6 = 0 ✓

Najczęściej zadawane pytania

Jak wpisać równanie z brakującym wyrazem?

Wpisz 0 dla brakującego współczynnika. x² − 9 = 0 staje się a = 1, b = 0, c = −9, a solver daje x = 3 lub x = −3. Dla równania liniowego jak 2x = 10, to jest a = 2, b = 0, c = 0, d = 10.

A jeśli wpiszę a = 0 w solwerze kwadratowym?

Wtedy wyraz x² znika i równanie jest naprawdę liniowe. Solver to zauważa i rozwiązuje je jako równanie liniowe, mówiąc Ci, że tak się stało.

Dlaczego solwer sprawdza swoją odpowiedź na końcu?

Podstawienie odpowiedzi z powrotem do pierwotnego równania to najpewniejszy sposób wyłapania błędu: jeśli obie strony wyjdą równe, odpowiedź jest na pewno prawidłowa. To też dobry nawyk przy zadaniach domowych — nauczyciele często przyznają punkty za metodę przy widocznym sprawdzeniu.
