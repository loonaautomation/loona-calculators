সমীকরণ সমাধানকারী (সরল ও দ্বিঘাত)

প্রতিটি ধাপ দেখিয়ে রৈখিক সমীকরণ (ax + b = cx + d) এবং দ্বিঘাত সমীকরণ (ax² + bx + c = 0) সমাধান করুন — যার মধ্যে রয়েছে নিশ্চায়ক, পুনরাবৃত্ত ও জটিল মূল, এবং উত্তরটি আবার বসিয়ে করা একটি চূড়ান্ত যাচাই।

চারটি সংখ্যা লিখুন ax + b = cx + d। কোনো পদ অনুপস্থিত থাকলে সেখানে 0 ব্যবহার করুন — যেমন, 2x + 3 = 7 হলো a = 2, b = 3, c = 0, d = 7।

তিনটি সহগ লিখুন ax² + bx + c = 0। কোনো পদ অনুপস্থিত থাকলে সেখানে 0 ব্যবহার করুন — যেমন, x² − 9 = 0 হলো a = 1, b = 0, c = −9।

কীভাবে সমীকরণ সমাধানকারী ব্যবহার করবেন

  1. সমীকরণের ধরন বেছে নিন: রৈখিক (শুধু x) অথবা দ্বিঘাত (x²)।
  2. সহগগুলো লিখুন — x² ও x-এর সামনের সংখ্যা, এবং সরল সংখ্যাটি। কোনো পদ অনুপস্থিত থাকলে 0 দিন।
  3. ধাপসহ Solve চাপুন এবং ধাপে ধাপে হিসাবটি পড়ুন। শেষ ধাপে উত্তরটি মূল সমীকরণে বসিয়ে দিয়ে তা যাচাই করা হয়।
উদাহরণ: 3x + 2 = x + 10। x-এর পদগুলো বামে নিন: 2x + 2 = 10। সংখ্যাটি ডানে নিন: 2x = 8। 2 দিয়ে ভাগ করুন: x = 4। যাচাই করুন: 3 × 4 + 2 = 14 এবং 4 + 10 = 14 ✓

সচরাচর জিজ্ঞাসিত প্রশ্নাবলী

এই সমাধানকারী কোন ধরনের সমীকরণ সামলাতে পারে?

ax + b = cx + d আকারের রৈখিক সমীকরণ এবং ax² + bx + c = 0 আকারের দ্বিঘাত সমীকরণ। এতে প্রতিটি ধাপ, দ্বিঘাতের জন্য নিশ্চায়ক (ডিসক্রিমিন্যান্ট) এবং শেষে যাচাই দেখানো হয়। এটি ঘন সমীকরণ, দুই অজানা রাশির যুগপৎ সমীকরণ বা অসমতা সমাধান করে না — পৃষ্ঠার শিরোনামেই ঠিক বলা আছে এটি কী কী করে।

"no solution" বা "infinitely many solutions" বলতে কী বোঝায়?

কখনো কখনো x পদগুলো পুরোপুরি কেটে যায়। সংখ্যাগুলোও যদি মিলে যায় (যেমন 5x + 1 = 5x + 1), সমীকরণটি সবসময় সত্য — অসীম সংখ্যক সমাধান। সংখ্যাগুলো না মিললে (5x + 1 = 5x + 3) এটি কখনোই সত্য হতে পারে না — কোনো সমাধান নেই। উত্তর বানিয়ে দেওয়ার বদলে সমাধানকারী সৎভাবে আপনাকে জানিয়ে দেয়, আপনার ক্ষেত্রে কোনটি প্রযোজ্য।

জটিল মূল কী?

যখন একটি দ্বিঘাত সমীকরণের ডিসক্রিমিন্যান্ট (b² − 4ac) ঋণাত্মক হয়, তখন লেখচিত্রটি কখনো x-অক্ষকে ছেদ করে না এবং কোনো বাস্তব উত্তর থাকে না। তখন মূলগুলো i ব্যবহার করে জটিল সংখ্যা হয়, যেখানে i² = −1 — উদাহরণস্বরূপ, x² + 1 = 0-এর মূল x = i এবং x = −i। এই সমাধানকারী সেগুলো দেখায় এবং তবুও সেগুলো যাচাই করে।

এটি কীভাবে কাজ করে — পদ্ধতিটি

রৈখিক সমীকরণসমূহ সমীকরণটিকে ভারসাম্যপূর্ণ রেখে সমাধান করা হয় — এক পাশে আপনি যা করেন, অন্য পাশেও তাই করেন। প্রথমে x পদগুলো বাম দিকে জড়ো করা হয় (উভয় পাশ থেকে cx বিয়োগ করে), তারপর সংখ্যার পদগুলো ডান দিকে (b বিয়োগ করে), এবং অবশেষে উভয় পাশকে x-এর সহগ দিয়ে ভাগ করা হয়।

দ্বিঘাত সমীকরণ দ্বিঘাত সূত্রটি ব্যবহার করুন। ax² + bx + c = 0-এর জন্য:

x = (−b ± √(b² − 4ac)) ÷ (2a)

মূলের নিচের অংশটি, D = b² − 4ac, -কে বলা হয় ডিসক্রিমিন্যান্ট, এবং এটি শেষ করার আগেই আপনাকে উত্তরের ধরনটি বলে দেয়: D > 0 মানে দুটি আলাদা বাস্তব মূল, D = 0 মানে একটি পুনরাবৃত্ত মূল, এবং D < 0 মানে দুটি জটিল মূল এবং কোনো বাস্তব উত্তর নেই।

সমাধান করা উদাহরণ

উদাহরণ: x² − 5x + 6 = 0 সমাধান করুন। এখানে a = 1, b = −5, c = 6। D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, তাই √D = 1। তারপর x = (5 + 1) ÷ 2 = 3 or x = (5 − 1) ÷ 2 = 2। যাচাই করুন x = 3: 9 − 15 + 6 = 0 ✓

সচরাচর জিজ্ঞাসিত প্রশ্ন

কোনো একটি পদ বাদ থাকলে আমি কীভাবে একটি সমীকরণ লিখব?

অনুপস্থিত সহগের জন্য 0 লিখুন। x² − 9 = 0 হয়ে যায় a = 1, b = 0, c = −9, এবং সমাধানকারী দেয় x = 3 অথবা x = −3। 2x = 10-এর মতো একটি সরল সমীকরণের ক্ষেত্রে তা হলো a = 2, b = 0, c = 0, d = 10।

আমি দ্বিঘাত সমাধানকারীতে a = 0 লিখলে কী হবে?

তখন x² পদটি অদৃশ্য হয়ে যায় এবং সমীকরণটি আসলে রৈখিক। সমাধানকারী এটি লক্ষ্য করে এবং বদলে এটিকে একটি রৈখিক সমীকরণ হিসেবে সমাধান করে, আপনাকে জানিয়ে যে তা-ই ঘটেছে।

সমাধানকারী শেষে তার উত্তর যাচাই করে কেন?

উত্তরটি মূল সমীকরণে আবার বসানোই ভুল ধরার সবচেয়ে নিশ্চিত উপায়: দুই পাশ সমান এলে উত্তরটি অবশ্যই ঠিক। এটি বাড়ির কাজের জন্যও একটি ভালো অভ্যাস — শিক্ষকেরা প্রায়ই দৃশ্যমান যাচাইয়ের জন্য পদ্ধতির নম্বর দেন।
