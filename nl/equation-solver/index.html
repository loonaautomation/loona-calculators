Vergelijkingsoplosser (Lineair & Kwadratisch)

Los lineaire vergelijkingen (ax + b = cx + d) en kwadratische vergelijkingen (ax² + bx + c = 0) op met elke stap weergegeven — inclusief de discriminant, herhaalde en complexe wortels, en een laatste controle die het antwoord weer invult.

Voer de vier getallen in ax + b = cx + d. Gebruik 0 waar een term ontbreekt — bijvoorbeeld: 2x + 3 = 7 is a = 2, b = 3, c = 0, d = 7.

Voer de drie coëfficiënten in ax² + bx + c = 0. Gebruik 0 waar een term ontbreekt — bijvoorbeeld: x² − 9 = 0 is a = 1, b = 0, c = −9.

Hoe je de Vergelijkingsoplosser gebruikt

  1. Kies het type vergelijking: lineair (alleen x) of kwadratisch (x²).
  2. Typ de coëfficiënten in — de getallen vóór x² en x, en het gewone getal. Voer 0 in voor elke ontbrekende term.
  3. Druk op Oplossen met stappen en lees de uitwerking regel voor regel. De laatste stap controleert het antwoord door het terug te plaatsen in de oorspronkelijke vergelijking.
Voorbeeld: 3x + 2 = x + 10. Breng de termen met x naar links: 2x + 2 = 10. Breng het getal naar rechts: 2x = 8. Deel door 2: x = 4. Controleer: 3 × 4 + 2 = 14 en 4 + 10 = 14 ✓

Veelgestelde vragen

Welke soorten vergelijkingen kan deze oplosser aan?

Lineaire vergelijkingen in de vorm ax + b = cx + d, en kwadratische vergelijkingen in de vorm ax² + bx + c = 0. De tool toont elke stap, de discriminant voor kwadratische vergelijkingen, en een eindcontrole. Hij lost geen derdegraadsvergelijkingen, stelsels van vergelijkingen met twee onbekenden of ongelijkheden op — de paginatitel zegt precies wat hij dekt.

Wat betekent "geen oplossing" of "oneindig veel oplossingen"?

Soms vallen de x-termen volledig weg. Als de getallen ook overeenkomen (zoals 5x + 1 = 5x + 1) is de vergelijking altijd waar — oneindig veel oplossingen. Als de getallen niet overeenkomen (5x + 1 = 5x + 3) kan hij nooit waar zijn — geen oplossing. De oplosser vertelt je eerlijk welk geval je hebt, in plaats van een antwoord te verzinnen.

Wat zijn complexe wortels?

Wanneer de discriminant (b² − 4ac) van een kwadratische vergelijking negatief is, kruist de grafiek nooit de x-as en zijn er geen reële antwoorden. De wortels zijn dan complexe getallen met i, waarbij i² = −1 — bijvoorbeeld, x² + 1 = 0 heeft wortels x = i en x = −i. Deze oplosser toont ze en controleert ze nog steeds.

Hoe het werkt — de methode

Lineaire vergelijkingen worden opgelost door de vergelijking in evenwicht te houden — wat je aan de ene kant doet, doe je ook aan de andere kant. Eerst worden de x-termen links verzameld (trek cx van beide kanten af), daarna de getaltermen rechts (trek b af), en tot slot worden beide kanten gedeeld door de coëfficiënt van x.

Kwadratische vergelijkingen gebruik de kwadratische formule. Voor ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

Het deel onder de wortel, D = b² − 4ac, wordt de discriminant genoemd, en die vertelt je al vóór je klaar bent wat voor antwoord je krijgt: D > 0 betekent twee verschillende reële wortels, D = 0 betekent één herhaalde wortel, en D < 0 betekent twee complexe wortels en geen reëel antwoord.

Uitgewerkt voorbeeld

Voorbeeld: Los x² − 5x + 6 = 0 op. Hier is a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, dus √D = 1. Dan is x = (5 + 1) ÷ 2 = 3 of x = (5 − 1) ÷ 2 = 2. Controleer x = 3: 9 − 15 + 6 = 0 ✓

Veelgestelde vragen

Hoe voer ik een vergelijking in waarin een term ontbreekt?

Voer 0 in voor de ontbrekende coëfficiënt. x² − 9 = 0 wordt a = 1, b = 0, c = −9, en de oplosser geeft x = 3 of x = −3. Voor een lineaire vergelijking zoals 2x = 10 is dat a = 2, b = 0, c = 0, d = 10.

Wat als ik a = 0 typ in de kwadratische oplosser?

Dan verdwijnt de x²-term en is de vergelijking eigenlijk lineair. De oplosser merkt dit op en lost hem in plaats daarvan op als een lineaire vergelijking, en vertelt je dat dat is gebeurd.

Waarom controleert de oplosser aan het einde zijn antwoord?

Het antwoord terug invullen in de oorspronkelijke vergelijking is de zekerste manier om een fout te ontdekken: als beide kanten gelijk uitkomen, is het antwoord zeker goed. Het is ook een goede gewoonte voor huiswerk — docenten geven vaak punten voor de methode als er een zichtbare controle staat.
