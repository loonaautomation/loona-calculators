📐 Калькулятор теоремы Пифагора

Введите любые две стороны прямоугольного треугольника, и калькулятор найдёт третью сторону по теореме Пифагора, показывая полную подстановку, чтобы ученики могли проследить каждый шаг.

Быстрый ответ: Теорема Пифагора гласит: a² + b² = c² для прямоугольного треугольника, где c — гипотенуза. Классический пример — 3-4-5: 9 + 16 = 25, значит гипотенуза равна 5.

Как использовать калькулятор теоремы Пифагора

  1. Введите две стороны, которые вы знаете (оставьте неизвестную сторону пустой или установите её равной 0).
  2. Если вы знаете гипотенузу, введите её как c.
  3. Нажмите «Рассчитать» — недостающая сторона и полный расчёт появятся.
Пример: Катеты 6 и 8: c = √(36 + 64) = √100 = 10. При гипотенузе 13 и катете 5: другой катет = √(169 − 25) = √144 = 12.

Часто задаваемые вопросы

Какая сторона является гипотенузой?

Сторона, противоположная прямому углу, — всегда самая длинная сторона, здесь обозначенная c. Две другие стороны (катеты) — a и b.

Как найти катет, а не гипотенузу?

Переставьте теорему: a = √(c² − b²). Гипотенуза должна быть длиннее любого катета; если это не так, треугольник не может быть прямоугольным с такими сторонами, и калькулятор так и говорит.

Работает ли он для непрямоугольных треугольников?

Нет. Теорема верна только для прямоугольных треугольников. Для других треугольников нужен закон косинусов — калькулятор тригонометрии на этом сайте может помочь с углами и соотношениями.

Почему треугольники 3-4-5 встречаются повсюду?

Потому что 3² + 4² = 5² в точности, строители и плотники тысячи лет использовали верёвку или ленту 3-4-5, чтобы отмечать настоящие прямые углы. Другие тройки целых чисел включают 5-12-13, 8-15-17 и 7-24-25.

Как это работает — формула

a² + b² = c². Нахождение гипотенузы: c = √(a² + b²). Нахождение катета: a = √(c² − b²) или b = √(c² − a²). Должны быть заданы ровно две стороны; третья выводится, а катет можно найти только тогда, когда гипотенуза — самая длинная сторона.

Разобранный пример

Исходные данные: гипотенуза c = 13, катет a = 5, найдите b.

Шаги: b = √(c² − a²) = √(169 − 25) = √144 = 12.

Результат: b = 12 — тройка 5-12-13.
