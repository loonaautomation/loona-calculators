👥 Генератор случайных команд

Вставьте список имён, выберите, сколько команд вы хотите, и получите честное случайное разделение. Размеры команд отличаются не более чем на одного человека, и каждый размещается ровно один раз.

Быстрый ответ: Генератор случайных команд честно перемешивает полный список, а затем распределяет людей по командам по одному, поэтому при 20 людях и 4 командах вы получаете 4 команды по 5 — размеры никогда не различаются больше чем на одного.

Как использовать генератор случайных команд

  1. Вставьте имена, по одному на строку.
  2. Выберите число команд.
  3. Нажмите «Сгенерировать команды».
  4. Нажмите ещё раз для новой перетасовки или скопируйте команды из поля результата.
Пример: 10 имён, разделённых на 3 команды, дают размеры команд 4, 3 и 3 — сбалансированы автоматически, при этом каждое имя используется ровно один раз.

Часто задаваемые вопросы

Как обеспечивается равенство команд?

Список перемешивается перемешиванием Фишера — Йейтса, управляемым защищёнными случайными числами, а затем раздаётся по кругу командам. Поэтому размеры различаются не более чем на единицу, и каждая позиция одинаково вероятна для всех.

Что, если имена не делятся ровно?

Первые команды получают одного дополнительного человека. При 10 людях и 3 командах размеры составляют 4, 3, 3 — никогда не 5, 3, 2.

Могу ли я вместо этого создать команды фиксированного размера?

Выберите число команд, которое даёт ваш размер: для команд по 4 человека при 20 людях выберите 5 команд.

Разрешены ли повторяющиеся имена?

Они рассматриваются как отдельные записи, поэтому два человека с одинаковым первым именем будут размещены оба. Добавьте фамилию или инициал, чтобы различать их.

Как это работает — формула

Генератор использует Перемешивание Фишера–Йетса: для каждой позиции от конца списка поменяйте её местами с равномерно случайной более ранней позицией (используя случайность криптографического уровня). Тогда каждый порядок списка равновероятен. Перемешанный список раздаётся по одному командам 1, 2, … N, 1, 2, … поэтому размеры команд составляют либо ⌊всего ÷ N⌋, либо ⌈всего ÷ N⌉ — никогда не различаясь больше чем на одного.

Разобранный пример

Исходные данные: 10 имён, 3 команды.

Шаги: После перемешивания имена распределяются по позициям: команда 1 получает перемешанные имена 1, 4, 7, 10 (4 человека); команда 2 получает имена 2, 5, 8 (3 человека); команда 3 получает имена 3, 6, 9 (3 человека). 4 + 3 + 3 = 10 — каждый распределён один раз.

Результат: Сбалансированные команды из 4, 3 и 3.
