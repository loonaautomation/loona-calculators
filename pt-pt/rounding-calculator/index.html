🎯 Calculadora de Arredondamento

Arredonde qualquer número da forma escolar padrão — metade para cima — para um número escolhido de casas decimais, para a dezena, centena ou milhar mais próximos, ou para um número definido de algarismos significativos.

Resposta rápida: O arredondamento observa o primeiro algarismo a eliminar: 5 ou mais arredonda para cima, menos de 5 arredonda para baixo. Assim, 1,234.5678 arredonda para 1,234.57 com 2 casas decimais, para 1,230 com arredondamento a múltiplos de 10, para 1,200 com arredondamento a múltiplos de 100 e para 1,235 com 4 algarismos significativos.

Como utilizar a Calculadora de Arredondamento

  1. Introduza o número para arredondar.
  2. Escolha o modo de arredondamento e a precisão.
  3. Leia o resultado arredondado e a regra aplicada.
Exemplo: 1,234.5678: para 2 casas decimais → 1,234.57; para o múltiplo de 100 mais próximo → 1,200; para 4 algarismos significativos → 1,235 (como o 5.º algarismo significativo é 5, o 4.º arredonda de 4 para 5 — dando 1,235).

Frequently Asked Perguntas

O que é arredondar metade para cima?

Quando a parte descartada é exatamente metade (um 5 seguido de nada), o número arredonda para cima, afastando-se de zero para os positivos. É a convenção ensinada nas escolas e utilizada na maioria dos contextos do dia a dia. O arredondamento bancário (metade para par) existe nas finanças e na informática, mas não é a predefinição aqui.

O que são algarismos significativos?

Algarismos esse carry meaning, contado de primeiro non-zero algarismo. 0.004560 tem 4 algarismos significativos (4, 5, 6 e trailing 0). Arredondamento para algarismos significativos mantém precision proporcional para tamanho de número, qual é porque scientists prefer isto.

Como se arredonda para o milhar mais próximo?

Isso é arredondamento ao valor posicional −3: observe o algarismo das centenas; 1,234 tem algarismo das centenas 2, pelo que arredonda para baixo para 1,000, enquanto 1,567 arredonda para cima para 2,000.

Porque é que os computadores mostram 2.675 como 2.67?

A vírgula flutuante binária não consegue guardar a maioria das frações decimais com exatidão, pelo que um código ingénuo por vezes arredonda 'mal'. Esta calculadora corrige com um épsilon minúsculo, para que as metades exatas se comportem como a matemática escolar espera.

Como funciona — a fórmula

Casas decimais: arredondado = round(x × 10ᵈ) ÷ 10ᵈ usando arredondamento metade para cima (com uma correção épsilon para a vírgula flutuante binária). Valor posicional: a mesma fórmula com d negativo — arredondar para o 100 mais próximo é d = −2. Algarismos significativos: se x ≠ 0, d = sig − 1 − floor(log₁₀|x|), e depois aplica-se a regra das casas decimais com esse d.

Exemplo prático

Entradas: x = 1,234.5678.

Passos: 2 casas decimais: 1,234.5678 × 100 = 123,456.78 → arredondar → 123,457 → ÷ 100 = 1,234.57. 100 mais próximo: 1,234.5678 ÷ 100 = 12.345678 → arredondar → 12 → × 100 = 1,200. 4 algarismos significativos: os primeiros quatro algarismos significativos são 1, 2, 3, 4 (o número até à casa das unidades, 1,234); o dígito seguinte é 5 (o dígito das décimas), pelo que o dígito das unidades arredonda de 4 para 5, dando 1,235. Em termos de fórmula, floor(log₁₀ 1234.5678) = 3, logo d = 4 − 1 − 3 = 0 casas decimais.

Resultado: 1,234.57 (2 c.d.), 1,200 (100 mais próximo), 1,235 (4 alg. sig.).
