🔗 เครื่องคำนวณสหสัมพันธ์

วางการวัดที่จับคู่กันสองคอลัมน์และรับสัมประสิทธิ์สหสัมพันธ์ของเพียร์สัน r — ตัวแปรทั้งสองเคลื่อนไหวไปด้วยกันอย่างแข็งแกร่งเพียงใดในรูปแบบเส้นตรง — พร้อม r² และผลรวมที่พร้อมใช้สำหรับการถดถอย

คำตอบอย่างรวดเร็ว: r ของเพียร์สันมีค่าตั้งแต่ −1 (เส้นลงที่สมบูรณ์แบบ) ผ่าน 0 (ไม่มีความเชื่อมโยงเชิงเส้น) ถึง +1 (เส้นขึ้นที่สมบูรณ์แบบ) สำหรับ x = 1,2,3,4,5 และ y = 2,4,5,4,5, r = 0.775 — เป็นสหสัมพันธ์เชิงบวกที่แข็งแกร่ง โดยมี r² = 0.60

วิธีใช้ Correlation Calculator

  1. วางค่า x ในช่องแรกและค่า y ที่สอดคล้องกันในช่องที่สอง ในลำดับเดียวกัน
  2. ใช้ช่องว่าง จุลภาค หรือบรรทัดใหม่เป็นตัวคั่น — จำนวนต้องตรงกัน (อย่างน้อย 3 คู่)
  3. อ่านค่า r ช่วงระดับความแข็งแกร่งของมัน และค่า r²
ตัวอย่าง: ชั่วโมงที่เรียน (x) เทียบกับคะแนนสอบ (y) สำหรับนักเรียนห้าคน — x: 1 2 3 4 5, y: 2 4 5 4 5 — ให้ r = 0.775: การเรียนมากขึ้นโดยทั่วไปไปกับคะแนนที่สูงขึ้น ในตัวอย่างเล็ก ๆ นี้

คำถามที่พบบ่อย

สหสัมพันธ์หมายความว่าตัวแปรหนึ่งเป็นสาเหตุของอีกตัวแปรหนึ่งหรือไม่?

ไม่ — นี่คือคำเตือนที่สำคัญที่สุดของเครื่องคำนวณ สหสัมพันธ์อาจเกิดจากความเป็นเหตุเป็นผลในทิศทางใดก็ได้ จากตัวแปรที่สามที่ขับเคลื่อนทั้งสองตัว หรือจากความบังเอิญในกลุ่มตัวอย่างขนาดเล็ก r วัดการเคลื่อนไหวร่วมกันเท่านั้น ไม่มีอะไรมากกว่านั้น

อะไรที่ถือว่าแข็งแกร่งหรืออ่อนแอ?

หลักเกณฑ์ทั่วไปที่ใช้กันทั่วไป: |r| ต่ำกว่า 0.3 ถือว่าอ่อน, 0.3–0.7 ปานกลาง, สูงกว่า 0.7 ถือว่าแข็งแกร่ง บริบทมีความสำคัญ — 0.4 อาจมีความสำคัญในทางการแพทย์และไม่มีความหมายในทางฟิสิกส์

ถ้าความสัมพันธ์เป็นเส้นโค้งจะเป็นอย่างไร?

r ของเพียร์สันเห็นเฉพาะรูปแบบเส้นตรงเท่านั้น รูปตัว U ที่สมบูรณ์แบบอาจได้ r ≈ 0 พล็อตข้อมูลเสมอ (เครื่องคำนวณการถดถอยเชิงเส้นวาดแผนภาพการกระจายให้) ก่อนเชื่อ r เพียงอย่างเดียว

r² คืออะไร?

ส่วนของความแปรปรวนของ y ที่อธิบายเชิงเส้นได้ด้วย x r = 0.775 ให้ r² = 0.60 — ประมาณ 60% ของความผันแปรใน y สอดคล้องกับ x ในแบบจำลองเชิงเส้น

วิธีการทำงาน — สูตร

r = Σ(x − x̄)(y − ȳ) ÷ √(Σ(x − x̄)² × Σ(y − ȳ)²). ตัวเศษ (ความแปรปรวนร่วม ที่ยังไม่ปรับมาตรฐาน) ถูกปรับขนาดด้วยการกระจายของตัวแปรทั้งสอง ซึ่งเป็นสิ่งที่ตรึงค่า r ให้อยู่ในช่วง [−1, 1]

ตัวอย่างการคำนวณ

ข้อมูลป้อนเข้า: x = [1,2,3,4,5], y = [2,4,5,4,5].

ก้าว: x̄ = 3, ȳ = 4. Σ(x−x̄)(y−ȳ) = (−2)(−2) + (−1)(0) + 0(1) + 1(0) + 2(1) = 4 + 0 + 0 + 0 + 2 = 6. Σ(x−x̄)² = 10. Σ(y−ȳ)² = 4 + 0 + 1 + 0 + 1 = 6. r = 6 ÷ √(10 × 6) = 6 ÷ 7.746 = 0.7746

ผลลัพธ์: r = 0.775, r² = 0.600.
