ตัวแก้สมการ (เชิงเส้นและกำลังสอง)

แก้สมการเชิงเส้น (ax + b = cx + d) และสมการกำลังสอง (ax² + bx + c = 0) พร้อมแสดงทุกขั้นตอน — รวมถึงดิสคริมิแนนต์ รากซ้ำและรากเชิงซ้อน และการตรวจสอบสุดท้ายที่แทนคำตอบกลับเข้าไป

ใส่ตัวเลขสี่ตัวใน ax + b = cx + d. ใช้ 0 ตรงที่พจน์ขาดหายไป — ตัวอย่างเช่น 2x + 3 = 7 คือ a = 2, b = 3, c = 0, d = 7

ใส่สัมประสิทธิ์ทั้งสามใน ax² + bx + c = 0. ใช้ 0 ตรงที่พจน์ขาดหายไป — ตัวอย่างเช่น x² − 9 = 0 คือ a = 1, b = 0, c = −9

วิธีใช้ Equation Solver

  1. เลือกประเภทสมการ: เชิงเส้น (x เท่านั้น) หรือกำลังสอง (x²)
  2. พิมพ์สัมประสิทธิ์ — ตัวเลขที่อยู่หน้า x² และ x และตัวเลขธรรมดา ป้อน 0 สำหรับพจน์ที่ขาดหายไป
  3. กดแก้สมการพร้อมขั้นตอน แล้วอ่านวิธีทำทีละบรรทัด ขั้นตอนสุดท้ายจะตรวจคำตอบโดยแทนค่ากลับเข้าไปในสมการเดิม
ตัวอย่าง: 3x + 2 = x + 10 ย้ายพจน์ x ไปด้านซ้าย: 2x + 2 = 10 ย้ายตัวเลขไปด้านขวา: 2x = 8 หารด้วย 2: x = 4. ตรวจสอบ: 3 × 4 + 2 = 14 และ 4 + 10 = 14 ✓

คำถามที่พบบ่อย

เครื่องแก้สมการนี้แก้สมการประเภทใดได้บ้าง?

สมการเชิงเส้นในรูป ax + b = cx + d และสมการกำลังสองในรูป ax² + bx + c = 0 มันแสดงทุกขั้นตอน ค่าจำแนกสำหรับสมการกำลังสอง และการตรวจสอบสุดท้าย มันไม่แก้สมการกำลังสาม สมการพร้อมกันสองตัวแปร หรืออสมการ — ชื่อหน้าบอกไว้พอดีว่ามันครอบคลุมอะไร

“ไม่มีคำตอบ” หรือ “มีคำตอบเป็นอนันต์” หมายถึงอะไร?

บางครั้งพจน์ x จะตัดกันหมด หากตัวเลขก็ตรงกันด้วย (เช่น 5x + 1 = 5x + 1) สมการจะเป็นจริงเสมอ — มีคำตอบมากมายอนันต์ หากตัวเลขไม่ตรงกัน (5x + 1 = 5x + 3) จะไม่มีวันเป็นจริง — ไม่มีคำตอบ ตัวแก้สมการจะบอกคุณอย่างตรงไปตรงมาว่าคุณอยู่ในกรณีใด แทนที่จะสร้างคำตอบขึ้นมา

รากเชิงซ้อนคืออะไร?

เมื่อดิสคริมิแนนต์ของสมการกำลังสอง (b² − 4ac) เป็นลบ กราฟจะไม่ตัดแกน x เลยและไม่มีคำตอบเป็นจำนวนจริง รากในกรณีนี้จะเป็นจำนวนเชิงซ้อนที่ใช้ i โดยที่ i² = −1 — ตัวอย่างเช่น x² + 1 = 0 มีรากคือ x = i และ x = −i เครื่องแก้สมการนี้จะแสดงรากเหล่านั้นและยังตรวจสอบให้ด้วย

วิธีการทำงาน — วิธีการ

สมการเชิงเส้น แก้ได้โดยการรักษาสมการให้สมดุล — ไม่ว่าคุณจะทำอะไรกับข้างหนึ่ง คุณต้องทำกับอีกข้างด้วยเช่นกัน ขั้นแรกพจน์ x จะถูกรวบรวมไว้ทางซ้าย (ลบ cx ออกจากทั้งสองข้าง) จากนั้นพจน์ตัวเลขไว้ทางขวา (ลบ b) และสุดท้ายทั้งสองข้างหารด้วยสัมประสิทธิ์ของ x

สมการกำลังสอง ใช้สูตรสมการกำลังสอง สำหรับ ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

ส่วนที่อยู่ใต้เครื่องหมายราก, D = b² − 4ac, เรียกว่าดิสคริมิแนนต์ และมันบอกประเภทของคำตอบให้คุณก่อนคำนวณเสร็จ: D > 0 หมายถึงรากจริงสองค่าที่ต่างกัน D = 0 หมายถึงรากซ้ำหนึ่งค่า และ D < 0 หมายถึงรากเชิงซ้อนสองค่าและไม่มีคำตอบจริง

ตัวอย่างการคำนวณ

ตัวอย่าง: แก้ x² − 5x + 6 = 0 ในที่นี้ a = 1, b = −5, c = 6 D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1 ดังนั้น √D = 1 จากนั้น x = (5 + 1) ÷ 2 = 3 หรือ x = (5 − 1) ÷ 2 = 2. ตรวจสอบ x = 3: 9 − 15 + 6 = 0 ✓

คำถามที่พบบ่อย

ฉันจะป้อนสมการที่มีพจน์ขาดหายไปได้อย่างไร?

ใส่ 0 สำหรับสัมประสิทธิ์ที่หายไป x² − 9 = 0 กลายเป็น a = 1, b = 0, c = −9 และตัวแก้สมการให้ x = 3 หรือ x = −3 สำหรับสมการเชิงเส้นอย่าง 2x = 10 นั่นคือ a = 2, b = 0, c = 0, d = 10

ถ้าฉันพิมพ์ a = 0 ในเครื่องแก้สมการกำลังสองจะเป็นอย่างไร?

จากนั้นพจน์ x² จะหายไปและสมการเป็นเชิงเส้นจริง ๆ ตัวแก้สมการสังเกตเห็นสิ่งนี้และแก้มันเป็นสมการเชิงเส้นแทน พร้อมบอกคุณว่านั่นคือสิ่งที่เกิดขึ้น

ทำไมเครื่องแก้สมการจึงตรวจสอบคำตอบตอนท้าย?

การแทนคำตอบกลับเข้าไปในสมการเดิมเป็นวิธีที่แน่นอนที่สุดในการจับข้อผิดพลาด: หากทั้งสองด้านออกมาเท่ากัน คำตอบจะถูกต้องแน่นอน เป็นนิสัยที่ดีสำหรับการบ้านด้วย — ครูมักให้คะแนนวิธีทำสำหรับการตรวจสอบที่เห็นได้ชัด
