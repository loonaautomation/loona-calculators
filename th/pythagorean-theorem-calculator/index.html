📐 เครื่องคำนวณทฤษฎีบทพีทาโกรัส

ใส่ด้านสองด้านใด ๆ ของสามเหลี่ยมมุมฉาก และเครื่องคำนวณจะหาด้านที่สามโดยใช้ทฤษฎีบทพีทาโกรัส แสดงการแทนค่าเต็มรูปแบบเพื่อให้นักเรียนตามทุกขั้นตอนได้

คำตอบอย่างรวดเร็ว: ทฤษฎีบทพีทาโกรัสกล่าวว่า a² + b² = c² สำหรับสามเหลี่ยมมุมฉาก โดยที่ c คือด้านตรงข้ามมุมฉาก ตัวอย่างคลาสสิกคือ 3-4-5: 9 + 16 = 25 ดังนั้นด้านตรงข้ามมุมฉากคือ 5

วิธีใช้ Pythagorean Theorem Calculator

  1. ใส่สองด้านที่คุณทราบ (เว้นด้านที่ไม่ทราบว่างไว้ หรือตั้งเป็น 0)
  2. หากคุณรู้ด้านตรงข้ามมุมฉาก ให้ป้อนเป็น c
  3. กดคำนวณ ด้านที่หายไปและวิธีคำนวณฉบับเต็มจะปรากฏขึ้น
ตัวอย่าง: ด้านประกอบ 6 และ 8: c = √(36 + 64) = √100 = 10 ด้วยด้านตรงข้ามมุมฉาก 13 และด้านประกอบ 5: ด้านประกอบอีกด้าน = √(169 − 25) = √144 = 12

คำถามที่พบบ่อย

ด้านใดคือด้านตรงข้ามมุมฉาก?

ด้านที่อยู่ตรงข้ามมุมฉาก — เป็นด้านที่ยาวที่สุดเสมอ ติดป้าย c ที่นี่ อีกสองด้าน (ขา) คือ a และ b

คุณจะหาด้านประกอบมุมฉากแทนด้านตรงข้ามมุมฉากได้อย่างไร?

จัดเรียงทฤษฎีบทใหม่: a = √(c² − b²) ด้านตรงข้ามมุมฉากต้องยาวกว่าด้านประกอบมุมฉากทั้งสอง หากไม่เป็นเช่นนั้น สามเหลี่ยมจะไม่สามารถเป็นสามเหลี่ยมมุมฉากที่มีด้านเหล่านั้นได้ และเครื่องคำนวณจะแจ้งเช่นนั้น

มันใช้ได้กับสามเหลี่ยมที่ไม่ใช่มุมฉากหรือไม่?

ไม่ ทฤษฎีบทนี้เป็นจริงเฉพาะกับสามเหลี่ยมมุมฉากเท่านั้น สำหรับสามเหลี่ยมอื่น คุณต้องใช้กฎของโคไซน์ — เครื่องคำนวณตรีโกณมิติบนเว็บไซต์นี้สามารถช่วยเรื่องมุมและอัตราส่วนได้

ทำไมสามเหลี่ยม 3-4-5 จึงพบได้ทุกที่?

เพราะ 3² + 4² = 5² พอดี ช่างก่อสร้างและช่างไม้จึงใช้เชือกหรือสายวัด 3-4-5 เพื่อทำเครื่องหมายมุมฉากที่แท้จริงมานานหลายพันปี สามจำนวนเต็มชุดอื่น ๆ ได้แก่ 5-12-13, 8-15-17 และ 7-24-25

วิธีการทำงาน — สูตร

a² + b² = c² การหาด้านตรงข้ามมุมฉาก: c = √(a² + b²) การหาขา: a = √(c² − b²) หรือ b = √(c² − a²) ต้องให้สองด้านพอดี; ด้านที่สามได้จากการคำนวณ และขาจะหาได้เฉพาะเมื่อด้านตรงข้ามมุมฉากเป็นด้านที่ยาวที่สุด

ตัวอย่างการคำนวณ

ข้อมูลป้อนเข้า: ด้านตรงข้ามมุมฉาก c = 13 ด้านประกอบมุมฉาก a = 5 จงหา b

ก้าว: b = √(c² − a²) = √(169 − 25) = √144 = 12

ผลลัพธ์: b = 12 — ชุดสามจำนวน 5-12-13
