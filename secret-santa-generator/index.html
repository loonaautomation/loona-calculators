🎅 Secret Santa Generator

Add everyone's names, add any exclusions (for example partners who should not draw each other), and run the draw. Nobody sees the full list — each person picks their own name and privately reveals only who they are buying for.

Quick answer: A Secret Santa draw is a random pairing where everyone gives one gift and receives one gift, nobody is paired with themselves, and the full list stays secret: each person reveals only their own match.

Private reveal — one person at a time

How to use the Secret Santa Generator

  1. Enter all names, one per line (at least 3 people).
  2. Optionally add exclusions, one per line, as Name1, Name2 — those two will not be paired in either direction.
  3. Press Run the Draw.
  4. Each person selects their own name in the reveal box and sees only their own match. Keep the screen private while revealing.
Example: Five friends — Ali, Sara, John, Maria, Chen — with the exclusion Ali, Sara: the draw always gives everyone exactly one person to buy for, nobody draws themselves, and Ali and Sara never draw each other.

Frequently Asked Questions

How do exclusions work?

Type a pair as Name1, Name2 on its own line. The draw will never pair those two in either direction — useful for couples or last year's pairing. Names must be spelled exactly as in the main list.

Can a draw become impossible?

Yes — with too many exclusions for too few people there may be no valid pairing. The tool then tells you honestly instead of forcing a bad draw; remove an exclusion or add a person.

Is the result stored or sent anywhere?

No. The draw happens entirely in your browser and nothing is uploaded. If you close the page, the draw is gone — that is the point of keeping it secret.

How does the private reveal work?

After the draw, a dropdown lists every name. Each person chooses their own name and presses Reveal to see only their own recipient. The organiser never needs to see the whole list.

How it works — the formula

A valid draw is a derangement with forbidden pairs: a permutation of the names where nobody maps to themselves and no excluded pair maps either way. The generator tries shuffled permutations first (fast for normal groups), and if random tries keep failing it switches to a deterministic backtracking search that either finds a valid draw or proves none exists — it never silently breaks a rule.

Worked example

Inputs: 5 names, exclusion Ali–Sara.

Steps: One valid draw the tool can produce: Ali → John, John → Maria, Maria → Chen, Chen → Sara, Sara → Ali. Check: five givers, five different receivers, nobody has themselves, and Ali and Sara do not have each other.

Result: Every rule satisfied, and each person sees only their own line when they reveal.
