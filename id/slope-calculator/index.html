📉 Kalkulator Kemiringan

Masukkan dua titik (x₁, y₁) dan (x₂, y₂) untuk mendapatkan segalanya tentang garis di antara keduanya: kemiringan, jarak, titik tengah, sudut, dan persamaan y = mx + b — dengan substitusi setiap rumus ditampilkan.

Jawaban cepat: Kemiringan = (y₂ − y₁) ÷ (x₂ − x₁). Untuk (1, 2) dan (4, 8): kemiringan = 6 ÷ 3 = 2, jarak = √(3² + 6²) = √45 ≈ 6.71, dan titik tengahnya adalah (2.5, 5).

Cara menggunakan Kalkulator Kemiringan

  1. Masukkan koordinat titik pertama.
  2. Masukkan koordinat titik kedua.
  3. Baca kemiringan, jarak, titik tengah, dan persamaan garisnya.
Contoh: Titik (1, 2) dan (4, 8): kemiringan 2, jarak √45 ≈ 6.708, titik tengah (2.5, 5), dan persamaan garis y = 2x + 0 — garis ini melewati titik asal, yang dapat Anda periksa: pada x = 1, y = 2 ✓.

Pertanyaan yang Sering Diajukan

Apa arti kemiringan (slope) sebesar 2?

Untuk setiap 1 unit Anda bergerak ke kanan, garis naik 2 unit. Kemiringan 0 adalah datar, kemiringan negatif jatuh ke kanan, dan kemiringan tak terdefinisi (pembagian dengan nol) adalah garis vertikal.

Bagaimana jarak di antara dua titik dihitung?

Dengan Pythagoras: jarak = √((x₂ − x₁)² + (y₂ − y₁)²). Selisih koordinat adalah kedua sisi tegak segitiga siku-siku dan jaraknya adalah sisi miringnya.

Apa rumus titik tengahnya?

Rata-ratakan koordinatnya: titik tengah = ((x₁ + x₂) ÷ 2, (y₁ + y₂) ÷ 2). Itu adalah titik tepat di tengah segmen.

Bagaimana jika kedua nilai x sama?

Garisnya vertikal: kemiringan tidak terdefinisi dan tidak ada persamaan y = mx + b. Kalkulator melaporkan garis vertikal x = nilai itu, ditambah jarak dan titik tengah seperti biasa.

Cara kerjanya — rumusnya

Kemiringan: m = (y₂ − y₁) ÷ (x₂ − x₁). Jarak: d = √((x₂ − x₁)² + (y₂ − y₁)²). Titik tengah: ((x₁ + x₂) ÷ 2, (y₁ + y₂) ÷ 2). Persamaan garis: menggunakan titik 1, b = y₁ − m·x₁, menghasilkan y = mx + b. Sudut: θ = arctan(m), dalam derajat dari sumbu x positif.

Contoh pengerjaan

Masukan: (1, 2) dan (4, 8).

Langkah: Kemiringan = (8 − 2) ÷ (4 − 1) = 6 ÷ 3 = 2. Jarak = √((4−1)² + (8−2)²) = √(9 + 36) = √45 = 6.708. Titik tengah = ((1+4)÷2, (2+8)÷2) = (2.5, 5). Intersep: b = 2 − 2×1 = 0, jadi garisnya adalah y = 2x.

Hasil: Kemiringan 2, jarak 6.708, titik tengah (2.5, 5), persamaan y = 2x.
