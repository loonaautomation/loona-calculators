Pemecah Persamaan (Linear & Kuadrat)

Selesaikan persamaan linear (ax + b = cx + d) dan persamaan kuadrat (ax² + bx + c = 0) dengan setiap langkah ditampilkan — termasuk diskriminan, akar ganda dan kompleks, serta pemeriksaan akhir yang menggantikan jawaban kembali ke persamaan.

Masukkan empat angka dalam ax + b = cx + d. Gunakan 0 bila suatu suku tidak ada — misalnya, 2x + 3 = 7 adalah a = 2, b = 3, c = 0, d = 7.

Masukkan tiga koefisien dalam ax² + bx + c = 0. Gunakan 0 bila suatu suku tidak ada — misalnya, x² − 9 = 0 adalah a = 1, b = 0, c = −9.

Cara menggunakan Pemecah Persamaan

  1. Pilih jenis persamaan: linear (x saja) atau kuadrat (x²).
  2. Ketik koefisiennya — angka di depan x² dan x, dan angka biasa. Masukkan 0 untuk suku yang hilang.
  3. Tekan Selesaikan dengan langkah dan baca perhitungannya baris demi baris. Langkah terakhir memeriksa jawaban dengan menggantinya kembali ke persamaan asal.
Contoh: 3x + 2 = x + 10. Pindahkan suku x ke kiri: 2x + 2 = 10. Pindahkan angka ke kanan: 2x = 8. Bagi dengan 2: x = 4. Periksa: 3 × 4 + 2 = 14 dan 4 + 10 = 14 ✓

Pertanyaan yang Sering Diajukan

Jenis persamaan apa saja yang dapat ditangani pemecah ini?

Persamaan linear dalam bentuk ax + b = cx + d, dan persamaan kuadrat dalam bentuk ax² + bx + c = 0. Alat ini menampilkan setiap langkah, diskriminan untuk persamaan kuadrat, dan pemeriksaan akhir. Alat ini tidak menyelesaikan persamaan kubik, persamaan simultan dengan dua variabel, atau pertidaksamaan — judul halaman menyatakan dengan tepat apa yang dicakupnya.

Apa arti "tidak ada solusi" atau "solusi tak berhingga banyaknya"?

Kadang-kadang suku x saling menghilangkan sepenuhnya. Jika angkanya juga cocok (seperti 5x + 1 = 5x + 1) persamaannya selalu benar — solusi tak terhingga banyaknya. Jika angkanya tidak cocok (5x + 1 = 5x + 3) persamaannya tidak akan pernah benar — tidak ada solusi. Penyelesai memberi tahu Anda dengan jujur kasus mana yang Anda miliki alih-alih mengada-ada jawaban.

Apa itu akar kompleks?

Ketika diskriminan suatu persamaan kuadrat (b² − 4ac) bernilai negatif, grafiknya tidak pernah memotong sumbu x dan tidak ada jawaban nyata. Akar-akarnya kemudian berupa bilangan kompleks yang menggunakan i, di mana i² = −1 — misalnya, x² + 1 = 0 memiliki akar x = i dan x = −i. Pemecah ini menampilkannya dan tetap memeriksanya.

Cara kerjanya — metodenya

Persamaan linear diselesaikan dengan menjaga persamaan tetap seimbang — apa pun yang Anda lakukan pada satu sisi, Anda lakukan juga pada sisi lainnya. Pertama, suku x dikumpulkan di sebelah kiri (kurangi cx dari kedua sisi), lalu suku angka di sebelah kanan (kurangi b), dan terakhir kedua sisi dibagi dengan koefisien x.

Persamaan kuadrat gunakan rumus kuadrat. Untuk ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

Bagian di bawah akar, D = b² − 4ac, disebut diskriminan, dan ia memberi tahu Anda jenis jawabannya sebelum Anda selesai: D > 0 berarti dua akar riil yang berbeda, D = 0 berarti satu akar kembar, dan D < 0 berarti dua akar kompleks dan tidak ada jawaban riil.

Contoh pengerjaan

Contoh: Selesaikan x² − 5x + 6 = 0. Di sini a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, jadi √D = 1. Lalu x = (5 + 1) ÷ 2 = 3 atau x = (5 − 1) ÷ 2 = 2. Periksa x = 3: 9 − 15 + 6 = 0 ✓

Pertanyaan yang sering diajukan

Bagaimana cara saya memasukkan persamaan dengan suku yang hilang?

Masukkan 0 untuk koefisien yang hilang. x² − 9 = 0 menjadi a = 1, b = 0, c = −9, dan penyelesai memberikan x = 3 atau x = −3. Untuk persamaan linear seperti 2x = 10, itu adalah a = 2, b = 0, c = 0, d = 10.

Bagaimana jika saya mengetik a = 0 di pemecah kuadrat?

Maka suku x² hilang dan persamaannya benar-benar linear. Penyelesai memperhatikan hal ini dan menyelesaikannya sebagai persamaan linear sebagai gantinya, memberi tahu Anda bahwa itulah yang terjadi.

Mengapa pemecah memeriksa jawabannya di akhir?

Menggantikan jawaban kembali ke persamaan asal adalah cara paling pasti untuk menangkap kesalahan: jika kedua sisi menjadi sama, jawaban itu pasti benar. Ini juga kebiasaan yang baik untuk pekerjaan rumah — guru sering memberikan nilai metode untuk pemeriksaan yang terlihat.
