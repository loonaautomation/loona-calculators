समीकरण हलकर्ता (रैखिक & द्विघात)

रैखिक समीकरण (ax + b = cx + d) और द्विघात समीकरण (ax² + bx + c = 0) हर चरण दिखाकर हल करें — विविक्तकर, दोहराए और सम्मिश्र मूल, और अंतिम जांच समेत जो उत्तर को वापस प्रतिस्थापित करती है।

चार संख्याएँ दर्ज करें ax + b = cx + d। जहाँ कोई पद ग़ायब हो वहाँ 0 उपयोग करें — उदाहरण के लिए, 2x + 3 = 7 है a = 2, b = 3, c = 0, d = 7।

तीन गुणांक दर्ज करें ax² + bx + c = 0। जहाँ कोई पद ग़ायब हो वहाँ 0 उपयोग करें — उदाहरण के लिए, x² − 9 = 0 है a = 1, b = 0, c = −9।

समीकरण हलकर्ता का उपयोग कैसे करें

  1. समीकरण प्रकार चुनें: रैखिक (केवल x) या द्विघात (x²)।
  2. गुणांक लिखें — x² और x के सामने की संख्याएँ, और सादा संख्या। किसी गायब पद के लिए 0 दर्ज करें।
  3. चरणों के साथ हल करें दबाएँ और कार्य पंक्ति-दर-पंक्ति पढ़ें। अंतिम चरण उत्तर को मूल समीकरण में वापस प्रतिस्थापित करके जांचता है।
उदाहरण: 3x + 2 = x + 10। x पदों को बाईं ओर लाएँ: 2x + 2 = 10। संख्या को दाईं ओर लाएँ: 2x = 8। 2 से भाग दें: x = 4। जांचें: 3 × 4 + 2 = 14 और 4 + 10 = 14 ✓

अक्सर पूछे जाने वाले प्रश्न

यह हलकर्ता किस प्रकार के समीकरण संभाल सकता है?

ax + b = cx + d रूप में रैखिक समीकरण, और ax² + bx + c = 0 रूप में द्विघात समीकरण। यह हर चरण, द्विघातों के लिए विविक्तकर, और अंतिम जांच दिखाता है। यह घन समीकरण, दो अज्ञात में युगपत समीकरण, या असमिकाएँ हल नहीं करता — पृष्ठ शीर्षक ठीक-ठीक कहता है कि यह क्या कवर करता है।

"no solution" या "infinitely many solutions" का क्या अर्थ है?

कभी-कभी x पद पूरी तरह रद्द हो जाते हैं। यदि संख्याएँ भी मेल खाती हैं (जैसे 5x + 1 = 5x + 1) तो समीकरण हमेशा सच है — अनंत अनेक हल। यदि संख्याएँ मेल नहीं खातीं (5x + 1 = 5x + 3) तो यह कभी सच नहीं हो सकता — कोई हल नहीं। हलकर्ता आपको ईमानदारी से बताता है कि आपका कौन सा मामला है, उत्तर का आविष्कार करने के बजाय।

सम्मिश्र मूल क्या हैं?

जब द्विघात का विविक्तकर (b² − 4ac) ऋणात्मक होता है, तो ग्राफ़ x-अक्ष को कभी पार नहीं करता और कोई वास्तविक उत्तर नहीं होते। तब मूल i का उपयोग करने वाली सम्मिश्र संख्याएँ होती हैं, जहाँ i² = −1 — उदाहरण के लिए, x² + 1 = 0 के मूल x = i और x = −i हैं। यह हलकर्ता उन्हें दिखाता है और फिर भी उन्हें जाँचता है।

यह कैसे काम करता है — विधि

रैखिक समीकरण समीकरण को संतुलित रखकर हल किए जाते हैं — आप एक पक्ष के साथ जो करते हैं, दूसरे के साथ भी करते हैं। पहले x पद बाईं ओर इकट्ठा किए जाते हैं (दोनों पक्षों से cx घटाएँ), फिर संख्या पद दाईं ओर (b घटाएँ), और अंत में दोनों पक्ष x के गुणांक से विभाजित होते हैं।

द्विघात समीकरण द्विघात सूत्र का उपयोग करें। ax² + bx + c = 0 के लिए:

x = (−b ± √(b² − 4ac)) ÷ (2a)

मूल के नीचे का हिस्सा, D = b² − 4ac, विविक्तकर कहलाता है, और यह आपको काम ख़त्म करने से पहले ही उत्तर का प्रकार बता देता है: D > 0 का अर्थ है दो अलग वास्तविक मूल, D = 0 का अर्थ है एक दोहराया गया मूल, और D < 0 का अर्थ है दो सम्मिश्र मूल और कोई वास्तविक उत्तर नहीं।

हल किया उदाहरण

उदाहरण: x² − 5x + 6 = 0 हल करें। यहाँ a = 1, b = −5, c = 6। D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, इसलिए √D = 1। फिर x = (5 + 1) ÷ 2 = 3 या x = (5 − 1) ÷ 2 = 2. Check x = 3: 9 − 15 + 6 = 0 ✓

अक्सर पूछे जाने वाले प्रश्न

मैं गायब पद वाला समीकरण कैसे दर्ज करूँ?

लापता गुणांक के लिए 0 दर्ज करें। x² − 9 = 0, a = 1, b = 0, c = −9 बन जाता है, और हलकर्ता x = 3 या x = −3 देता है। 2x = 10 जैसे रैखिक समीकरण के लिए, वह a = 2, b = 0, c = 0, d = 10 है।

अगर मैं द्विघात हलकर्ता में a = 0 लिखूँ तो क्या होगा?

तब x² पद गायब हो जाता है और समीकरण वास्तव में रैखिक हो जाता है। हलकर्ता यह देखता है और इसे रैखिक समीकरण के रूप में हल करता है, आपको बताते हुए कि यही हुआ।

हलकर्ता अंत में अपना उत्तर क्यों जाँचता है?

उत्तर को मूल समीकरण में वापस प्रतिस्थापित करना ग़लती पकड़ने का सबसे निश्चित तरीका है: यदि दोनों पक्ष समान निकलते हैं, तो उत्तर निश्चित रूप से सही है। यह गृहकार्य के लिए भी अच्छी आदत है — शिक्षक अक्सर दृश्य जांच के लिए विधि अंक देते हैं।
