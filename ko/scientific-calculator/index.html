🧮 공학용 계산기

브라우저 안의 완전한 공학용 계산기: 삼각함수와 그 역함수, 로그, 거듭제곱과 제곱근, 팩토리얼과 퍼센트 — DEG/RAD 각도 모드와 전체 키보드 지원이 있어요.

각도 모드를 전환하려면 DEG/RAD를 탭하세요. 키보드도 작동해요 — 식을 입력하고 Enter를 누르세요.

공학용 계산기 사용 방법

  1. 버튼을 탭하거나, 키보드로 직접 입력해, 식을 만드세요 — 예를 들어 sin(30) + 2^3.
  2. sin, cos 또는 tan을 쓰기 전에 각도가 어떻게 측정되는지 고르려면 DEG/RAD 버튼을 쓰세요.
  3. 답을 보려면 = (또는 Enter)를 누르세요. 답에서 계속 계산하거나, AC를 눌러 다시 시작할 수 있어요.
예시: sin(30), DEG 모드에서 = 0.5, 그리고 2^3^2 = 512, 거듭제곱은 오른쪽에서 먼저 계산되기 때문이에요(3² = 9, 그다음 2⁹ = 512).

자주 묻는 질문

DEG와 RAD의 차이는 무엇인가요?

DEG는 각도를 도로 재요(한 바퀴는 360°) 그리고 RAD는 라디안으로 재요(한 바퀴는 2π). 학교와 일상 수학은 보통 도를 쓰고, 고급 수학과 과학은 종종 라디안을 써요. sin, cos, tan을 쓰기 전에 항상 모드를 확인하세요 — sin(30)은 DEG 모드에서 0.5지만 RAD 모드에서는 약 −0.988이에요.

5의 세제곱 같은 거듭제곱은 어떻게 계산해요?

5를 탭하고, xʸ 버튼, 그다음 3, 그다음 =를 탭하세요. 키보드로 5^3을 입력할 수도 있어요. x² 버튼은 앞의 숫자를 제곱하는 바로 가기예요.

% 버튼은 무엇을 하나요?

그것은 앞 숫자를 100으로 나눠요, 그래서 50%는 0.5가 되고 8%는 0.08이 돼요. 예를 들어, 200 × 8% = 16 — 빠른 세금, 팁, 할인 합에 편리해요. 두 숫자 사이의 백분율 변화에는 백분율 계산기를 쓰세요.

작동 원리 — 따르는 규칙

이 계산기는 온전한 식을 읽고 표준 연산 순서를 써서 그것을 계산해요 — 학교에서 가르치는 같은 규칙:

1. 괄호 먼저 — ( ) 안의 모든 것은 다른 모든 것보다 먼저 계산돼요.
2. 거듭제곱과 제곱근 — xʸ, x², √가 다음이에요. 거듭제곱은 오른쪽 결합이에요: 2^3^2는 2^(3^2) = 512를 뜻해요.
3. 곱셈과 나눗셈 — ×와 ÷는 왼쪽에서 오른쪽으로 해요. 곱셈은 2π나 2(3 + 4)처럼 나란히 배치해 쓸 수도 있어요.
4. 덧셈과 뺄셈 — +와 −는 마지막에, 왼쪽에서 오른쪽으로 해요.

sin, log, ln 같은 함수는 괄호 안 값에 적용돼요. log는 밑 10이에요(log 1000 = 3)이고 ln은 자연 로그, 밑 e예요. n! 버튼은 팩토리얼을 줘요 — 5! = 5 × 4 × 3 × 2 × 1 = 120 — 0부터 위쪽 정수에 작동해요.

작업 예시

예시: 변 3과 4를 가진 직각삼각형의 가장 긴 변을 찾으세요. √(3² + 4²)를 입력하세요: 괄호 먼저(9 + 16 = 25), 그다음 제곱근 — 답은 5. 키패드에서: √, 3, x², +, 4, x², )를 차례로 누른 뒤 =를 누르세요.

자주 묻는 질문

왜 sin(30)이 잘못된 답을 줬나요?

거의 항상 각도 모드 문제예요. 계산기가 RAD 모드이면 30을 30도가 아니라 30라디안으로 취급해요. DEG/RAD 버튼을 눌러 DEG가 표시되게 한 뒤 다시 해보세요. 모드는 키패드 왼쪽 위 버튼에 표시돼요.

세제곱근이나 다른 근은 어떻게 찾아요?

분수 거듭제곱을 쓰세요: 27의 세제곱근은 27^(1/3) = 3이에요. 일반적으로, 숫자 x의 n제곱근은 x^(1/n)이에요. √ 버튼은 흔한 제곱근 경우를 다뤄요.

이 계산기는 무료이고, 내 계산을 저장해요?

예, 그것은 가입 없이 완전히 무료예요. 모든 것은 자신의 브라우저에서 계산돼요 — 식은 절대 서버에 전송되거나 저장되지 않아요.
