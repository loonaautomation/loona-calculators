📐 피타고라스 정리 계산기

직각삼각형의 두 변을 입력하면 계산기는 피타고라스 정리를 이용해 세 번째 변을 찾고, 전체 대입을 보여줘서 학생이 모든 단계를 따라갈 수 있어요.

빠른 답: 피타고라스 정리는 직각삼각형에 대해 a² + b² = c²라고 말해요, c는 빗변이에요. 고전적인 예는 3-4-5예요: 9 + 16 = 25, 그래서 빗변은 5예요.

피타고라스 정리 계산기 사용 방법

  1. 아는 두 변을 입력하세요(모르는 변은 비워 두거나 0으로 설정하세요).
  2. 빗변을 알면, c로 입력하세요.
  3. 계산을 누르세요 — 빠진 변과 온전한 과정이 나타나요.
예시: 다리 6과 8: c = √(36 + 64) = √100 = 10. 빗변 13과 다리 5로: 다른 다리 = √(169 − 25) = √144 = 12.

자주 묻는 질문

빗변은 어느 쪽인가요?

직각 반대편 — 항상 가장 긴 변, 여기서 c로 라벨돼요. 다른 두 변(다리)은 a와 b예요.

빗변 대신 다리는 어떻게 찾아요?

정리를 재배열하세요: a = √(c² − b²). 빗변은 어느 다리보다 길어야 해요; 그렇지 않으면 그 변으로 삼각형은 직각삼각형일 수 없고 계산기가 그렇게 말해요.

직각삼각형이 아닌 경우에도 작동하나요?

아니요. 정리는 직각삼각형에만 참이에요. 다른 삼각형에는 코사인 법칙이 필요해요 — 이 사이트의 삼각법 계산기가 각도와 비율을 도울 수 있어요.

왜 3-4-5 삼각형이 곳곳에 나타나나요?

3² + 4² = 5²가 정확히 성립하기 때문에, 건축업자와 목수들은 수천 년 동안 3-4-5 로프나 줄자로 정확한 직각을 표시해 왔어요. 다른 정수 삼조에는 5-12-13, 8-15-17, 7-24-25가 있어요.

작동 원리 — 공식

a² + b² = c². 빗변 찾기: c = √(a² + b²). 다리 찾기: a = √(c² − b²) 또는 b = √(c² − a²). 정확히 두 변이 주어져야 해요; 세 번째는 도출되고, 다리는 빗변이 가장 긴 변일 때만 찾을 수 있어요.

작업 예시

입력들: 빗변 c = 13, 다리 a = 5, b를 찾으세요.

단계: b = √(c² − a²) = √(169 − 25) = √144 = 12.

결과: b = 12 — 5-12-13 세트.
