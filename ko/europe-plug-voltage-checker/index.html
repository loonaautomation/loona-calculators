🔌 유럽 플러그 & 전압 확인 도구

거기서 쓰이는 플러그 유형, 주전원 전압과 주파수 — 그리고 기기에 단순 어댑터로 충분한지 전압 변환기가 필요한지에 대한 평이한 안내를 보려면 모든 유럽 국가를 고르세요.

빠른 답: 유럽 거의 전역은 230 V, 50 Hz로 돌아가요. 차이는 플러그 모양이에요: 대륙 대부분은 C/F형, 프랑스/벨기에/폴란드는 C/E형, 이탈리아는 L형도 쓰고, 스위스는 J형, 영국과 아일랜드는 세 핀 G형을 써요.

유럽 플러그 & 전압 확인 도구 사용 방법

  1. 방문하는 국가를 고르세요.
  2. 기기가 어디서 오는지 고르세요.
  3. 플러그 유형과 전압, 어댑터/변환기 판정을 읽으세요.
예시: 영국에서 프랑스를 방문하기: 프랑스는 230 V/50 Hz에서 Type C & E를 써요. 전압은 영국의 230 V와 일치해요, 그래서 플러그 어댑터(영국 Type G에서 프랑스 Type E로)만 필요해요 — 전압 변환기 없음.

자주 묻는 질문

어댑터와 변환기의 차이는 무엇인가요?

어댑터는 플러그 모양만 바꿔서 플러그가 물리적으로 들어가게 해요. 변환기는 전압을 바꿔요. 기기 라벨에 입력: 100–240 V라고 쓰여 있으면(사실상 모든 휴대폰, 노트북, 카메라 충전기가 그래요), 어댑터만으로 유럽 어디서든 안전해요.

어떤 유럽 플러그가 서로 바꿀 수 있나요?

날씬한 Type C(Europlug)는 C, E, F, J(보통), K, L 소켓에 느슨하게부터 잘 맞기 때문에, 하나의 작은 어댑터가 대륙 대부분을 다뤄요. F 또는 E 플러그가 있는 접지 가전은 완전한 안전을 위해 맞는 접지 어댑터가 필요해요.

왜 스위스는 자체 어댑터가 필요한가요?

스위스 Type J 소켓은 독특한 삼각형 배치에 세 번째 핀을 가져요; Type C 플러그는 맞지만, 다른 곳의 접지 플러그는 맞지 않아요. 범용 어댑터 또는 스위스 전용 어댑터가 그것을 해결해요.

영국이 정말 튀는 존재예요?

영국과 아일랜드는 Type G — 퓨즈가 있는 큰 세 핀 플러그 — 를 써요, 유럽 다른 어디에도 맞지 않고, 유럽 플러그는 어댑터를 통해서만 영국 소켓에 맞아요. 전압은 양쪽 모두 같은 230 V예요.

작동 원리 — 공식

국가 표준(IEC)을 선별한 참고 자료: 전압과 주파수는 유럽 전역에서 사실상 통일돼 있어요, 다음으로 230 V / 50 Hz, 그래서 이 도구의 실제 역할은 플러그 모양 호환성이에요: 목적지의 플러그 계열과 집의 플러그 계열을 비교하고, 집의 표준이 120 V(북미)이고 기기에 100–240 V 표시가 없을 때만 전압 변환기가 필요하다는 규칙을 적용해요.

작업 예시

경우: 영국 여행자 (Type G, 230 V)가 스위스를 방문해요 (Type C & J, 230 V).

확인: 전압이 일치해요 (230 V = 230 V) → 변환기 없음. 플러그 가족이 달라요 (G ≠ C/J) → 어댑터 필요, 그리고 그것은 접지 플러그를 위해 스위스 Type J가 가능한 것이어야 해요.

결과: 어댑터: 예. 변환기: 아니요.

확인된 규칙: 십일월 8일 2026년. 여행 규칙은 바뀌어요 — 여행 전에 항상 공식 정부 또는 EU 출처로 확인하세요.
