👥 무작위 팀 생성기

이름 목록을 붙여 넣고, 원하는 팀 수를 고르면, 공정한 무작위 분할을 얻을 수 있어요. 팀 크기는 최대 한 사람 차이이고, 모두가 정확히 한 번씩 배치돼요.

빠른 답: 무작위 팀 생성기는 전체 목록을 공정하게 섞은 뒤 한 명씩 팀에 나눠줘서, 20명에 4개 팀이면 4개 팀, 각 5명씩이 돼요 — 크기가 한 명 이상 차이 나지 않아요.

무작위 팀 생성기 사용 방법

  1. 이름을 붙여 넣으세요, 한 줄에 하나씩.
  2. 팀 수를 고르세요.
  3. 팀 생성을 누르세요.
  4. 새 섞기를 위해 다시 누르거나, 결과 상자에서 팀을 복사하세요.
예시: 이름 10개를 팀 3개로 나누면 팀 크기가 4, 3, 3이 돼요 — 자동으로 균형이 맞고, 모든 이름이 정확히 한 번씩 쓰여요.

자주 묻는 질문

팀은 어떻게 공정하게 만들어져요?

목록은 안전한 무작위 숫자로 구동되는 Fisher–Yates 섞기로 섞인 뒤, 팀에 라운드로빈으로 나눠져요. 크기는 그래서 최대 하나로 다르고 모든 위치는 모두에게 동등히 가능해요.

이름이 고르게 나뉘지 않으면요?

첫 팀은 한 사람을 더 얻어요. 10명과 3팀으로 크기는 4, 3, 3예요 — 절대 5, 3, 2가 아니에요.

대신 고정 크기의 팀을 만들 수 있나요?

4명 팀으로, 20명이면, 5개 팀을 고르세요 — 팀 크기에 맞는 팀 수를요.

중복된 이름을 허용하나요?

그들은 별도 항목으로 취급돼요, 그래서 이름이 같은 두 사람 모두 배치될 거예요. 그것들을 구별하려면 성이나 이니셜을 더하세요.

작동 원리 — 공식

생성기는 다음 a를 써요 피셔-예이츠 셔플: 목록의 끝에서부터 각 위치마다, 균일하게 무작위로 고른 앞쪽 위치와 바꿔요(암호학 수준의 난수 사용). 그러면 목록의 모든 순서가 같은 확률이 돼요. 섞인 목록은 팀 1, 2, … N, 1, 2, … 순으로 한 명씩 나눠주므로, 팀 크기는 ⌊합계 ÷ N⌋ 또는 ⌈합계 ÷ N⌉ 중 하나예요 — 한 명보다 더 벌어지지는 않아요.

작업 예시

입력들: 이름 10개, 팀 3개.

단계: 셔플 후, 이름은 위치로 나뉘어요: 팀 1은 셔플된 이름 1, 4, 7, 10(4명)을 받고; 팀 2는 이름 2, 5, 8(3명)을 받고; 팀 3은 이름 3, 6, 9(3명)을 받아요. 4 + 3 + 3 = 10 — 모든 사람이 한 번 배치돼요.

결과: 균형 잡힌 팀 구성 4, 3, 3.
