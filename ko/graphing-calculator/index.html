📈 그래프 계산기

x의 함수를 입력하세요 — 예를 들어 x^2, sin(x), 2x+3 또는 1/x — 그리고 그 그래프를 즉시 보세요. 두 번째 함수를 더해 비교하고, 확대하거나 축소해 절편, 전환점, 점근선을 탐색하세요.

빠른 답: 그래프 계산기는 보이는 구간 전체에서 수백 개의 x 값에 대해 y를 구하고 점들을 이어 y = f(x)를 그려요. 이것은 x^2, sin(x), cos(x), tan(x), sqrt(x), log(x), 분수와 2x 같은 암묵적 곱셈을 이해해요.

그래프 계산기 사용 방법

  1. 첫 번째 함수를 입력하세요, 예를 들어 x^2 - 4.
  2. 선택적으로 다른 색으로 비교할 두 번째 함수를 입력하세요.
  3. 그리기를 누른 뒤, 확대 / 축소 또는 보기 초기화를 쓰세요.
  4. 격자에서 절편과 교차점을 읽으세요 — 각 정사각형은 기본적으로 1단위예요.
예시: x^2 - 4를 그리면 x = -2와 x = 2에서 x축과 만나고, 가장 낮은 점이 (0, -4)에 있는 포물선을 줘요. 직선 2x+3을 더하면 곡선과 직선이 어디서 만나는지 보여줘요.

자주 묻는 질문

어떤 식을 쓸 수 있나요?

숫자, x, + − * / ^ 와 괄호, sin, cos, tan, sqrt, abs, log(밑 10), ln, exp, 상수 pi와 e까지요. 암묵적 곱셈도 작동해요: 2x, 3(x+1), (x+1)(x-1) 모두 이해돼요.

왜 1/x 또는 tan(x)의 그래프가 곳곳에서 끊기나요?

그 기능들은 점근선에서 매우 큰 양과 음 값 사이를 점프해요. 플로터는 점프를 감지하고 거짓 수직 직선을 그리는 대신 펜을 들어요.

x 제곱이나 거듭제곱은 어떻게 써요?

캐럿을 쓰세요: x^2는 x 제곱을 뜻하고, x^3은 세제곱, x^0.5는 sqrt(x)와 같아요. 거듭제곱은 오른쪽 결합이에요, 그래서 2^3^2는 2^(3^2) = 512로 읽혀요.

그래프는 어떤 범위를 보여주나요?

그것은 x가 −10부터 10까지, y가 −10부터 10까지에서 시작해요. 각 확대 단계는 범위를 약 0.7(안) 또는 1.4(밖)로 곱해요.

작동 원리 — 공식

플로터는 각 식을 토큰(숫자, x, 연산자, 함수)으로 파싱하고, 암시된 곱셈 기호를 삽입하고(2x → 2*x), 표준 연산 순서를 존중하는 재귀 하강 파서로 그것을 평가해요: ^는 가장 강하게 묶이고 오른쪽으로 결합해요, 그다음 *와 /, 그다음 +와 −, 함수와 괄호를 먼저 처리해요. 그런 다음 구간 전체의 x 위치 720곳에서 함수를 표본화해 연속한 유한한 점들을 연결하고, 함수가 정의되지 않거나 점근선을 건너뛰는 간격은 건너뛰어요.

작업 예시

입력들: f(x) = x^2 − 4.

단계: x = 0에서 y = −4(가장 낮은 점)예요. x = 2에서 y = 4 − 4 = 0, x = −2에서 y = 0 — 두 개의 x절편이에요. x = 3에서 y = 9 − 4 = 5예요.

결과: 꼭짓점이 (0, −4)인 포물선이 x축과 만나는 점 −2와 2, 그래프가 보여주는 그대로예요.
