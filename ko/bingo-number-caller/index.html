🎱 빙고 번호 추첨기

우리가 없는 빙고 밤을 운영하세요: 75공(미국 B-I-N-G-O 열) 또는 90공(영국) 모드를 고르고, 다음 번호 소집을 누르면, 진행자가 각 숫자를 정확히 한 번 뽑고 온전한 소집 보드를 최신으로 유지해요.

빠른 답: 75볼 빙고에서는 숫자가 문자 열에 속해요: B = 1–15, I = 16–30, N = 31–45, G = 46–60, O = 61–75. 공정한 호출기는 비복원으로 뽑아요, 그래서 온전한 게임에서 75개 숫자가 모두 정확히 한 번씩 나타나요.
시작 / 초기화를 누른 뒤, 다음 번호 소집

빙고 번호 추첨기 사용 방법

  1. 75볼 또는 90볼 모드를 고르고 시작 / 재설정을 누르세요.
  2. 각 추첨마다 다음 번호 소집을 누르세요 — 큰 표시에 현재 공과 그 문자(75공)가 보여요.
  3. 호출 보드를 확인해 어떤 선수의 주장도 검증하세요; 카운터는 남은 번호 수를 보여줘요.
예시: 75볼 게임: 첫 호출은 B-7, O-68, N-33일 수 있어요 — 각각 자기 열의 범위에서 나오며, 같은 게임에서 다시 불릴 수는 없어요.

자주 묻는 질문

75공과 90공 빙고의 차이는 무엇인가요?

75볼(북미에서 흔함)은 1–75 숫자를 다섯 개 문자 열에 쓰고 가운데 빈 칸이 있는 카드를 사용해요. 90볼(영국과 유럽에서 흔함)은 1–90을 세 행짜리 티켓에 써요. 추첨 방식은 같아요: 비복원 추출이에요.

추첨이 공정한가요?

예. 각 추첨은 아직 불리지 않은 숫자에서 균일하게 무작위로 골라요, 암호 등급 무작위성을 써요 — 우리에서 뽑힌 공처럼 정확히, 반복은 불가능해요.

번호를 잘못 부르면 돌아갈 수 있나요?

진행자는 소집된 숫자를 제거하지 않아요(실제 우리도 뽑은 것을 되돌릴 수 없어요) — 소집이 초기에 잘못되면 초기화를 써서 새 게임을 시작하세요.

강당이나 교실에서 오프라인으로 작동하나요?

페이지가 로드되면, 모든 것은 브라우저에서 로컬로 실행돼요 — 게임 중에는 연결이 필요 없어요.

작동 원리 — 공식

진행자는 소집되지 않은 숫자의 집합을 유지하고, 각 소집마다, 균일하게 무작위로 하나를 고르고 제거해요 — 비복원 샘플링. 남은 숫자 중 특정 숫자가 다음에 불릴 확률은 1 ÷ (남은 숫자 개수)예요. 75볼 모드에서는 문자가 범위로 정해져요: 문자 인덱스 = floor((n − 1) ÷ 15)를 B, I, N, G, O에 적용해요.

작업 예시

예시: 숫자 33, 75공 모드에서: (33 − 1) ÷ 15 = 2.13, floor = 2 → 세 번째 문자, N. 그래서 33은 항상 ‘N-33’으로 불려요. 숫자 68: (68 − 1) ÷ 15 = 4.47, floor 4 → O, ‘O-68’로 불려요.

확인: B는 1–15, I는 16–30, N은 31–45(33 ✓), G는 46–60, O는 61–75(68 ✓)를 담당해요.
