🧬 IVF 출산 예정일 계산기

배아 이식 날짜와 배아가 3일차에 이식됐는지 5일차(배반포)에 이식됐는지 입력하세요. 계산기는 추정 출산 예정일과 오늘 임신 몇 주인지 계산해요.

빠른 답: 5일차 이식의 경우, 출산 예정일은 이식 날짜에 261일을 더한 거예요; 3일차 이식은 263일을 더해요. 5일차 이식, 삼월 2일 2026년의, 은 출산 예정일 십일월 18일 2026년을 줘요.

IVF 출산 예정일 계산기 사용 방법

  1. 배아 이식 날짜를 입력하세요.
  2. 이식 시 배아 나이를 고르세요: 3일 또는 5일.
  3. 추정 출산 예정일, 오늘의 임신 나이, 수학이 쓴 동등한 마지막 생리 날짜를 읽으세요.
예시: 5일차(배반포) 이식, 삼월 2일 2026년: 출산 예정일 = 삼월 2일 + 261일 = 십일월 18일 2026년. 이식 당일 자체에 이미 임신 2주 + 5일로 세요.

자주 묻는 질문

왜 이식 때 이미 '2주 임신'인가요?

임신 주수는 동등한 마지막 생리일에서 세어져요, 수정 약 14일 전이에요. 따라서 5일차 배아는 이식일에 임신 주수 2주 + 5일이고, 280일 카운트다운은 이식이 아니라 그 동등한 LMP에서 실행돼요.

261일과 263일은 어디서 오나요?

출산 예정일 = 동등 LMP + 280일. 동등 LMP = 이식일 − (14 + 일 단위 배아 나이). 5일차: 이식 + 280 − 19 = 이식 + 261일. 3일차: 이식 + 280 − 17 = 이식 + 263일.

IVF 출산 예정일은 자연적인 것보다 더 정확해요?

보통 예요 — 수정 날짜가 정확히 알려져 있어요, 그것은 자연 출산 예정일 수학에서 가장 큰 오류 원인을 제거해요. 클리닉은 날짜 측정 스캔 후에도 날짜를 조정할 수 있어요.

이것은 동결 배아 이식(FET)을 다루나요?

예 — 중요한 것은 이식한 날 배아의 나이(3일차 또는 5일차)예요, 신선하든 냉동이든. 실제 이식 날짜를 쓰세요.

작동 원리 — 공식

동등 LMP = 이식일 − (14 + 배아 나이)일. 출산 예정일 = 동등 LMP + 280일, 즉 이식일 + 263일(3일차 배아) 또는 이식일 + 261일(5일차 배아)로 간단해져요. 어떤 날짜의 임신 연령 = 해당 LMP 이후의 일수를 주 + 일로 나타낸 거예요.

작업 예시

입력들: 5일차 이식, 삼월 2일 2026년의.

단계: 동등 LMP = 삼월 2일 − 19일 = 이월 11일 2026년. 출산 예정일 = 이월 11일 + 280일 = 십일월 18일 2026년(동등하게 삼월 2일 + 261일: 삼월 남은 29일 + 사월 30일 + 오월 31일 + 육월 30일 + 칠월 31일 + 팔월 31일 + 구월 30일 + 시월 31일 = 243일, 시월 31일까지, + 18 = 십일월 18일).

결과: 출산 예정일 십일월 18일 2026년.

건강 고지: 교육용 추정치일 뿐이에요. 병원의 날짜 측정 — 날짜 스캔 포함 — 이 우선해요.
