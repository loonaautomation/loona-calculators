⚖️ 가중 의사결정 도구

가중치와 함께 옵션을 나열하세요 — 가중치가 클수록 기회가 커요 — 그리고 도구가 그 확률에 따라 공정하게 하나를 고르게 하세요. 모든 옵션의 정확한 확률은 선택 전후에 표시돼요.

빠른 답: 가중 선택은 옵션 i를 가중치 ÷ 전체 가중치의 확률로 골라요. 가중치가 1, 2, 3인 옵션의 확률은 1/6 ≈ 16.7%, 2/6 ≈ 33.3%, 3/6 = 50%예요.

가중 의사결정 도구 사용 방법

  1. 옵션을 한 줄에 하나씩 옵션, 가중치로 입력하세요 — 예를 들어 피자, 3.
  2. 가중치는 모든 양수일 수 있어요; 모든 선택지에 1을 쓰면 평범한 동등 확률 고르기를 얻을 수 있어요.
  3. 하나 고르기를 누르고 승자와 온전한 확률 표를 보세요.
예시: 저녁 옵션 — 피자, 3 · 스시, 1 · 버거, 2: 전체 가중치 6이라, 피자는 50% 확률, 버거는 33.3%, 스시는 16.7% 확률을 매 선택마다 가져요.

자주 묻는 질문

이것은 이름 룰렛와 어떻게 다른가요?

바퀴는 모든 조각에 같은 몫을 줘요. 여기서는 가중치로 조각 크기가 정해져요, 그래서 좋아하는 것을 더 가능하게 만들 수 있어요 — 그리고 페이지는 승자만이 아닌 각 선택지의 정확한 확률을 보여줘요.

가중치가 100이 돼야 하나요?

아니요. 그들의 비율만 중요해요: 가중치 2, 3, 5는 20, 30, 50과 같은 확률을 줘요. 자연스러운 척도를 쓰세요 — 별, 표, 예산 몫.

사람마다 티켓 수가 다른 추첨에 쓸 수 있나요?

예 — 그것은 완벽한 쓰임이에요. 각 사람을 그들의 티켓 수와 함께 가중치로 입력하면 고르기는 보유한 티켓에 정확히 비례해요.

하나의 선택이 시간이 지나며 균형을 맞출 '차례'예요?

아니요 — 각 선택은 독립적이에요. 많은 선택에 걸쳐 우승 횟수는 확률에 다가가지만(큰 수의 법칙), 어떤 옵션도 다음 선택에서 우승을 '빚진' 적은 없어요.

확률 계산기

수학

작동 원리 — 공식

확률(선택 i) = wᵢ ÷ Σw. 선택은 [0, Σw) 구간에서 균일 난수 u를 뽑고, u가 어떤 선택지의 구간 안에 들 때까지 누적 가중치를 따라가며 이뤄져요 — 정확한 확률을 재현하는 표준 역CDF 방식이에요.

작업 예시

입력들: 가중치 3, 1, 2(전체 6).

단계: 확률: 3÷6 = 50%, 1÷6 = 16.7%, 2÷6 = 33.3%. 누적 구간: Pizza [0, 3), Sushi [3, 4), Burgers [4, 6). u = 4.7의 추첨은 Burgers 구간에 떨어져요.

결과: u = 4.7 고르기 버거, 확률이 33.3%인 선택지예요.
