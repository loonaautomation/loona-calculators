방정식 풀이 도구 (일차 & 이차)

선형 방정식(ax + b = cx + d)과 이차 방정식(ax² + bx + c = 0)을 모든 단계와 함께 푸세요 — 판별식, 중복 및 복소수 근, 답을 대입하는 최종 확인을 포함해요.

네 개의 숫자를 다음에 입력하세요 ax + b = cx + d. 항이 없을 때는 0을 쓰세요 — 예를 들어, 2x + 3 = 7은 a = 2, b = 3, c = 0, d = 7이에요.

세 개의 계수를 다음에 입력하세요 ax² + bx + c = 0. 항이 없을 때는 0을 쓰세요 — 예를 들어, x² − 9 = 0은 a = 1, b = 0, c = −9예요.

방정식 풀이 도구 사용 방법

  1. 방정식 종류를 고르세요: 선형(x만) 또는 이차(x²).
  2. 계수를 입력하세요 — x²와 x 앞의 숫자, 그리고 일반 숫자. 빠진 항에는 0을 입력하세요.
  3. 단계와 함께 풀기를 누르고 과정을 줄마다 읽으세요. 마지막 단계는 답을 원래 방정식에 대입해 답을 확인해요.
예시: 3x + 2 = x + 10. x 항을 왼쪽으로 옮기세요: 2x + 2 = 10. 숫자를 오른쪽으로 옮기세요: 2x = 8. 2로 나누세요: x = 4. 검산: 3 × 4 + 2 = 14이고 4 + 10 = 14 ✓

자주 묻는 질문

이 솔버는 어떤 종류의 방정식을 처리할 수 있나요?

ax + b = cx + d 형태의 선형 방정식, 그리고 ax² + bx + c = 0 형태의 이차 방정식. 그것은 모든 단계를 보여주고, 이차의 판별식과 최종 확인을 보여줘요. 삼차 방정식, 미지수 두 개의 연립 방정식, 부등식은 풀지 않아요 — 페이지 제목이 정확히 무엇을 다루는지 말해요.

"해 없음" 또는 "무한히 많은 해"는 무엇을 뜻하나요?

때때로 x 항이 완전히 사라져요. 숫자도 일치하면(5x + 1 = 5x + 1처럼) 방정식은 항상 참이에요 — 무한히 많은 해. 숫자가 일치하지 않으면(5x + 1 = 5x + 3) 그것은 절대 참일 수 없어요 — 해 없음. 솔버는 답을 발명하는 대신 어느 경우인지 정직히 말해요.

복소수 근은 무엇인가요?

이차의 판별식(b² − 4ac)이 음수이면, 그래프는 절대 x축과 만나지 않고 실제 답은 없어요. 근은 그다음 i를 쓰는 복소수예요, i² = −1인 곳에서 — 예를 들어, x² + 1 = 0은 근 x = i와 x = −i를 가져요. 이 솔버는 그것들을 보여주고 여전히 그것들을 확인해요.

작동 원리 — 방법

선형 방정식 방정식을 균형 있게 유지해 풀어요 — 한쪽에 하는 것은 다른 쪽에도 해요. 먼저 x 항은 왼쪽에 모아요(cx를 양쪽에서 빼요), 그다음 숫자 항은 오른쪽에(b를 빼요), 그리고 마지막으로 양쪽을 x의 계수로 나눠요.

이차 방정식 이차 공식을 쓰세요. ax² + bx + c = 0에 대해:

x = (−b ± √(b² − 4ac)) ÷ (2a)

근 아래의 부분, D = b² − 4ac, 판별식이라고 하며, 끝까지 풀기 전에 답의 종류를 알려줘요: D > 0이면 서로 다른 두 실근, D = 0이면 하나의 중근, D < 0이면 두 복소근이라 실수 답이 없다는 뜻이에요.

작업 예시

예시: x² − 5x + 6 = 0을 푸세요. 여기서 a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, 그래서 √D = 1. 그다음 x = (5 + 1) ÷ 2 = 3 또는 x = (5 − 1) ÷ 2 = 2. x = 3으로 검산: 9 − 15 + 6 = 0 ✓

자주 묻는 질문

항이 빠진 방정식은 어떻게 입력해요?

누락된 계수에 0을 입력하세요. x² − 9 = 0은 a = 1, b = 0, c = −9가 되고, 솔버는 x = 3 또는 x = −3을 줘요. 2x = 10 같은 선형 방정식에서는 a = 2, b = 0, c = 0, d = 10이에요.

이차 솔버에 a = 0을 입력하면요?

그러면 x² 항이 사라지고 방정식은 진짜로 선형이에요. 솔버는 이것을 알아차리고 대신 그것을 선형 방정식으로 풀어요, 그것이 일어난 일이라고 말해요.

왜 솔버는 끝에 답을 확인하나요?

답을 원래 방정식에 대입하는 것은 실수를 잡는 가장 확실한 방법이에요: 양쪽이 같게 나오면, 답은 확실히 맞아요. 그것은 숙제에도 좋은 습관이에요 — 교사는 종종 보이는 확인에 방법 점수를 줘요.
