Risolutore di equazioni (lineari e quadratiche)

Risolvi equazioni lineari (ax + b = cx + d) ed equazioni quadratiche (ax² + bx + c = 0) con ogni passaggio mostrato — inclusi discriminante, radici ripetute e complesse, e una verifica finale che sostituisce la risposta di nuovo dentro.

Inserisci i quattro numeri in ax + b = cx + d. Usa 0 dove manca un termine — ad esempio, 2x + 3 = 7 è a = 2, b = 3, c = 0, d = 7.

Inserisci i tre coefficienti in ax² + bx + c = 0. Usa 0 dove manca un termine — ad esempio, x² − 9 = 0 è a = 1, b = 0, c = −9.

Come usare il risolutore di equazioni

  1. Scegli il tipo di equazione: lineare (solo x) o quadratica (x²).
  2. Digita i coefficienti — i numeri davanti a x² e x, e il numero semplice. Inserisci 0 per qualsiasi termine mancante.
  3. Premi Risolvi con i passaggi e leggi lo svolgimento riga per riga. L'ultimo passaggio verifica la risposta sostituendola di nuovo nell'equazione originale.
Esempio: 3x + 2 = x + 10. Sposta i termini in x a sinistra: 2x + 2 = 10. Sposta il numero a destra: 2x = 8. Dividi per 2: x = 4. Verifica: 3 × 4 + 2 = 14 e 4 + 10 = 14 ✓

Domande frequenti

Quali tipi di equazioni può gestire questo risolutore?

Equazioni lineari nella forma ax + b = cx + d, ed equazioni quadratiche nella forma ax² + bx + c = 0. Mostra ogni passaggio, il discriminante per le quadratiche e una verifica finale. Non risolve equazioni cubiche, sistemi di equazioni in due incognite o disequazioni — il titolo della pagina dice esattamente cosa copre.

Cosa significa “nessuna soluzione” o “infinite soluzioni”?

A volte i termini in x si cancellano completamente. Se anche i numeri coincidono (come 5x + 1 = 5x + 1) l'equazione è sempre vera: infinite soluzioni. Se i numeri non coincidono (5x + 1 = 5x + 3) non può mai essere vera: nessuna soluzione. Il risolutore ti dice onestamente quale caso hai, invece di inventare una risposta.

Cosa sono le radici complesse?

Quando il discriminante di un'equazione quadratica (b² − 4ac) è negativo, il grafico non attraversa mai l'asse x e non ci sono risposte reali. Le radici sono allora numeri complessi che usano i, dove i² = −1 — per esempio, x² + 1 = 0 ha radici x = i e x = −i. Questo risolutore le mostra e le verifica comunque.

Come funziona — il metodo

Equazioni lineari si risolvono mantenendo l'equazione in equilibrio — qualsiasi cosa fai a un lato, la fai anche all'altro. Prima i termini con x si raccolgono a sinistra (sottrai cx da entrambi i lati), poi i termini numerici a destra (sottrai b), e infine entrambi i lati vengono divisi per il coefficiente di x.

Equazioni quadratiche usa la formula quadratica. Per ax² + bx + c = 0:

x = (−b ± √(b² − 4ac)) ÷ (2a)

La parte sotto la radice, D = b² − 4ac, è chiamato discriminante, e ti indica il tipo di risposta prima di finire: D > 0 significa due radici reali diverse, D = 0 significa una radice ripetuta, e D < 0 significa due radici complesse e nessuna risposta reale.

Esempio svolto

Esempio: Risolvi x² − 5x + 6 = 0. Qui a = 1, b = −5, c = 6. D = (−5)² − 4 × 1 × 6 = 25 − 24 = 1, quindi √D = 1. Allora x = (5 + 1) ÷ 2 = 3 o x = (5 − 1) ÷ 2 = 2. Verifica x = 3: 9 − 15 + 6 = 0 ✓

Domande frequenti

Come inserisco un'equazione con un termine mancante?

Inserisci 0 per il coefficiente mancante. x² − 9 = 0 diventa a = 1, b = 0, c = −9, e il risolutore dà x = 3 o x = −3. Per un’equazione lineare come 2x = 10, cioè a = 2, b = 0, c = 0, d = 10.

E se digito a = 0 nel risolutore quadratico?

Allora il termine x² scompare e l'equazione è in realtà lineare. Il risolutore lo nota e la risolve invece come un'equazione lineare, dicendoti che è quello che è successo.

Perché il risolutore verifica la sua risposta alla fine?

Sostituire la risposta di nuovo nell'equazione originale è il modo più sicuro per cogliere un errore: se entrambi i lati risultano uguali, la risposta è certamente giusta. È una buona abitudine anche per i compiti a casa: gli insegnanti spesso danno punti per il metodo a una verifica visibile.
